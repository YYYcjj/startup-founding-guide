> 定位：合伙人、客户、供应商、投资人、同行、监管——**商业关系靠信用和边界，不靠酒量和义气**。
> 本文把这六类关系从"一句话原则"展开成**可照做的经营动作**：每类都讲「怎么经营 → 常见坑 → 话术/动作 → 红线」。

## 1. 合伙人 / 股东关系（最重要的商业关系）

### 1.1 选人：用"测试期"代替"拍脑袋"

- 选合伙人看四样：**能力互补、价值观一致、能扛事、家庭支持**（伴侣反对的合伙很难长久——出问题时后院先起火）。
- **别一上来就注册**：先一起做一个 3–6 个月的项目/订单，观察他面对**钱、分歧、压力**时的真实反应，比酒桌上聊一百句都准。
- 拉长"蜜月期"的代价最小：此时拆伙只伤感情不伤股权；注册后再拆，涉及出资、债务、税务清算，成本高十倍。

**候选人心态体检表（对号入座）：**

| 信号 | 判断 |
|------|------|
| 谈钱含糊、抢功、推责 | ⚠️ 慎选，出事大概率先甩锅 |
| 只愿意出钱/出资源，不想干活 | 除非你缺的是钱，否则是"股东"不是"合伙人" |
| 什么都"没问题"从不说不 | 风险意识弱，容易把公司带进坑 |
| 有分歧能摆事实、对事不对人 | ✅ 值得长期共事 |

### 1.2 股权与钱：丑话说在前面，白纸黑字

- **避免平均**：50:50、各 1/3 会在关键决策时僵局。按"出资 + 贡献 + 风险"谈出**一个能拍板的人**（如 51:49 或 60:40），并用章程约定决策机制。
- 出资不只是钱：**技术、客户资源、全职投入**都要折算成条款写清楚（技术入股怎么估值、离职怎么收回）。
- 分红规则定死：利润多少比例再投入、多少分红、多久一次（如每季度/每半年）、谁有权决定——**赚钱后最伤感情的往往不是分多分少，而是规则没定**。
- 预留**期权池**（10–15%）：给未来核心员工/新合伙人留空间，否则到时候没人愿意加入，现股东又不想稀释。

### 1.3 协议必写的十件事（缺一项都是雷）

> 全文可直接抄的样张见 [附录/05-可直接抄写的模板样张](../附录/05-可直接抄写的模板样张.md)「股东协议」。

1. 股权比例与出资方式（含非现金出资估值）
2. 分工与决策权（哪些事一个人说了算、哪些要全体）
3. 竞业限制（在职与退出后 1–2 年内不得同业）
4. 保密义务（客户名单、供应链、技术）
5. 知识产权归属（公司做的归公司，含个人私下开发的界定）
6. 退出机制（怎么退、按什么估值、多久付清）
7. 增资与稀释规则（未来融资怎么摊）
8. 僵局处理（意见 50:50 时怎么破：轮流 CEO / 第三方仲裁 / 一方买断）
9. 违约与处理（不干活、抽逃出资怎么办）
10. 死亡/失能处理（股权怎么继承或回购——呼应公司遗嘱）

### 1.4 日常相处：三个动作防变味

- **定期对账会**：每月/每季度一次正式的"账目 + 方向"同步，别等问题攒到爆才谈。
- **分工边界书面化**：谁管钱、谁管业务、谁管对外，各写各的 KPI；重叠地带提前划。
- **钱和情分开**：私人借款走借条（见模板样张），别用公司账和个人情混着还。

> 🚫 **红线**：合伙期间做两套账、私下转让股权、把公司客户带出去自己做——任何一条都足以让合伙彻底破裂，还可能涉诉。

## 2. 客户关系（公司的命脉）

### 2.1 客户分层：不是所有客户都值得伺候

| 层级 | 特征 | 策略 |
|------|------|------|
| A 核心客户 | 复购稳定、付款及时、愿意转介绍 | 优先服务、给资源、维护到位 |
| B 成长客户 | 有潜力但还在磨合 | 正常服务、观察 2–3 单再升 A |
| C 消耗型客户 | 压价狠、要求无底线、拖欠 | **逐步汰换**，别让 20% 烂客户拖垮你 |

**坏客户预警信号**：首单就拼命砍价、要求先干活后给钱、把"介绍大客户"当空头支票、对合同条款反复推翻——出现 2 条以上，接单前要三思（详见 [公司/10-报价与收款](../公司/10-报价与收款.md) 坏账红线）。

### 2.2 让客户赢：交付与关系管理

- **承诺最小化、交付超预期**：答应 3 天交付就按 2 天安排；答应"能用"就做到"好用"。惊喜产生复购，惊吓产生投诉。
- **主动汇报进度**：重要项目每周/每里程碑主动同步一次，别等客户来问——客户最怕的不是慢，是"不知道进行到哪了"。
- 投诉与失误处理：用 [公司/12-危机与客诉应对](../公司/12-危机与客诉应对.md) 的五步法，**先接情绪、再解决问题**。

### 2.3 关系沉淀到公司，别绑在个人微信

- 合同主体是**公司**（不是法人个人）；收款进**对公账户**。
- 对接人多点化：至少让客户认识你公司 2–3 个人，别只认你一个——你病假三天，客户就找不到人，等于业务断三天。
- 客户信息进 CRM/表格：联系人、历史订单、偏好、下次跟进时间——**公司资产，不是个人记忆**。

### 2.4 复购与转介绍：最便宜的获客

- 交付完成后 1–2 周回访一次："用得怎么样？有没有可以优化的地方？"——顺便提一句"有朋友需要可以介绍给我"。
- 转介绍给**明确的好处**：老客户介绍新客户，给老客户返点/赠服务/优先排期，把"人情"变成"规则"。
- 每年做一次核心客户盘点：谁是靠你吃饭的人，谁是你可以靠的人。

> 🚫 **红线**：为了留客户无底线让利（做到亏本）、给回扣、陪客户做假账——短期留住的是客户，长期毁掉的是公司。

## 3. 供应商 / 合作方

### 3.1 选择与试合作

- 关键物料/服务**至少储备 2 家**可替换供应商，别被一家拿捏（断供、坐地起价时你才有还手余地）。
- **先小单试合作再给大单**：小额订单验证质量、交期、出了问题怎么处理，再放量。
- 供应商报价明显低于同行时问一句"**差在哪**"——材料、人工还是账期？便宜得离谱往往有坑。

### 3.2 合同：写清四件事

1. **验收标准**（什么算合格，怎么验收，多久内提出异议）
2. **付款节点**（预付比例、货到/验收后付多少，别一次付清）
3. **交期与违约责任**（延迟每天罚多少、什么情况可解约）
4. **质保与售后**（出问题谁负责、响应时限）

> 配套动作链：[公司/10-报价与收款](../公司/10-报价与收款.md) 讲你收款，本节讲你付款——同一套逻辑反过来用。

### 3.3 长期经营：付款信用是最好的筹码

- **按时付款**：账期说 30 天就 30 天，别拖到 60 天。供应商圈子里你的口碑，决定你困难时能不能拿到账期和优先供货。
- 遇到资金紧张**提前 3–5 天主动沟通**："这批款要晚 X 天，我确认 X 号前到"，好过到期无声——主动说明 vs 失联，是两个完全不同的信用等级。
- 逢年过节/合作周年一份小问候（信息即可），把"交易关系"升级为"伙伴关系"。

> 🚫 **红线**：为了压价编造别家报价、拖欠后失联、把供应商的账期挪作他用去投机。

## 4. 投资人 / 股东（外部资本）

### 4.1 拿钱之前：想清楚三个问题

- **要的是钱还是资源？** 纯钱（银行/亲友借款能解决）就别轻易稀释股权；要的是渠道、背书、行业资源，才值得用股权换。
- **拿了钱之后你还说了不算？** 股权稀释 + 对赌条款可能让你"公司越大越不是你的"——先看 [公司/01-公司创立](../公司/01-公司创立.md) 的股权基础。
- **退出路径是什么？** 投资人投你是为了退出（分红/回购/并购/上市），你得知道对方期待几年怎么退——没有共识，迟早是冲突。

### 4.2 条款：识别"毒条款"

| 条款 | 一句话 | 警惕点 |
|------|--------|--------|
| 对赌（业绩承诺）| 达不到目标就要补偿/回购 | 目标要可达成，别签"翻倍式"赌约 |
| 回购 | 特定条件下你要把钱还回去 | 看清触发条件，别把自己个人资产搭进去 |
| 优先清算 | 退出时投资人先拿钱 | 正常；但"优先倍数"过高你要细算 |
| 一票否决 | 重大事项投资人有一票否决 | 范围越小越好，别让日常经营也被否决 |
| 反稀释 | 后续融资低价时补差价 | 标准条款，但看清是"加权平均"还是"完全棘轮" |

> **所有条款请律师逐条看**，别信"这是标准条款没风险"——标准是"常见"，不等于"对你有益"。

### 4.3 投后管理：坏消息早说

- 定期（月度/季度）如实汇报：财务数据 + 业务进展 + 遇到的困难。
- **坏消息第一时间的报告原则**：问题刚露头就同步 + 附上你的应对方案，别拖到爆雷才让投资人从别人嘴里听说——信任一旦破裂，比亏钱更难修。
- 需要追加钱/支持时，带着数据去谈（增长曲线、现金流预测），别只带故事。

> 🚫 **红线**：美化报表、隐瞒重大风险、把投资款挪用做与约定无关的事——这是法律与信任的双重自杀。

## 5. 同行 / 圈子 / 导师

### 5.1 进圈：先给后取

- 高质量圈子（行业协会、垂直社群、线下课程）的信息差和转介绍，远超你单独摸索。**进入方式**：付费课程/活动是最快路径（花钱买门，比蹭来得体面）。
- 进圈第一原则：**先贡献价值再索取**。自我介绍带干货（"我做过 X，能帮大家 Y"），多回答问题、分享踩坑经验——先被认识，才有被介绍。
- 圈子贵精不贵多：深耕 1–2 个与你业务强相关的圈子，比加了 50 个群从不说话强。

### 5.2 同行：可以合作，别恶性竞争

- **同行是资源不是敌人**：拼单、互补交付（你做不了的活推荐给他）、联合报价大项目、共享不敏感的经验——圈子就这么大，谁靠谱大家门儿清。
- 恶性压价、撬同行客户、背后说坏话：短期得利，长期在整个圈子里社会性死亡。
- 竞品动态要跟踪（价格、新品、打法），但目的是学打法，不是骂对手。

### 5.3 导师：找 1–2 个能说真话的人

- 找谁：年长你 5–10 岁、走过你正在走的路、且愿意直说的前辈（同行前辈、客户里的高手、上家老板、课程老师）。
- 怎么处：**主动、带问题、不白嫖**。请教前先自己查过资料（"我研究了 A/B 两个方案，倾向 A，您看呢？"），对方答完给反馈；逢年过节问候、有成果报个喜。
- 导师的终极价值不是给你答案，是**在你要做蠢事时敢拦你一句**。

> 🚫 **红线**：把导师当免费顾问无限索取、拿导师名义在外招摇、向同行刺探对方客户隐私。

## 6. 监管关系（税务 / 工商 / 行业主管）

### 6.1 认知：合规是最好的"关系"

- 依法申报、账目清楚、材料齐全——被稽查时，**材料和账就是你的护身符**，比任何关系都硬。
- 千万别信"找个关系摆平"：现在税务/工商全程系统化留痕，违规摆平的成本和风险远超补税本身。

### 6.2 接触分寸：客气可以，利益输送是雷

- 办事人员、检查人员：正常礼貌、一杯茶的客气都可以；**送礼、回扣、好处费、帮忙安排"工作"——红线，绝对不碰**（行贿是刑事犯罪，不是人情世故）。
- 被检查/稽查时：配合、如实、不卑不亢；不清楚的条款**书面咨询**（官方咨询电话、办事窗口、12366），留好记录。

### 6.3 日常动作清单

- [ ] 各项申报日历化：报税（每月 15 日前）、年报（每年 1.1–6.30）、汇算清缴（次年 5.31 前）——详见 [公司/11-第一年经营节奏](../公司/11-第一年经营节奏.md)
- [ ] 官方文件/回执**归档留存**（电子+纸质），至少保留 5 年
- [ ] 政策变化跟一跟：所在地税务公众号、行业主管通知，别等被通知违规才知道新规
- [ ] 行业需要的资质/许可证（消防、食品、ICP 等）按行业办理，见 [附录/01-办事网站与入口](../附录/01-办事网站与入口.md)

> 🚫 **红线**：虚开发票、私户收款不报税、行贿、伪造材料——任何一条都可能让公司一夜归零并牵出刑事责任。

## 7. 商业信誉：把"信用"当资产来经营

- **承诺闭环是底层货币**：交付时间、付款承诺、合同条款——说到的做到。一次失信，在圈子里传播的速度远超你的想象。
- **失信之后怎么办（补救公式）**：第一时间承认 → 说明原因不找借口 → 给出补救方案和明确时限 → 超预期补偿。修复一次失信的成本是守信的十倍，但比装没事强一百倍。
- 信誉是**复利资产**：专业、靠谱、守信的口碑积累 3–5 年，会成为融资、合作、招人时最硬的敲门砖——别人愿意赌你，是因为信你这个人。

## ✅ 综合行动清单

**本月：**
- [ ] 合伙人有协议吗？没有就补签（十件事逐条过）；有就检查有没有过时条款
- [ ] 客户分层 A/B/C 拉一张表，标出要汰换的 C 类
- [ ] 关键供应商是否 ≥2 家？没有就开发备胎
- [ ] 检查合同里有没有毒条款（尤其对赌/回购），必要时找律师过一遍

**每季度：**
- [ ] 核心客户回访 + 转介绍机会盘点
- [ ] 供应商/合作方账期复盘：有没有拖欠记录
- [ ] 投资人/股东同步一次进展（哪怕只是邮件）

**每年：**
- [ ] 圈子评估：留 1–2 个高价值圈，退掉消耗型
- [ ] 导师关系维护（成果报喜 + 节日问候）
- [ ] 商业信誉自评：今年有没有失信记录？有就按补救公式处理掉
