## 三、"详细版"写作标准（样板篇遵循）

- 有**操作步骤**（第几步做什么），不只是"要做什么"
- 有**数字参考**（预算区间、比例、期限）
- 有**示例话术/模板片段**（可直接改着用）
- 结尾附**可勾选行动清单**
- 链接到兄弟文档与附录，不重复造内容

## 四、盲区扫描方法（三步，可复用）

盲区不能靠"感觉缺什么"，要靠**扫描出证据**。本轮已固化成脚本：`<repo>/.workbuddy/audit-content.py`，三步依次跑。

### 第一步：相对链接死链扫描

把全站 md 里的 `[文字](路径)` 全部解析，逐个检查目标文件是否存在（跳过 `http`/`mailto`/纯锚点）。

> ⚠️ **这一步只能抓"文件不存在"，抓不到"引用指错"**——本轮就有一例：`[01-商业关系](01-商业关系.md) 5.2 的说不清单` 链接完全有效，但 01 的 5.2 讲的是同行竞争。**必须配第二步。**

### 第二步：引用小节编号核验

把全站所有标题建成索引（`### 5.2 xxx` → `5.2`），再扫"`](xxx.md)` 后面紧跟的 `X.Y`"这类引用，比对目标文件里**是否真有这一节**。

**这是最有价值的一步**：内容增删改过几轮之后，小节编号会漂移，而链接检查永远是绿的。

> 💡 **两类假阳性要靠规则排除，别靠肉眼**：① 编号属于**别篇**（同行里紧挨 `.md` 链接）；② **全文没有编号小节的文件**（如本页用"一、二、三"）里的 `§2.3` 只可能是"在描述别人的小节"。加这两条排除后，本轮一次性报出的 2 条警报归零，且用正反用例验证过**真错仍会被抓到**（造一个引用不存在小节的临时文件 → 依旧报错）。

### 第三步：关键词 0 命中扫描

维护一张"这个站该覆盖的关键词"表（如 谈判 / 倾听 / 说服 / 竞业 / 意定监护 / 长护险 ……），统计每个词在几篇里出现。**0 命中 = 结构性盲区**（早期就是靠它发现"说服/反驳 0 篇、倾听仅 1 篇"，进而定位出"沟通与谈判"这个板块级空白；本轮靠它定位出"年化收益/被动收入/财务自由/市盈率/行业研究 0 命中"，进而发现整个"未来与投资"板块只覆盖了"选方向 + 看项目"两件事）。

> 💡 **用法**：每次补完内容，把新写入的关键词加回表里——**下次扫描就会告诉你还有哪些领域一次都没碰过**。
> 💡 **新加的类别**：`未来与投资`（资产配置 / 复利 / 定投 / 被动收入 / 负债 / 征信 / 财报 / 市盈率 / 行业研究 / 通胀 / 买房 ……）。下一轮补完内容后，把新词继续加进去。
