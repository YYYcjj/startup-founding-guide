## 0. 注册前要备好的 6 件事（先备齐再动系统）

| # | 事项 | 提前做 | 备注 |
|---|------|--------|------|
| 1 | 公司名称 3–5 个备选字号 | 注册前 1–3 天 | 同行业/同地区重名率较高，备多 |
| 2 | 注册资本金额与 5 年实缴计划 | 决策前 | 新《公司法》5 年内须缴足 |
| 3 | 经营范围（主营 + 兼营）| 决策前 | 主营决定税种与资质 |
| 4 | 注册地址证明（租赁合同 / 挂靠 / 孵化器）| 注册前 1 周 | 商住两用/民用地址多数地区已不接受 |
| 5 | 法人 / 股东 / 监事 / 财务负责人 身份证+实名手机号 | 注册前 1 周 | 法人≠监事，需另设一人 |
| 6 | 股权比例与股东协议（先签后注）| 注册前 | 亲友合伙先签，避免后扯 |

### 0.1 公司名称怎么起（核名通过率高）

- 格式：`深圳 + 字号 + 行业描述 + 有限公司`
  - 例：`深圳市云启科技有限公司`（深圳+字号"云启"+行业"科技"+组织形式"有限公司"）
- **字号避坑**：不要用驰名/知名/著名商标；不要用"中国/国家/中央"开头；不要含数字、字母（部分允许）；行业描述要准确（如做服装的写"服饰"别写"科技"）。
- 行业表述参考《国民经济行业分类》——主营必须和行业描述匹配，否则后续开发票可能受限。
- 准备 3–5 个字号时，按"喜欢度"排序，第一个重名就立刻换第二个。

### 0.2 注册资本填多少（认缴 5 年内要实缴）

| 场景 | 建议金额 | 理由 |
|------|----------|------|
| 普通服务/咨询 | 10–50 万 | 客户/平台对注册资本没硬要求 |
| 需投标/平台开店/部分资质 | 100–500 万 | 部分行业招标设门槛 |
| 平台型/有外部融资计划 | 100 万起+动态调整 | 后续融资要重评 |

> ⚠️ 2024-07-01 起，新《公司法》要求有限责任公司认缴出资**自成立之日起 5 年内缴足**；老公司有过渡期最晚 2032-06-30 前调整到位。注册资本是**责任上限**——公司欠债时未实缴部分可被"加速到期"。
> 实缴到位前，**账上别长期趴着大额未实缴挂账**——会被税务/工商关注。

### 0.3 经营范围怎么填（顺序与税种挂钩）

- 第一项是**主营**（决定税种核定、行业税率、可能的资质审批）。
- 兼营按相关性往下排；可参考同行模板但**别照抄**——你的实际业务范围决定你需要哪些资质。
- 涉及前置审批的（如食品、医疗、教育、危化品、ICP 等）先办许可证再写进经营范围。
- 后期可变更，但每次变更都涉及工商提交+章程修改，建议**起步把未来 1–2 年可能要做的也写进去**。

### 0.4 注册地址类型对比（影响费用与异常风险）

| 类型 | 月/年费用 | 适用 | 风险提示 |
|------|-----------|------|----------|
| 自有商用地址 | 0（已有） | 有真实办公地 | 最稳 |
| 租赁写字楼/办公 | 月租数千–数万 | 已确定办公 | 合规首选 |
| 孵化器 / 众创空间挂靠 | 1,000–5,000/年 | 早期无固定办公 | 确认孵化器有真实备案 |
| 前海/各地政策地址 | 数百–数千元/年 | 想拿政策红利 | 不同园区政策差异大，逐条问清 |
| 虚拟地址 / 虚假地址 | 看似便宜 | — | **高风险**：被列入经营异常名录，影响贷款/投标/法人征信 |

> 🚫 千万别图便宜用虚假地址——市场监管局会"双随机"抽查，地址失联 6 个月直接列异，**影响所有需要信用良好的场景**（贷款、平台入驻、投标）。

## 1. 完整注册流程（8 步，深圳一窗通可全线上）

```text
步骤1 名称申报 → 步骤2 设立登记 → 步骤3 实名认证 → 步骤4 领取执照
步骤5 刻章 → 步骤6 银行开基本户 → 步骤7 税务报到 → 步骤8 社保/公积金开户
```

### 步骤 1：名称自主申报（即时）

- 入口：深圳市市场监督管理局「开办企业一窗通」https://amr.sz.gov.cn/
- 填写：行政区划（深圳）+ 字号 + 行业 + 组织形式 → 系统自动查重。
- 通过后获得**"企业名称自主申报告知书"**（保留截图），30 天内有效；过期要重新申报。

### 步骤 2：设立登记提交（1–3 工作日）

- 同一窗通继续填写：注册资本、实缴期限、经营范围、股东信息、任职文件（法人/董事/监事/经理）。
- 上传材料：股东身份证、住所证明、公司章程（系统可生成模板）。
- 全体股东电子签名（用"粤商通"App 或微信小程序扫码）。
- 提交后等审核——一次没通过的常见原因：经营范围不规范、住所证明不清晰、签名不全。

### 步骤 3：实名认证（当天）

- 全体人员（股东、法人、监事、经理、财务负责人）在「登记注册身份验证」App 或微信小程序完成**人脸识别**。
- 必须本人做、必须身份证号与登记一致——别让同事代做。

### 步骤 4：领取营业执照（当天）

- 审核通过后 1 小时内一般可下载**电子营业执照**（微信/支付宝小程序"电子营业执照"），纸质版可选择邮寄或现场领取。
- 电子执照与纸质版具有同等法律效力——谈客户、签合同、办银行都可用电子版。

### 步骤 5：刻章（当天，深圳新设常免费）

- 公章 / 财务章 / 法人章 / 发票章 / 合同章——5 枚一套。
- 必须**公安备案**的刻章点（系统会推荐），其他途径刻的章无效且违法。
- 领章后第一件事：**建立用印登记本**（谁、什么时候、什么文件、用途——公章=公司意志，别随手放桌上）。

### 步骤 6：银行开基本户（1–2 周，最易卡的环节）

- 选银行原则：距离近（每月要跑）、费用低（小规模账户管理费 0–200 元/年差异大）、开户快（招行/建行/工行效率较高）。
- **必须法人亲自到场**，带：营业执照、公章、财务章、法人章、法人身份证、股东身份证、住所证明。
- 提前电话预约（多数银行不接临时上门的开户）；可能需要现场面谈（问公司做什么、办公在哪），答得清晰有利通过。
- 开户后开通网银 U盾 / App，绑定对公账户——**基本户是公司唯一的"工资户"**（发工资、缴税、收款都走它）。

> 💡 **小坑预警**：部分银行对注册地址查得严，孵化器地址可能要求提供额外证明；先电话问清再去。

### 步骤 7：税务报到（当天可办）

- 入口：深圳市电子税务局 https://shenzhen.chinatax.gov.cn/
- 用法人或财务负责人身份注册、登录 → 「企业开办」 → 确认税种核定、票种核定（小规模 vs 一般纳税人）。
- **领 UKey / 税控盘**（开发票用），绑定到开票电脑。
- 签"三方协议"（银行+税务+公司）——以后自动从基本户扣税。
- 即使还没收入，**次月 15 日前必须申报**（零申报也要报，逾期罚款+影响信用）。

### 步骤 8：社保 + 公积金开户（当天可办）

- 深圳市社保局 https://hrss.sz.gov.cn/ → 单位首次参保登记
- 公积金中心 https://zjj.sz.gov.cn/ → 单位开户
- 完成开户后：每月通过网上服务系统**增员/减员/缴费基数申报**——员工入职次月起缴。

> ⚠️ 即使公司暂时没员工，也要做这一步——后续招人时才能及时增员；否则员工社保中断 = 你的责任。

## 2. 注册后必做的 6 件合规事（前 30 天）

- [ ] **建账**：无论是否有收入都要建账（设凭证、账簿）。代账公司通常含在服务里。
- [ ] **挂网银 + 设置出纳**：U盾/网银由出纳保管；复核权限另设一人（不相容职责分离）。
- [ ] **签发首张发票前**：先在电子税务局完成票种核定 + 领取 UKey + 装好开票软件。
- [ ] **设置报税提醒**：每月 15 日前（增值税+个税）、每季 15 日前（企业所得税预缴）。用日历或记账 App 提醒。
- [ ] **建立档案盒**：纸质/电子两套——执照、章程、股东协议、合同、印章登记本、银行回单、发票存根——保存至少 10 年。
- [ ] **给公章/执照/网银/U盾 建一份"使用登记本"**：借出/归还签字，防丢防滥用（呼应 [05-数字资产与账号安全](../个人与人际/05-数字资产与账号安全.md) 的权限管理）。

## 3. 注册成本估算（深圳 2026 年参考）

| 项目 | 费用区间 | 说明 |
|------|----------|------|
| 工商注册 | 0 元 | 政府不收费 |
| 刻章 | 0–300 元 | 新设企业深圳多区有免费首套 |
| 挂靠/孵化器地址 | 1,000–3,000 元/年 | 不需真实办公时 |
| 银行开户 | 0–500 元 | 部分银行收年费/网银费 |
| 代理记账 | 200–500 元/月 | 小规模；一般纳税人 500–1,500 元/月 |
| 注册资本 | 0（认缴） | 5 年内实缴 |
| 税控 UKey / 发票 | 0–200 元 | 部分免费 |
| **起步最低预算** | **约 3,000–5,000 元/年** | 包含地址 + 记账，零办公租金情形 |

> 自己办可省代办费（500–1,500 元），但要花时间学；怕麻烦 + 业务忙 → 代办性价比更高。

## 4. 常见失败原因速查（一次通过的关键）

| 失败原因 | 怎么避免 |
|----------|----------|
| 名称重名 | 字号避开行业热词；备 3–5 个 |
| 经营范围不规范 | 参考同行，但**只写你真要做/可能做的** |
| 住所证明不被认可 | 商用/孵化器地址有书面证明；民宅多数地区不行 |
| 股东/法人未实名 | 注册前所有人员先在 App 实名 |
| 注册资本过大 | 按业务真实需要；5 年内必须实缴，**别写亿级** |
| 法人兼监事 | **法律禁止**，需另设一人 |
| 银行开户被拒 | 选小银行或先电话沟通；准备公司业务说明（1 页纸） |
| 经营范围缺前置许可 | 食品/医疗/教育/危化品等先办许可证 |

## 5. 决策清单（注册前自问 5 问）

| # | 问题 | 没想清楚就别注 |
|---|------|----------------|
| 1 | 这个生意有人愿意付费吗？**至少 3 个目标客户给了口头意向** | 没 |
| 2 | 注册后 6 个月的现金流够活吗？**安全垫 = 6 个月固定成本** | 不够 |
| 3 | 注册资本 5 年内能实缴吗？ | 不能就降 |
| 4 | 与合伙人/股东协议签了吗？ | 没签就先别注 |
| 5 | 经营范围里需要前置许可的行业，你办了吗？ | 办了再注 |

## ✅ 本节行动清单

**注册前 1 周：**
- [ ] 备齐 6 件事（名称 3-5 个 / 注册资本 / 经营范围 / 地址 / 人员 / 协议）
- [ ] 完成股东协议签字（哪怕一人公司也写一份《独资股东决定》）
- [ ] 法人在「登记注册身份验证」App 完成实名

**注册当天：**
- [ ] 一窗通提交设立登记 → 等审核 → 领执照
- [ ] 刻章 + 用印登记本上线
- [ ] 电子税务局完成税务报到、税种核定、三方协议

**注册后 1–2 周：**
- [ ] 银行开基本户（提前电话预约）
- [ ] 社保 + 公积金开户
- [ ] 装开票软件 + 领 UKey（即便暂时不开票也先装好）

**注册后 30 天内：**
- [ ] 建账（找代账或自学）
- [ ] 设报税/缴费日历提醒
- [ ] 归档所有注册文件（电子+纸质）
