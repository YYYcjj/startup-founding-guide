## 📖 阅读顺序建议

1. 先看 **总纲**：建立「维度 × 阶段」全局观 + 优先级矩阵

3. 注册时照着 [创业流程/03-注册清单.md](创业流程/03-注册清单.md) 逐项打勾 ✅
