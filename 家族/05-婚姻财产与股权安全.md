# 婚姻财产与股权安全：把最坏的情况写清楚，才敢做最好的事

> 定位：创业者最贵的一课不是产品失败，是**公司正跑到关键处，股权突然多出一个"不参与经营的共有人"**。
> 本篇讲三件事：**你的公司股份，到底有多少是"夫妻共有"的；有哪些合法又体面的办法提前安排好；一旦走到最坏，公司会受什么冲击。**
> 看这一篇之前请先接受一个前提：**这不是"防配偶"，而是"两个人都知道底线在哪"**——写清楚规则，才不必靠猜和忍。

> ⚠️ 通用参考，**不构成法律意见**。婚姻家事法律高度依赖个案证据与地方裁判口径，涉及具体安排请找婚姻家事律师出一版方案。

## 一、先把最容易被误解的一点说清：股份到底是不是"夫妻共同财产"

很多创业者以为"公司是我婚前开的 / 拿我自己的钱开的，所以股份跟配偶无关"。**这个理解只对了一半。**

**判断分两层：股份本身 与 股份带来的收益，规则不一样。**

| 情形 | 股份本身 | 婚后产生的**分红** | 婚后产生的**增值** |
|---|---|---|---|
| **婚前**已取得股份 | 个人财产 | 原则上**共同** | 原则上**共同**（自然增值如市场普涨除外） |
| **婚后**取得股份 | **共同** | 共同 | 共同 |
| 婚前财产出资、**婚前**登记 | 个人财产 | 原则上共同 | 原则上共同 |

法律依据是《民法典》第 1062、1063 条：一方婚前财产属个人；但**婚后"生产、经营、投资的收益"，原则上归夫妻共同所有**。

> 也就是说：**股份的所有权可能只属于你，但"它这几年挣的钱和涨的价"，配偶通常有一半权益。**
> 这正好对应了公司估值最高、也是矛盾最容易爆发的时候——融资、上市、大额退出。

**所以真正需要提前安排的，不是"股份是不是她的"，而是"当收益要兑现时，钱从哪出、股份归谁"。**

## 二、婚前该做的三件事（还没结婚的，先看这里）

### 1. 搞清对方的负债状况（这一项最容易漏）

婚后共同财产是要一起过日子的。**婚前债务原则上是个人债务，但如果用于婚后共同生活（比如借钱买房装修、办婚礼），可能转化为共同债务。**

**做法：** 婚前坦诚交换一次征信报告（人民银行征信中心可查），重点看有没有网贷、担保、被执行的记录。**这不是查岗，是合伙前的基本尽调**——你开公司见投资人还要看财报，为什么结婚不看？

### 2. 婚前财产留好"来源证据"

如果公司是你婚前创立的，**必须能证明"出资来自婚前个人财产、且没有和婚后财产混同"**。

| 动作 | 为什么 |
|---|---|
| 保留出资转账记录、银行流水、验资/股权证明 | 证明钱的来路 |
| 婚前财产单独放一个账户，**不与婚后收入混着用** | 一旦混同，很难区分，举证会变成一场苦战 |
| 转账备注写清用途（如"婚前个人财产出资"） | 事后补不了 |
| 不要用婚后工资、家庭共同账户给公司追加出资 | 会让"个人股份"掺进共同成分 |

> **混同是最大的敌人。** 钱的路径越干净，将来争议越小——这对双方都是保护，不是单方面占便宜。

### 3. 婚前财产协议：谈的时机比内容更重要

**什么时候谈？** 在讨论婚礼细节之前，趁感情稳定、双方理性时谈。临到婚礼前一周提，谁都会觉得被算计。

**怎么开口（可直接用的说法）：**

> "我看过一些朋友的事，两个人感情很好，但因为钱没说明白最后很难看。我想我们先把各自婚前的东西、以后怎么管钱写清楚——**不是防你，是因为我希望我们将来吵架的时候，吵的只有感情，不用吵钱。**"

**合法有效的三个要点：**

1. **必须书面**（《民法典》第 1065 条：夫妻财产约定应当采用书面形式）。
2. **双方自愿、没有胁迫**，各留一份原件。
3. **不能约定违法内容**：不能免除对子女的抚养义务、不能约定"债务由一方承担"来对抗善意债权人（对内有约束力，对外不能对抗）。
4. 建议**公证**：公证不是生效条件，但能大幅降低将来"这是被逼签的"这类争辩空间，也便于银行/登记机构认可。

**协议里可以写什么：**

- 婚前各自财产（房产、股权、存款、投资）归各自所有
- 婚前财产的**婚后收益**（含股权分红、增值）归谁
- 婚后收入是否分开管理、家庭支出怎么分摊
- 房屋登记、还贷、装修的出资与权属
- 一方经营公司产生的债务，由谁承担（**对内有约束力**）
- 一方丧失行为能力时的监护安排（也可另做"意定监护"，见 [07-家庭应急与身后安排](07-家庭应急与身后安排.md)）

## 三、已经结婚了怎么办：四个补救动作

错过了婚前，不代表没有空间。以下按"最容易做 → 最需要专业协助"排序。

### 动作 1：盘一次家底，做一张"资产与权属表"（本周就能做）

| 资产 | 登记在谁名下 | 出资来源 | 取得时间（婚前/婚后） | 是否共有 | 备注 |
|---|---|---|---|---|---|
| 公司股权 | | | | | |
| 房产 | | | | | |
| 存款/理财 | | | | | |
| 保险 | | | | | 看**受益人**写的是谁 |
| 车辆 | | | | | |

**这张表有三个用途**：① 你自己心里有数；② 出事时家人能接手（见 [07](07-家庭应急与身后安排.md)）；③ 谈任何安排时的共同事实基础。

### 动作 2：婚内财产协议（现在就能签）

婚后同样可以书面约定财产归属（《民法典》第 1065 条），效果和婚前协议类似。

**注意两点：**
- 约定"婚后各自收入归各自"这类内容，会实质改变家庭财务结构，**务必双方自愿**，且建议同时约定好家庭共同开支怎么承担，否则容易变成新矛盾的起点。
- 如果**主要目的是逃避公司债务**，这种约定对债权人无效，且可能被认定为恶意逃债（见 §六）。

### 动作 3：把股权放在"结构"里，而不是放在"个人名下打架"

规模上来之后，常见的合法安排是：

| 做法 | 作用 |
|---|---|
| **持股平台 / 有限合伙** | 你作为普通合伙人掌握表决权，家人作为有限合伙人只享收益——**收益可以给，控制权不分** |
| **公司章程约定** | 约定股东资格继承限制、股权转让条件（见 §五） |
| **配偶同意函 / 财产约定确认** | 在融资、股权转让时，投资人常要求配偶书面确认对股权不主张权利。**看得懂再签**，见 §四 |
| **保单指定受益人** | 保险金在指定受益人的情形下**不作为遗产**，是很干净的定向给付工具 |

> 这类安排的价值不在"省税"，而在**把"不确定"变成"写清楚"**。等公司值钱了再来做，谈判成本要高十倍。

### 动作 4：家庭安全垫与公司资产切割

让配偶安心的最有效方式，往往不是股份，而是**一笔在公司之外的、看得见的安全垫**（6–12 个月家庭生活费，见 [01](01-家庭与健康规划.md) §一.1）。

**这笔钱的作用**：公司出事时家里不断粮 → 配偶不必把公司股权当"唯一保障" → 矛盾从"分股份"变成"活下去"，性质完全不同。

## 四、关于融资时的"配偶同意函"：别签得不明不白

公司融资时，投资人（尤其机构）常要求创始人配偶签署一份**同意函 / 确认函**。目的是：确认配偶知晓并同意股权相关的处置安排，避免将来婚变影响公司控制权。

**签名之前，至少确认四件事：**

1. **它约束的是什么**：是对"已持有的股份"确认不主张权利，还是包含**未来的股权处置、回购、质押**也要一并同意？
2. **有没有连带责任**：确认函里是否出现"担保""差额补足""共同承担"这类字样——**一旦出现，性质就变了**，可能让你家背上公司债务。
3. **有没有放弃家庭财产**：有些版本会写"放弃对公司及其关联方的一切权利主张"，措辞宽，可能顺带放弃了对家庭其他资产的主张。
4. **能不能加一句**：可以要求加"**本函不影响双方对家庭共同财产的其他安排，亦不构成对家庭安全垫资产的处分**"。机构通常可以接受这种限定。

> **如果对方催你"赶紧签、模板都是这样"——那就更应该看。** 一份文件的价值和它出现的场景成反比：越是"来不及看"的时候签的，代价越大。

## 五、最坏的情况：离婚会怎么冲击公司

先给一句实话：**公司不会因为离婚而"自动分掉"，但控制权可能丢、决策可能被拖死。**

### 1. 如果配偶要求分股份，实务上三种走向

| 走向 | 条件 | 结果 |
|---|---|---|
| **折价补偿**（创业者最优） | 双方协商，由你把股份对应的价值折成钱支付 | 股份完整保留在你名下，公司结构不变 |
| **转让股份给配偶** | 需**其他股东过半数同意，且放弃优先购买权** | 公司多出一个股东；若没有这个同意，法院一般不支持直接转让 |
| **配偶本来就是股东** | 无需征求他人同意 | 直接按共有份额处理 |

**要点：** 大多数情况下法院倾向于"**股份判给原持股方、由持股方给对方折价补偿**"，而不是把股权硬拆给非股东配偶。**但前提是你能拿出现金。** —— 这就是为什么 §三.4 的"家庭安全垫"和公司之外的流动性，其实是**保护公司控制权的工具**。

### 2. 其他连带影响

- **转让/变更登记**：股权变动要办工商变更，期间公司融资、投标、开户可能受阻。
- **限高与被执行**：若涉及个人债务或补偿款执行，法定代表人可能被限制高消费（见 [04](04-家人参与生意的边界.md) §三.1）。
- **公章与证照争夺**：一旦进入诉讼，常见的动作是"抢公章、换法人"。**平时就把证照印章的保管和使用登记做好**，是最好的预防。
- **员工与客户的信心**：创始人婚变上新闻，客户和员工会慌。**对外统一一句话**："个人家事已依法处理，公司经营与股权结构不受影响。"（对外沟通方法见 [公司/12-危机与客诉应对](../公司/12-危机与客诉应对.md)）

### 3. 抚养费的一个数量级参考

有子女的，不直接抚养方一般按其**月收入的 20%–30%** 支付抚养费；负担两个以上子女的，一般不超过 **50%**。收入不固定的，参照当地实际生活水平与孩子的合理需要确定。

> 关键词是"**收入**"——这也是为什么把个人收入、家庭支出、公司账户彻底分开，是长期要守的纪律。

## 六、财产隔离的正确做法 vs 恶意转移（这条线不能越）

很多人在公司出事前，想把资产"转到配偶名下""过户给父母"来避险。**这一步踩错，会把一个民事纠纷变成更严重的后果。**

| | ✅ 合法安排（事前做） | ❌ 恶意转移（事后做） |
|---|---|---|
| **时机** | 在债务发生**之前**，基于正常的家庭安排 | 在已被追债、进入诉讼或执行**之后** |
| **方式** | 婚前/婚内财产协议；公司章程约定；持股平台；保险受益人；正常价格的转让 | 无偿赠与、明显低价转让、假离婚、"以物抵债"的虚假安排 |
| **结果** | 受法律保护 | 债权人可请求**撤销**；离婚分割时可能**少分或不分**；情节严重可能涉刑 |

**一句话记法：**

> **在没出事的时候安排，叫"规划"；在出事的时候安排，叫"转移"。**
> 时间点决定性质，这是唯一的分水岭。

## 七、还可以提前想的两件"身后"的事（别跳过）

婚姻与继承是连着的。这两件事十分钟能想明白，但如果没想，家人要用几年去收拾：

1. **保单受益人写谁、写清了没有**。指定受益人的保险金**不作为遗产**，直接给受益人，不参与遗产分配、不用先还债。若没指定或受益人先身故，保险金才回到遗产里。（配合 [01](01-家庭与健康规划.md) §一.2 的"每年保单体检"：收入变了、婚育变了、离婚了，都要重看一眼受益人。）
2. **遗嘱与配偶的法定继承份额怎么衔接**。配偶是第一顺序法定继承人——**你写了一份把全部财产留给父母的遗嘱，配偶依然可能主张其应得的份额（尤其涉及夫妻共同财产中属于她的那一半）。** 遗嘱只能处分"你自己的那部分"。细节见 [07-家庭应急与身后安排](07-家庭应急与身后安排.md) §五。
