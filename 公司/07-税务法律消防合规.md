## 一、税务合规（每月/每季都别漏）

### 1.1 必办 5 件事（注册后立即做）

| # | 事项 | 在哪做 | 何时 |
|---|------|--------|------|
| 1 | **税种核定** | 电子税务局 → 企业开办 → 税种核定 | 注册后 30 天内 |
| 2 | **办理财务会计制度备案** | 电子税务局 | 注册后 30 天内 |
| 3 | **领 UKey / 税控盘** | 税务局服务厅或邮寄 | 报税前 |
| 4 | **签"三方协议"** | 电子税务局 + 银行 + 税务 | 注册后 30 天内 |
| 5 | **建账**（自建或找代账）| 自己 / 代账公司 | 注册后 15 天内 |

### 1.2 主要税种速查（小规模纳税人版）

| 税种 | 申报频率 | 申报时间 | 计税方式 | 常见税率 |
|------|----------|----------|----------|----------|
| **增值税** | 月/季 | 次月/季 15 日前 | 小规模：简易计税 3%（季度免征额 30 万）| 3% |
| **增值税附加** | 月/季 | 与增值税同步 | 增值税 × 12% 左右（城建 7%+教育 3%+地方教育 2%）| — |
| **企业所得税** | 季（预缴）+ 年（汇算）| 季：次季 15 日前；年：次年 5.31 前 | 查账征收按利润；小微优惠税率 | 5–25% |
| **个人所得税（工资）** | 月 | 次月 15 日前 | 累计预扣法 | 3–45% |
| **个人所得税（经营所得）** | 季/年 | 季：次季 15 日前；年：次年 3.31 前 | 个体户/个人独资企业 | 5–35% |
| **印花税** | 季/年 | 按季申报 | 购销/合同/资金账簿等 | 0.03%–1% |
| **残保金** | 年 | 各地不同 | 按上年职工人数 | 浮动 |

### 1.3 小规模 vs 一般纳税人（怎么选）

| 维度 | 小规模纳税人 | 一般纳税人 |
|------|--------------|------------|
| **标准** | 年应税销售额 ≤ 500 万 | 年应税销售额 > 500 万（可主动登记）|
| **税率** | 简易 3%（季度免征额 30 万）| 6/9/13% |
| **发票** | 只能开普票 | 可开专票（客户可抵扣）|
| **进项抵扣** | 不能 | 可以（专票认证抵扣）|
| **会计** | 简单（多数代账公司 200–500 元/月搞定）| 复杂（500–1,500 元/月）|
| **何时选** | 初创、客户不需专票 | 大客户要求专票、行业普遍专票 |

> **起步建议**：先小规模（多数创业公司），等客户要专票/营收过 500 万再转一般。

### 1.4 零申报也要报（99% 新手踩过的坑）

- **没有收入、没开发票**也要每月/每季在电子税务局点击"申报"——逾期一天罚款 50 元起 + 影响纳税信用。
- **连续 3 个月零申报**：会被系统"关注"，但**不违规**；连续 6 个月则可能触发稽查。
- **怎么办**：每月登录电子税务局 → 申报 → 填 0 → 提交。**整个过程 2 分钟**。

### 1.5 报税实操路径（电子税务局）

```
登录 https://shenzhen.chinatax.gov.cn/
  → 我要办税 → 税费申报及缴纳
    → 增值税及附加 → 季度申报（按月类推）
      → 填表（销项/进项/免税额）
        → 提交 → 三方协议自动扣款
```

- **首次登录**：用法人或财务负责人身份证 + 密码；忘记密码用"找回"。
- **找不到入口**：直接打 12366 纳税服务热线咨询。

### 1.6 发票管理红线

| 红线 | 后果 |
|------|------|
| **虚开发票**（为他人/为自己/让他人为自己/介绍他人虚开）| **最高无期徒刑** + 5 倍罚款 + 没收违法所得 |
| 买发票抵成本 | 同虚开 + 信用黑名单 |
| 与实际业务不符（品名/金额/购货方）| 偷税 + 罚款 + 滞纳金 |
| 大额不开票（私户收款不报税）| 偷税 + 罚款 + 刑事风险 |
| 发票丢失 | 登报声明 + 税局报备 + 罚款 50–500 元/份 |

> **原则**：业务真实，发票与合同/物流/资金**四流一致**——这是底线。

### 1.7 常见税务优惠（白送的钱，不申白不申）

| 优惠 | 适用 | 大概省多少 |
|------|------|-----------|
| **小规模季度免征额 30 万** | 月均 ≤ 10 万 | 增值税全免 |
| **小微企业所得税优惠**（100 万以下 5%、100–300 万 5%）| 年利润 ≤ 300 万 | 所得税大幅减免 |
| **小规模附加税减半** | 小规模 | 附加税减半 |
| **研发费用加计扣除** | 有研发活动的企业 | 研发费用 × 100% 加计抵扣 |
| **残疾人工资加计扣除** | 雇佣残疾人 | 工资 × 100% 加计抵扣 |
| **小微企业社保减免** | 小微 | 阶段性政策（看当年）|

> **注意**：政策每年会变，**以申报时电子税务局提示 + 当地税局公告为准**。

## 二、法律与劳动

### 2.1 劳动合同（入职 1 个月内必须签）

| 必含条款 | 注意点 |
|----------|--------|
| **双方信息**（姓名/身份证/地址）| 与身份证一致 |
| **合同期限**（固定期限/无固定期限/以完成一定工作任务为期限）| ≥3 次续签可申请无固定期 |
| **工作内容与地点** | 模糊条款 → 后续调岗扯皮 |
| **工时制度**（标准/综合/不定时）| 不定时需劳动局审批 |
| **工资构成与发放日** | 写清基本工资 + 绩效 + 各类补贴 |
| **试用期** | 1 年合同 ≤1 月；1–3 年 ≤2 月；3 年以上/无固定期 ≤6 月；试用期工资 ≥ 转正 80% |
| **社保公积金** | 公司依法缴纳 |

- **超 1 个月未签**：每月支付**二倍工资**，最多 11 个月。
- **没签合同的"事实劳动关系"也算**——别心存侥幸。
- **标准模板**：深圳市人力资源保障局官网搜索"劳动合同范本"下载（每年更新）。
- **条款片段**：见 [附录/05-可直接抄写的模板样张](../附录/05-可直接抄写的模板样张.md) §3。

### 2.2 试用期六大红线

| # | 红线 | 法律后果 |
|---|------|----------|
| 1 | 试用期不签合同 | 二倍工资 |
| 2 | 试用期不缴社保 | 补缴 + 滞纳金 + 罚款 |
| 3 | 试用期工资 < 转正 80% | 补差 + 赔偿 |
| 4 | 试用期超过法定上限 | 视为已转正，超期工资按转正 |
| 5 | 试用期随意辞退 | 违法解除 = 2N 赔偿 |
| 6 | 试用期单独签合同 | 视为正式合同，试用期不成立 |

### 2.3 辞退流程与补偿（N/N+1/2N 计算）

| 辞退情形 | 补偿 |
|----------|------|
| **协商解除** | N（双方谈，通常 ≥N）|
| **员工不胜任**经培训/调岗仍不胜任 | N+1（提前 30 日通知或代通知金）|
| **经济性裁员**（需符合法定情形）| N |
| **违法解除**（公司无合法理由）| **2N** |
| **员工主动辞职** | 0 |
| **员工严重违纪**（公司可单方解除）| 0（但需证据链充分）|

> **N 的计算**：工作每满 1 年 = 1 个月工资；不满半年 = 0.5 个月；6 个月–1 年 = 1 个月。
> **月工资**：辞退前 12 个月平均工资（含奖金/津贴/补贴），不超过当地社平工资 3 倍封顶。

### 2.4 规章制度（成文 + 公示 = 争议时公司武器）

- **必备制度**：考勤、请假、加班、报销、绩效考核、保密、奖惩、信息安全。
- **三步生效**：
  1. **民主程序**：经职工代表/全体职工讨论，提出方案和意见。
  2. **公示程序**：员工手册签收、邮件全员发送、公告栏张贴（保留照片/邮件截图）。
  3. **报送程序**：部分行业需报劳动部门备案。
- **争议处理**：员工违反制度的，公司可依据规章制度处理——但**前提是制度本身合法 + 经过公示**。

### 2.5 知识产权

| 类别 | 谁申请 | 时机 | 费用参考 |
|------|--------|------|----------|
| **商标** | 公司 | 品牌定型后尽早 | 官费 300 元/类 + 代理 500–1,000 元/类 |
| **著作权** | 公司 | 作品完成即自动产生，登记可举证 | 官费 100–300 元/件 |
| **软件著作权** | 公司/员工 | 代码完成即自动，登记可举证 | 官费 100–500 元/件 |
| **专利** | 公司 | 技术方案完成后 | 发明 900 元 + 实审 2,500 元；实用新型 500 元；外观 500 元 |

> **关键**：员工在职期间完成的与本职工作相关的成果，**归属公司**——必须签"职务作品协议"（参考 [附录/05 劳动合同补充协议](../附录/05-可直接抄写的模板样张.md)）。

### 2.6 数据与隐私（《个人信息保护法》核心要求）

- **最小必要**：只采集业务需要的字段，不"为以后用"过度收集。
- **知情同意**：采集时告知目的、方式、范围；用户拒绝时不能强制。
- **存储安全**：加密 + 访问控制 + 操作日志。
- **删除权**：用户要求删除，30 天内响应。
- **数据跨境**：确需时做 PIPL 安全评估或签标准合同。
- **处罚上限**：5,000 万元或上年营收 5%；严重者吊销许可。

## 三、消防与办公安全（很多人忽略，出事就是大事）

### 3.1 基础消防配置清单（所有办公场所必查）

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 灭火器 | 在有效期（看压力表指针在绿区）、数量/位置符合面积 |
| 2 | 疏散通道 | 畅通无锁、无堆物、宽度 ≥ 1.4m |
| 3 | 应急照明 | 断电自动亮、电池有电 |
| 4 | 疏散指示标志 | 可见、指向正确 |
| 5 | 安全出口 | ≥2 个、标识清楚、不上锁（员工下班可推开）|
| 6 | 烟感/喷淋（按面积）| 高层/大面积必装 |
| 7 | 消防栓/水带 | 高层/大面积必装 |

### 3.2 用电安全（小公司最容易出问题）

- ❌ **不私拉乱接**：插座不够用时找电工规范加装。
- ❌ **不超负荷**：大功率电器（空调/烤箱/电热水器）单独走专线。
- ❌ **下班断电**：非 24h 设备下班拔插头。
- ❌ **不堆易燃物**：纸箱/纸张/泡沫远离电源。

### 3.3 行业专项要求

| 行业 | 专项 | 检查方 |
|------|------|--------|
| **餐饮** | 厨房自动灭火、燃气泄漏报警、油烟管道定期清洗 | 消防 + 市场监管 |
| **仓储** | 易燃物分区、消防通道、防爆灯 | 消防 |
| **生产** | 设备安全防护、劳保用品、特种设备年检 | 应急管理 + 市场监管 |
| **住宿/酒店** | 每房间独立疏散、烟感、自动喷淋 | 消防 |
| **学校/培训** | 学员安全、紧急疏散预案 | 消防 + 教育 |
| **电商仓库** | 同仓储；锂电池单独存放 | 消防 |

### 3.4 年度消防自查（每年至少 1 次）

```
【第 X 年 · 消防自查】
□ 灭火器数量/有效期
□ 疏散通道畅通
□ 应急照明/疏散指示可用
□ 安全出口标识
□ 用电规范（无私拉乱接）
□ 易燃物分类存放
□ 员工消防培训（每年 ≥1 次）
□ 应急疏散演练（每年 ≥1 次桌面演练）
```

### 3.5 员工安全（生产/现场作业行业必看）

- **劳保用品**：根据岗位配发（安全帽/防护眼镜/防护鞋/手套等）。
- **雇主责任险 / 团体意外险**：所有行业都建议买——员工工伤时除了工伤保险，多一道赔付。
- **特种作业人员**：电工/焊工/高处作业等需持证上岗。

## 四、年报与其他周期事项

### 4.1 工商年报（每年 1.1–6.30）

- **入口**：国家企业信用信息公示系统 https://www.gsxt.gov.cn/
- **内容**：股东信息、资产状况、社保人数、是否有对外投资等。
- **不报后果**：列入**经营异常名录**→ 满 3 年未移出 → 严重违法失信名单（"老赖"）→ 影响贷款/投标/平台入驻。

### 4.2 企业所得税汇算清缴（次年 5.31 前）

- **入口**：电子税务局 → 汇算清缴。
- **对象**：查账征收的企业所得税纳税人（核定征收的按季预缴不汇算）。
- **准备材料**：年度财务报表、纳税调整项目、发票抵扣清单、资产损失清单等。
- **简化版**：营收 300 万以下、小型微利企业可走"简化申报"——大部分字段自动带出。

### 4.3 资质证照（按行业办理）

| 行业 | 资质 | 主管部门 |
|------|------|----------|
| 食品经营（餐饮/零售/批发） | 食品经营许可证 | 市场监管 |
| 餐饮服务 | 食品经营许可证 + 食品安全等级 | 市场监管 |
| 互联网信息服务 | ICP 备案 / ICP 证（经营）| 工信部 |
| 在线交易/电商 | EDI 证（第三方平台）| 工信部 |
| 进出口 | 进出口经营权 + 海关备案 | 海关 + 商务 |
| 医疗器械 | 医疗器械经营许可/备案 | 药监 |
| 药品 | 药品经营许可证 | 药监 |
| 教育培训 | 办学许可证 / 备案 | 教育 |
| 道路运输 | 道路运输许可证 | 交通 |
| 危险化学品 | 危化品经营许可证 | 应急 |
| 人力资源 | 人力资源服务许可证 | 人社 |
| 印刷 | 印刷经营许可证 | 出版 |

> **共性原则**：**先办证后经营**——无证经营罚款起步 5 万，情节严重吊销执照。

### 4.4 银行账户年检

- **基本户**每年做年检/对账（多数银行自动完成，但需你确认）。
- **长期不用账户**可能被冻结（久悬户）→ 激活需重新尽调 + 提供资料。
- **销户**：长期不用的账户及时销户，避免管理费累计 + 风险敞口。

### 4.5 印章备案与年检

- **公章/财务章/法人章/发票章/合同章**：公安备案 + 工商备案。
- **外企/合资企业**：印章需中英文并列 + 备案。
- **变更/重刻**：公司名称变更需重刻全套印章；遗失需登报声明作废 + 重新刻制。

## 五、一年合规节奏总表（建议打印贴办公位）

| 频率 | 事项 | 截止 | 漏了的后果 |
|------|------|------|-----------|
| **每月** | 增值税及附加申报 | 次月 15 日 | 罚款 50 起 + 滞纳金 |
| **每月** | 个税代扣代缴（工资）| 次月 15 日 | 同上 |
| **每月** | 社保缴纳 | 次月底前（各地不同）| 滞纳金 + 影响员工权益 |
| **每季** | 企业所得税预缴（小规模季报）| 次季 15 日 | 同上 |
| **每季** | 印花税申报 | 次季 15 日 | 同上 |
| **每年** | 工商年报 | 6.30 | 经营异常名录 |
| **每年** | 企业所得税汇算清缴 | 次年 5.31 | 罚款 + 滞纳金 |
| **每年** | 残保金申报 | 各地不同（多数 9 月）| 罚款 |
| **每年** | 消防自查 | 全年 | 隐患累积 |
| **每年** | 资质年检 | 按行业 | 资质过期 |
| **持续** | 合同/制度体检 | 滚动 | 风险累积 |

> **设置日历**：把上述事项设成"年度重复提醒"，提前 3 天再设一次。

## 六、出错了怎么办（应急响应）

| 情况 | 紧急度 | 立即做 | 后续 |
|------|--------|--------|------|
| **报税逾期** | 高 | 立即补报 + 缴滞纳金（每日万分之五）| 申请信用修复（首违不罚可能）|
| **发票丢失** | 中 | 登报声明 + 税局报备 | 罚款 50–500 元/份 |
| **员工工伤** | 极高 | 立即送医 + 24h 内报社保 | 工伤认定 + 待遇申领 |
| **被税务稽查** | 极高 | 配合 + 如实 + 不卑不亢；**重大事项立即找律师** | 补税 + 滞纳金 + 罚款（必要时）|
| **被工商稽查** | 高 | 同上 + 准备合同/章程/股东会决议 | 整改 + 罚款（必要时）|
| **火灾** | 极高 | 报警 119 + 疏散 + 灭火（初期）| 配合调查 + 整改 + 通报 |
| **数据泄露** | 极高 | 切断 + 评估范围 + 72h 通报监管 + 用户告知 | 整改 + 罚款 + 民事赔偿 |
