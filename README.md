## 0. 先想清楚的 3 件事

| 问题 | 说明 |
|------|------|
| **为什么开公司？** | 业务需要、签合同、开发票、隔离个人风险、融资/招标等 |
| **开哪种类型？** | 绝大多数人选「有限责任公司」——股东以出资额为限承担责任 |
| **自己办还是代办？** | 深圳全程可线上「开办企业一窗通」自己办（免费）；怕麻烦可找财税代办（几百~上千）|

---

## 1. 公司类型怎么选

| 类型 | 责任 | 适合 |
|------|------|------|
| **有限责任公司（有限公司）** | 有限责任，风险隔离 ✅ | 绝大多数创业、接业务、开票 |
| 个体工商户 | 无限责任（个人承担） | 小本经营、无固定团队 |
| 个人独资企业 | 无限责任 | 个人品牌、工作室 |
| 合伙企业 | 普通合伙无限 / 有限合伙有限 | 投资、律所、基金 |
| 股份有限公司 | 有限责任，可募股 | 拟上市、规模较大 |

**建议**：首次创业、要签合同/开发票/招聘 → 选**有限责任公司**。

## 2. 注册前要确定 6 个核心要素

1. **公司名称**：`深圳 + 字号 + 行业 + 有限公司`
   - 例：`深圳市云启科技有限公司`
   - 准备 **3–5 个备选字号**（核名可能重名），避免用禁用/限用字。
2. **注册资本**：认缴制，但 **2024-07-01 施行的新《公司法》要求 5 年内实缴**（自成立之日起 5 年内缴足；2024-06-30 前注册的老公司有过渡期，最晚 2032-06-30 前调整到位）。
   - 写合理金额：**试水 10 万–50 万、需投标/资质 100 万–500 万**，够用就好。写太大 = 5 年内真要掏钱 + 承担更大责任；写太小可能影响客户/平台门槛。
   - ⚠️ 公司欠债时，未实缴部分可被债权人要求「加速到期」提前缴纳，认缴期限不能对抗债权人。
3. **经营范围**：主营 + 兼营，参考《国民经济行业分类》。
   - 可后期变更，但主营影响税种和资质。
4. **注册地址**：
   - 自有/租赁商用地址；或深圳**挂靠地址 / 孵化器 / 前海**政策地址。
   - 地址异常会被列入「经营异常名录」，务必真实可联系。
5. **人员架构**（至少 2 人）：
   - 法定代表人（老板/总经理）、股东、监事、**财务负责人**。
   - ⚠️ 法人 **不能** 兼任监事，需另设一人。
6. **股权结构**：股东出资比例；**避免「股权平均」**（50:50、各 1/3）导致决策僵局。认缴期限按新法最长 5 年。
7. **股东协议**：即便亲友合伙也要**书面约定**——出资金额、分工、决策机制、退出方式、竞业限制、知识产权归属。

## 3. 注册流程（深圳，全程线上「开办企业一窗通」）

```text
名称自主申报 → 设立登记 → 实名认证 → 领取执照 → 刻章 → 银行开户 → 税务报到 → 社保/公积金开户
```

| 步骤 | 做什么 | 渠道 | 耗时 |
|------|--------|------|------|
| 1. 名称申报 | 在线核名、备选字号 | 深圳市市场监督管理局「开办企业一窗通」 | 即时 |
| 2. 设立登记 | 填股东/章程/任职，提交 | 同上（一网通办） | 1–3 工作日 |
| 3. 实名认证 | 全体人员人脸/身份验证 | 「登记注册身份验证」APP 或微信小程序 | 当天 |
| 4. 领执照 | 审核通过领电子+纸质营业执照 | 一窗通 / 政务短信 | 当天 |
| 5. 刻章 | 公章、财务章、法人章、发票章、合同章 | 公安备案刻章点（深圳新设常免费） | 当天 |
| 6. 银行开户 | 开立**基本存款账户** | 各商业银行（需预约、法人在场） | 1–2 周 |
| 7. 税务报到 | 税种核定、票种核定、选小规模/一般纳税人 | 电子税务局 | 当天 |
| 8. 社保/公积金 | 单位开户、增员 | 社保局 / 公积金中心（线上） | 当天 |

> 深圳支持「一窗通」一次办完设立+刻章+税务+社保+公积金，材料齐可同日出照。

## 4. 注册后必做的合规（避免异常）

- ✅ **记账报税**：无论是否经营、是否零收入，都要**按月/季申报**（零申报也要报）。
- ✅ **工商年报**：每年 **1 月 1 日 – 6 月 30 日** 报送上一年度年报，逾期列异。
- ✅ **发票与税务合规**：开票、抵扣、留抵按规定来，别买发票。
- ✅ **银行账户**：基本户用于收付款、缴税；长期不用可能被冻结。
- ✅ **社保公积金**：有员工必须依法缴纳。

## 5. 成本大致估算（深圳，2026 年参考）

| 项目 | 费用 |
|------|------|
| 工商注册 | **0 元**（政府不收费） |
| 挂靠/孵化器地址 | 约 1,000–3,000 元/年（如无需实际地址） |
| 刻章 | 新设企业常**免费**或几百元 |
| 银行开户 | 0–几百元（各行不同） |
| 代理记账 | 小规模约 200–500 元/月 |
| 注册资本 | 认缴，**不立即掏现金** |

> 自己办几乎「零成本」；怕麻烦找代办主要花在记账和地址上。

## 6. 常见坑

- ❌ 法人兼任监事 → 不允许，需另设监事。
- ❌ 认为「没业务就不报税」→ 零申报也要报，否则列异+罚款。
- ❌ 注册地址填虚假/失联 → 列入经营异常名录，影响信用。
- ❌ 注册资本瞎写 1 个亿 → 5 年内真要实缴 + 承担更大责任。
- ❌ 用个人卡收公司款 → 公私混同，可能被「揭开公司面纱」承担无限连带责任。
- ❌ **股权平均（50:50 / 33:33:34）** → 决策僵局、公司内耗。
- ❌ 不签劳动合同 → 员工入职超 1 个月未签有双倍工资风险。
- ❌ 忽视商标 → 品牌做起来才发现被抢注。
- ❌ 过早租大办公室/招很多人 → 固定成本过高、现金流紧张。
- ❌ 给亲友做贷款担保 / 轻易合伙 → 易成「提款机」或决策变形。

---

## 7. 推荐时间线

```text
第 1 天：确定名称/注册资本/范围/地址/人员
第 1–3 天：一窗通提交设立 + 实名认证 → 出执照
第 3 天：刻章
第 1–2 周：银行开户
第 2 周：税务报到、社保公积金开户
持续：记账报税 + 次年 6 月前年报
```
