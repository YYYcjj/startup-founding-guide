## 一、验证需求：先有人付钱，再租办公室

### 1.1 验证 vs 假设

| 状态 | 含义 | 你该怎么做 |
|------|------|-----------|
| **假设** | "我觉得有人会买" | 还不算需求，只是猜测 |
| **信号** | "有人问、有人收藏、有人转发" | 弱信号，进一步验证 |
| **付费** | "有人实际付了钱" | **唯一硬指标** |
| **复购** | "同一客户多次付钱" | 真需求 |
| **转介绍** | "客户主动介绍别人来" | 真口碑 |

> **判据**：≥3 个客户、付费（哪怕小单）→ 才算"需求成立"。3 个都没有 = 还在猜。

### 1.2 验证四步法（1–3 个月）

1. **找 20 个目标客户聊**（不是"问卷"，是 1v1 通话/面聊，30 分钟/人）：
   - 现在怎么解决这个问题？
   - 这个方案你愿意付多少钱？
   - 如果有 X 服务你会不会买？
   - 不买的最大原因是什么？
2. **做最小产品/服务**（MVP）：能交付最小价值的最简形态——一页落地页、一段演示视频、一个朋友圈广告、一个手工 Excel、一个朋友私厨餐会……**别一上来写完整 App**。
3. **以"创始客户价"卖出去**（前 5 个客户大幅折扣甚至免费换"案例+反馈"）：拿到钱 + 拿到证言 + 拿到改进建议。
4. **看三个信号**：
   - 付了钱（哪怕 9.9 元）
   - 主动复购/续费
   - 转介绍给朋友
   - 三个里出现 1 个 = 方向可继续；都没有 = 调方向。

### 1.3 创始客户（design partner）怎么找

- 你朋友圈/老同事里最贴近目标画像的 20 人。
- 行业垂直社群（豆瓣小组、知识星球、微信群）发"招募创始客户"贴。
- 朋友介绍朋友——**比广告便宜 100 倍**。
- 不愿付钱的客户 → 大概率不是真客户；可以问"什么情况下你愿意付？"而不是直接送。

## 二、销售与获客：从"靠运气接单"到"流水线接单"

### 2.1 销售漏斗四步（每一步算转化率）

```
曝光 → 咨询 → 报价 → 成交 → 复购/转介绍
```

| 阶段 | 动作 | 转化率参考 |
|------|------|-----------|
| 曝光 | 让目标人群看到你（朋友圈/短视频/SEO/转介绍） | 触达成本 < 客户终身价值 1/10 |
| 咨询 | 客户主动咨询或你主动触达 | 咨询率 1–5% 是常态 |
| 报价 | 把需求整理成报价单/方案 | 报出价 30–60% 接到 |
| 成交 | 签合同 + 收定金 | 成交率 20–50% 算合格 |
| 复购/转介绍 | 让客户再买或介绍别人 | 健康业务：复购 + 转介绍 ≥ 30% |

> **核心原则**：每一步记数据——不知道转化率的"销售"是运气。**运气赚的钱不是钱**。

### 2.2 起步获客 6 路径（成本从低到高）

| 路径 | 成本 | 适合阶段 | 关键动作 |
|------|------|----------|----------|
| **熟人转介绍** | 0 | 任何阶段 | 每成交一个客户主动问"有朋友需要可以介绍" |
| **个人朋友圈/微信** | 0 | 起步 | 持续输出业务相关内容（每周 ≥1 条） |
| **垂直社群** | 几十–几千/年 | 起步 | 加入 1–2 个深度活跃群，先贡献后索取 |
| **内容输出（公众号/小红书/抖音/B站）** | 时间成本 | 起步–成长期 | 围绕客户最常问的问题写，一致性 > 爆款 |
| **搜索引擎/SEM** | 几千–几万/月 | 有稳定现金流后 | 关键词选品 + 落地页 A/B 测试 |
| **付费投放（信息流/抖音/小红书）** | 几千–几万/月 | 验证 ROI 后 | 小预算测试，跑通模型再放量 |

### 2.3 定价三种思路（阶段切换）

| 思路 | 怎么定 | 适合阶段 | 利润率 |
|------|--------|----------|--------|
| 成本加成 | 成本 × 1.5–3 | 早期没名气，保底 | 10–30% |
| 市场参照 | 看同行价取中上 | 有可比产品 | 20–40% |
| 价值定价 | 按"帮客户省/赚多少"分一份 | 客户算得清账 | 30–60% |

> **升级路径**：成本加成活下来 → 有案例后转价值定价。**别一直按成本卖——你会累死还穷**。
> 价值定价的关键：**让客户先看到"我能帮你赚/省多少"，再谈你收多少**——把价格变成"投资回报率"。

### 2.4 转介绍设计（让老客户主动介绍）

- **给好处**：返点 5–15% / 赠服务 / 优先排期——把人情的"不好意思"变成规则的"应该给"。
- **降低门槛**：给老客户一段"可转发的推荐话术"（不要让对方自己编）。
- **及时反馈**：被介绍来的客户成交了，立刻告诉介绍人"您的朋友 X 已经成交，谢谢您！"——正反馈循环。
- **每年一次"客户答谢"**：小礼物/茶歇/专属优惠——成本低、黏性强。

## 三、产品与交付：把"老板亲自做"变成"流程化做"

### 3.1 选拳头产品（先做深 1 个）

- 选**客户复购最多、毛利最高、你有相对优势**的那个产品/服务做深。
- 别同时铺 5 个方向——资源分散，每个都做不深；客户认知也模糊"你到底是干嘛的"。
- 拳头产品稳定后再扩第 2 个；扩的判断标准：第一个产品已标准化且有 1 人能独立交付。

### 3.2 交付 SOP 化（把"我脑子里的东西"写下来）

| 步骤 | 写什么 | 例子（设计服务） |
|------|--------|----------------|
| 接单 | 客户需求确认清单 | 风格、预算、时间、参考案例 |
| 启动 | 启动会议纪要 / 项目群 | 目标 + 节点 + 责任 |
| 执行 | 各阶段交付物标准 | 初稿/二稿/终稿/源文件 |
| 验收 | 验收清单 + 签字 | 客户逐项确认 |
| 售后 | 售后承诺 | 7 天修改/30 天咨询 |
| 复盘 | 项目复盘文档 | 耗时 / 卡点 / 客户反馈 |

> **SOP 写作心法**：写给"入职 1 个月的新人"看，他照着做能交出 80 分的活——做到就够用。

### 3.3 客户反馈循环（别让产品停在初版）

- **每月一次**：列出客户反馈 ≥5 条，按"功能改进 / 流程优化 / 体验细节"分类。
- **季度迭代**：选 1–2 个最高频的需求做进版本；其他进"未来考虑"清单。
- **原则**：客户愿付费的痛点 > 你觉得酷的功能。**别为了"完整"加一堆没人用的功能**。

## 四、现金流：公司的氧气（不是利润）

### 4.1 利润 ≠ 现金（核心认知）

- 利润是**权责发生制**（签了合同就算收入，不管钱到没到）。
- 现金是**收付实现制**（钱真到了基本户才算）。
- **账面赚 100 万、应收账款 90 万 = 你手里只有 10 万**——工资/货款/税照样要付。

### 4.2 12 周现金预测（每月底做一次）

**模板**（复制到表格）：

| 周次 | 期初余额 | 预计收款 | 预计付款 | 期末余额 | 备注 |
|------|----------|----------|----------|----------|------|
| 第 1 周 | | | | | |
| 第 2 周 | | | | | |
| ... | | | | | |
| 第 12 周 | | | | | |

- **预计收款**：按合同账期 + 历史回款率估算（保守打 7 折）。
- **预计付款**：固定支出（房租/工资/社保）+ 已知应付（货款/服务费/税）。
- **期末余额**：永远保持 ≥ 3 个月固定支出的安全垫；低于 1 个月 = 红色警报。

### 4.3 现金流断流的 5 大征兆（提前识别）

1. 客户账期越拖越长（>90 天）
2. 大客户欠款占应收 > 50%
3. 你开始用个人卡/朋友借款垫付公司款
4. 供应商开始要求"先款后货"
5. 工资发放开始"先发一半、月底补"

> 任一出现 = **立即砍非必要支出 + 加紧催收 + 考虑股东借款**——别等问题爆发再处理。

## 五、团队：前 5 人决定文化

### 5.1 招人三判断（满足才雇）

> 详细见 [09-招人与用人](09-招人与用人.md)，核心三判断先列这里：

1. **钱**：账上至少够发 TA 6 个月工资（含社保），且不伤家庭安全垫。
2. **事**：这件事你已亲手做过 ≥3 遍、能写成流程。
3. **标准**：TA 不来，你明确知道会损失什么（不是"忙不过来"，是"不做就丢客户/违约"）。

### 5.2 早期招什么人

- **多面手 > 螺丝钉**：能跨职能顶，比单一技能的人更扛事。
- **自驱 > 听话**：能自己找事做，比需要被管的省心 10 倍。
- **价值观合 > 能力强**：能力可以补，价值观不合改不动。

### 5.3 团队节奏（5 人以内够用）

| 动作 | 频率 | 目的 |
|------|------|------|
| 周一 15 分钟目标对齐 | 每周 | 本周 1 目标 + 3 件事 |
| 每周进度快照 | 每周 | 做了 / 卡在哪 / 下周做什么 |
| 一对一沟通 | 每 1–2 周 | 听卡点、给支持、聊状态 |
| 月复盘 | 每月 | 数据回顾 + 下月计划 |

## 六、融资：能不融就先不融

### 6.1 什么时候不用融

- 当前业务能自己造血（利润 > 支出）
- 增速合理（不需要烧钱换增长）
- 现金流健康（≥6 个月安全垫）

> **股权是公司最贵的资产**——融资是用你的"未来收益"换当下的钱；融多了回头看你会心疼。

### 6.2 什么时候考虑融

- 出现"窗口期"（不抢就错过）：政策红利、大客户合作窗口、品类快速爆发期。
- 模式已验证（已经有 1 个赚钱的小样本），需要钱复制。
- 现金流紧张但业务健康——拿钱续命，不是救命。

### 6.3 融资三步走（不踩坑）

1. **先估值**：找 3–5 个同行业近期融资案例，看可比估值；不要投资人"给多少就多少"。
2. **再对赌**：业绩对赌条款必须请律师过——目标要可达成，别签"翻倍式"赌约。
3. **后签 TS**（投资意向书）：TS 不是正式协议，但**估值、董事会席位、否决权、回购条款会带进正式协议**——TS 阶段就要认真看。

> 详细条款识别见 [个人与人际/01-商业关系 §4 投资人](../个人与人际/01-商业关系.md)。

## 七、增长误判速查（常见翻车模式）

| 误判 | 真相 | 后果 |
|------|------|------|
| "订单多 = 赚得多" | 可能在垫资 | 账上利润、现金为零 |
| 增长靠降价补贴 | 停补贴就没人 | 利润为负、用户无忠诚 |
| 大客户占比 > 50% | 丢一个就重伤 | 业绩大起大落 |
| 创始人只管业务不管钱 | 账乱到查不出 | 决策无依据、税务风险 |
| 拿新钱烧旧模式 | 没跑通就放大 | 加速死亡 |
| 招人来"显得正规" | 没事做 = 内耗 | 人心散、现金流伤 |
