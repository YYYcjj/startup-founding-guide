# 朋友与同学往来：同辈的边界，最难也最值得经营

> 🧭 板块：**家族 ②** ｜ ↩ [🏠 返回首页](../README.md) ｜ 总纲：[年轻创业者全攻略](../年轻创业者全攻略.md)
> 同板块：[01-家庭与健康规划](01-家庭与健康规划.md) ｜ [02-亲戚相处](02-亲戚相处.md)

> 定位：同学、发小、老友——**同辈关系里钱和情最容易混**，处理好了是人生资产，处理不好是长期内耗。
> 适用金钱原则同 [02-亲戚相处](02-亲戚相处.md)：救急不救穷、不帮懒、不担保、不轻易合伙。
> 本文把所有边界问题整理成**借钱三问 + 合伙前 5 问 + 关系维护 4 个动作 + 嫉妒应对 + 底线红线**。

---

## 1. 朋友借钱：先问三句

> 朋友开口借钱，最容易让关系破裂的不是"不借"，而是**借错的方式**。

### 1.1 必问三句（按顺序）

| # | 问题 | 你要的答案 |
|---|------|-----------|
| 1 | **借多少？** | 具体金额（不是"借点"） |
| 2 | **干什么用？** | 真实用途（医疗/教育/周转 vs 消费/还债/赌博）|
| 3 | **什么时候还？** | 还款计划（明确日期 + 方式）|

> 答不全 / 含糊其辞 = 警惕信号。
> 答得清晰 = 大概率是真需求。

### 1.2 决策表

| 维度 | 可借 | 慎借 / 不借 |
|------|------|-----------|
| **用途** | 生病/教育/突发 | 投资/还赌债/享乐/还他人 |
| **金额** | 你"送得起"的额度 | 超出承受范围 |
| **还款能力** | 有稳定收入/有资产 | 无业/月光 |
| **历史** | 借过按时还 | 借过没还/多次借 |
| **借的态度** | 主动说借款期限 | 反问"你还计较" / 暗示不还也行 |

### 1.3 借条必写的情形

> 朋友间不写借条 = 大概率出问题——**不是因为朋友坏，是人情会让双方都尴尬**。

**建议必写借条**：
- 金额 ≥ 5,000 元
- 借款期限 > 3 个月
- 朋友关系"非至亲"（铁哥们也要写）

**借条关键内容**：
- 借款金额（大小写）
- 用途（写"个人周转"或具体用途）
- 借款期限（明确日期）
- 还款方式（一次性 / 分期 / 利息）
- 违约责任（如逾期违约金比例）
- 借款人签字 + 身份证号 + 日期

> 完整模板见 [附录/05-可直接抄写的模板样张 §1 借条](../附录/05-可直接抄写的模板样张.md)。

### 1.4 催还钱（最难开口的话术）

| 阶段 | 语气 | 话术示例 |
|------|------|----------|
| **到期前 1 周**（提醒） | 友好 | 「XX，那笔借款下周到期，您那边准备得怎么样了？」 |
| **逾期 1 周**（温和提醒） | 关心 | 「不好意思问一下，XX 那笔您那边方便了吗？有什么卡住的地方吗？」 |
| **逾期 1 月**（正式） | 坚定但不伤 | 「XX，借款已经逾期一个月了，我这边也有自己的安排，希望您本周内能给个明确的还款计划。」 |
| **逾期 3 月+**（书面） | 严肃 | 发微信/短信：「XX，借款已逾期 X 个月，我有权通过法律途径追讨。请您在 X 日前还款，否则我将 [采取法律行动/起诉]。」 |
| **拒不还钱** | 留证据 | 必要时起诉（小额诉讼程序简单，费用低），同时**放弃这个朋友**——不还钱的朋友不值得交。 |

> **原则**：借钱时就把"催还"当作会发生的事——**先小人后君子**才是对朋友最好的保护。

## 2. 朋友想合伙 / 拉你投资

### 2.1 谈钱伤感情是假命题

> **不谈清楚才伤感情**——感情破裂通常是因为"想当然"和"没说清"。

### 2.2 合伙前必问 5 个问题

1. **做什么**？——清晰描述业务（不是"我在搞个大项目"）。
2. **你出资多少**？——他要出钱还是只想让你出钱？
3. **怎么分钱**？——有没有数字 + 时间表？
4. **多久能回本**？——他对预期有理性判断吗？
5. **亏了怎么办**？——他有没有考虑过这个问题？

> 答不出 3 个以上 = 还不够成熟；答得清晰 + 自己也投资 = 可以往下谈。

### 2.3 被拉去"跟着投"怎么办

| 信号 | 决策 |
|------|------|
| 他自己没出钱，只让你出 | 不投（**他不投钱，凭什么叫你投**） |
| 商业计划模糊，承诺高回报 | 不投（**讲不清怎么赚钱的，通常不赚钱**） |
| 催你"赶紧打钱，错过就没" | 不投（**制造紧迫感是收割的前置**） |
| 项目你不熟、不懂 | 不投（**只投看得懂的**） |
| 让你"借你账户/身份证走账" | 不参与（**违法**） |

### 2.4 合伙的 5 个必谈（具体协议内容）

1. 出资与股权
2. 分工与决策权
3. 分红规则
4. 退出机制
5. 竞业与保密

> 模板与细节见 [个人与人际/01-商业关系 §1.3](../个人与人际/01-商业关系.md) + [附录/05-可直接抄写的模板样张 §2 股东协议](../附录/05-可直接抄写的模板样张.md)。

> **黄金原则**：朋友合伙也要签协议，**不签 = 风险全在你**——朋友办不下去也伤钱。

## 3. 聚会与消费的边界

### 3.1 谁买单的 3 种规矩

| 规矩 | 适合 | 怎么建 |
|------|------|--------|
| **轮流买单** | 关系对等 | 主动说"上次你请，这次我来" |
| **AA 制** | 朋友/同事 | 吃完饭当场打开 AA 工具（微信群收款）|
| **谁组局谁买单** | 大型聚会 | 组局的人在邀请时就说清规则 |

> **关键**：规矩要在第一次就建，**不能等你付了 5 次才说"下次 AA 吧"**——建晚了双方都尴尬。

### 3.2 同学群/老友圈的常见坑

- **"众筹"**：生日/婚礼/生病筹款——量力而行，**不必跟随攀比**。
- **"拼单"**：团购大额商品（茅台/球鞋/电子产品）——看自己是否真需要，不为"占便宜"而买。
- **"捧场"**：你不去就是不给面子——去不了的场合就直说"有事去不了，下次一定"，**不要勉强**。
- **"借钱搞副业"**：群里时不时有人推荐项目——按 [02-亲戚相处 §3.1](../家族/02-亲戚相处.md) 的话术拒绝。

### 3.3 "隐形买单人"的应对

> 朋友/同学里你最成功后，聚会买单常落到你头上——**不是因为你该付，是他们默认你有钱**。

- **第一次就打破**：AA 时主动打开收款码，让别人习惯"这次我付"或"这次你付"。
- **不必害羞**：你的钱是你的，**大方花在自己觉得值的地方**。
- **例外**：你主动请的客，可以记在小本子上"今年请了 X 次"——避免过度。

## 4. 嫉妒与疏远的应对

### 4.1 老友疏远/带刺的常见原因

| 表面行为 | 真实原因 | 应对 |
|----------|---------|------|
| 突然不回你消息 | 落差感 / 嫉妒 | 主动 1 次问，不强求 |
| 说话带刺 / 阴阳怪气 | 内心不平衡 | 不接茬、不解释 |
| 朋友圈不点赞不互动 | 心理距离拉远 | 接受——**有些人注定渐行渐远** |
| 当众让你下不来台 | 嫉妒 / 想找存在感 | 不当场翻脸，过后私下沟通 |
| 找各种理由疏远 | 不一定是你做错了什么 | **允许关系结束**——别硬留 |

### 4.2 你主动些、姿态低些

- **不炫富、不教育人**：少在朋友圈发收入/资产/消费内容；少讲"你应该这样"的话。
- **主动示好**：节日问候、对方重要日子记着、偶尔请客——成本不高但关系留得住。
- **不比较**：与老友聊天时不提收入数字、消费档次——**比较是关系的杀手**。

### 4.3 允许关系结束

- 有些人注定渐行渐远——**不是因为你做错了什么**，是各自的人生轨道不同了。
- **别硬留**：硬留的关系双方都累，不如好聚好散。
- **留下的才是真朋友**：5–10 个能说真心话的老友，远胜过 100 个点赞之交。

## 5. 关系维护：4 个低成本高价值动作

### 5.1 记住重要日子

- **生日、结婚纪念日、孩子出生**——一份小礼/一条消息成本很低、价值很高。
- **推荐工具**：微信"提醒"功能 + 手机日历设循环提醒。
- **预算**：每人每年 100–500 元的小礼成本，**维护 10 个核心朋友 = 1,000–5,000 元/年**。

### 5.2 朋友落难时主动伸手

- 失业、离婚、生病、亲人去世——**低谷期维护的关系最真**。
- 主动问候、提供帮助、陪伴——不用等对方开口。
- **不必大动作**：一通电话、一顿饭、一句"我在"——就够了。

### 5.3 让朋友"帮你一点小忙"

> 被需要感是关系的黏合剂，比单方面付出更牢。

- 介绍人脉、提供建议、请朋友帮忙看看方案——给对方"被尊重"的感觉。
- 别什么都自己扛，**主动示弱也是关系维护**（不是真弱，是信任）。

### 5.4 把朋友分层经营

| 层级 | 朋友类型 | 维护频率 | 投入 |
|------|----------|----------|------|
| **铁杆**（3–5 人）| 什么话都能说 | 每周/每月至少 1 次 | 高（时间 + 情感）|
| **重要**（10–20 人）| 重要日子联系 | 每季至少 1 次 | 中（节日 + 重要事）|
| **普通**（50–100 人）| 朋友圈互动 | 半年/每年 | 低（点赞 + 评论）|
| **点赞之交**（更多）| 几乎无交集 | 随缘 | 极低 |

> **原则**：用一套标准要求所有人是错的——按层级投入才是聪明做法。

## 6. 底线红线（这些事无论关系多铁都不做）

| 红线 | 原因 |
|------|------|
| ❌ 替朋友担保贷款 | 对方还不上，银行找你 |
| ❌ 借身份证、银行卡 | 对方出事你担责 |
| ❌ 借公司资质走账/开票 | 虚开=刑事，你涉刑 |
| ❌ "用你账户走一下款" | 涉嫌洗钱/诈骗 |
| ❌ 朋友要你做"灰色地带"的事 | 朋友让你违法 = 真朋友不会 |
| ❌ 为面子打肿脸充胖子 | 你垮了没人替你养家 |
| ❌ 替朋友隐瞒家庭/出轨/违法 | 包庇 = 共犯 |
| ❌ 替朋友出头打架/做违法事 | 朋友让你违法 = 该断 |

> **真朋友的特征**：
> - 不让你为难的事
> - 不让你违法的事
> - 不让你牺牲家庭/健康的事
>
> 让你做这些事的**不是真朋友**。

## 7. 紧急情境的应对

| 情境 | 你的应对 |
|------|---------|
| **朋友突然找你借大钱** | 先问三句（金额/用途/还款时间），再判断 |
| **朋友生病住院** | 第一周去看望 + 红包 + 帮联系资源 |
| **朋友失业/离婚** | 主动关心 + 提供资源 + 不评价对方 |
| **朋友找你倾诉出轨/家事** | 只倾听、不站队、不传播 |
| **朋友失联/出事** | 联系家属 + 报警（如有必要） |
| **朋友找你做担保** | 直接拒绝 + 帮想其他办法 |
| **朋友拉你进他创业项目** | 看合伙前 5 问 + 签协议 |
| **朋友圈里朋友突然炫富/炫关系** | 点赞不评论，**不参与攀比** |
| **朋友群起哄让你请客** | 婉拒或 AA："今天我请，下次轮到你们" |
| **朋友公开场合让你下不来台** | 不当场翻脸，过后私下沟通 |

## 8. 同学/老友会的组织技巧（你组局时）

| 决策点 | 建议 |
|--------|------|
| **频率** | 每年 1–2 次大聚会 + 不定期小饭局 |
| **地点** | 大家方便的中立地点（不出差太远） |
| **费用** | AA 为主，可设基金池（每人每年预交 X 元作活动经费）|
| **议题** | 提前收集话题，避免冷场 / 避免敏感话题（政治/收入比较）|
| **人员** | 不必叫齐所有人——**5–15 人小范围更易维护** |
| **形式** | 吃饭 + 短途游 + 兴趣活动（球局/读书会/音乐会）|
