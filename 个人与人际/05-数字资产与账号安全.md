> 定位：你的钱、账号、作品、回忆，越来越多是**一串字符**。丢了密码、账号被封、人出意外家人登不进去——每一种都是真实的损失。
> 本节把"账号安全"从口号变成可执行的三层：**盘清楚 → 守得住 → 交得出去**。

---

## 1. 先盘清楚：你有哪些数字资产

花 1 小时列一张表（模板见下），列完你会发现比想象的多：

| 类别 | 常见例子 | 丢了/被黑的代价 |
|------|---------|----------------|
| **资金类** | 银行卡、支付宝/微信支付、券商、交易所（如 OKX/币安）| 直接金钱损失 ⭐最高 |
| **身份类** | 手机号（一切的根）、主邮箱、微信/QQ | 收不到验证码 = 所有账号被连锁接管 |
| **账号类** | GitHub、云服务器、域名、APP/系统后台、企业邮箱 | 代码泄露、业务停摆（见 [公司/06-经营风险](../公司/06-经营风险.md)）|
| **内容类** | 云笔记、手机相册、网盘、个人站点 | 多年积累一夜蒸发 |

> 🔑 **手机号是根**：几乎所有账号都靠"短信验证码"找回。手机号一旦被补卡/盗用，攻击者能顺藤摸瓜重置你全部账号——所以运营商客服密码、SIM 卡 PIN 也要设。

## 2. 三道安全基线（先做到这三条，就超过 90% 的人）

**① 密码管理器 + 唯一强密码**
- 别再用"一个密码走天下"或"姓名+生日"——数据泄露库里几秒就能撞库。
- 用密码管理器（Bitwarden/1Password 等）生成并保存**每个账号独立的长随机密码**。
- 主密码是"钥匙中的钥匙"：设成你能记住的最长句，**手写一份放家里**（不是只存云端）。

**② 双重验证（2FA），能用 App 不用短信**
- 优先 Authenticator 类（Google/Microsoft/密码器内置），其次硬件 Key。
- **交易所/券商/邮箱**务必开 2FA；API Key 只开"读取"权限、别开提现（呼应交易安全）。
- 短信验证码可被"换卡攻击"绕过，仅作为兜底。

**③ 恢复码离线保存**
- 开启 2FA 时给的**备用码/恢复码**：打印或手抄，放家里/银行保险柜，**别只存在同一个云盘里**。
- 手机丢了/换了，恢复码是你唯一退路——没存 = 账号可能永久锁死。

**④ 每 90 天做一次"权限体检"**
- 检查：哪些设备登录着你的账号？哪些第三方应用有授权？哪些 API token 还活着？
- 习惯：**用完即吊销、用时再生成**（token 一旦在聊天/截图/日志出现，按已泄露处理）。GitHub 入口见 [附录01-办事网站](../附录/01-办事网站与入口.md)。

## 3. 分级：分清"能承受的损失"和"不能承受的"

| 级别 | 判断标准 | 保护强度 |
|------|---------|---------|
| A 级 | 丢了会致命（资金、手机号、主邮箱、代码仓库）| 2FA + 恢复码 + 季度体检 + 离线备份 |
| B 级 | 丢了很麻烦（社交、云笔记、网盘）| 2FA + 定期导出备份 |
| C 级 | 丢了不可惜（论坛、一次性注册）| 独立随机密码即可 |

> 原则：**保护强度跟级别走，别所有账号一样用力**——你会累到放弃，反而裸奔。

## 4. 交得出去：意外时家人怎么接手（数字遗嘱）

多数人没想过：**你出意外/失能时，家人连你的钱都取不出来**——交易所账号、基金、甚至手机都打不开。留好后路：

- **资产清单**：把上表那张"数字资产清单"（哪个平台、大概多少钱/在哪）打印放家里，加密文档存一份给可信的人。家人不知道你有 = 资产永久沉睡。
- **"钥匙位置"而不是"钥匙本身"**：别把全部密码写在一张纸上到处放；而是写"密码管理器主密码在 XX 保险柜/交给 XX"，需要时再取。
- **防滥用设计**：留给最信任的 1 人 + 律师/配偶各持一半，或约定"仅在本人失联 X 天以上才启用"；涉及大额（房产/公司股权）走正式遗嘱（见 [家族/01-家庭与健康规划](../家族/01-家庭与健康规划.md) 的传承一节）。
- **公司账号**：域名/服务器/企业邮箱的接管人，写进公司交接文档（[公司/08-退出与传承](../公司/08-退出与传承.md)）。

## 5. 红线清单（这些事别做）

- ❌ 密码明文贴在工位/手机备忘录，或发在聊天里
- ❌ API Key / token 截图发给任何人、提交进代码仓库（哪怕私有库）
- ❌ 所有账号共用同一密码，或用生日/手机号当密码
- ❌ 2FA 恢复码只存在同一个云盘（云盘被盗=一起丢）
- ❌ 手机号停机/换号前不迁移绑定——换绑要提前 1 个月逐个处理

## 6. 季度自检（每 90 天 10 分钟）

- [ ] 授权设备/第三方应用清一遍，踢掉不认识的
- [ ] API token 清单过一遍，不用的吊销
- [ ] 密码管理器提示的"弱密码/重复密码"改掉
- [ ] 数字资产清单更新（新增的平台/账户补上）
- [ ] 确认 2FA 恢复码仍可用（拿一张试登录一次）
