# 08 退出与传承：给公司留一条体面的退路

> 🧭 板块：**公司 ①** ｜ ↩ [🏠 返回首页](../README.md) ｜ 总纲：[年轻创业者全攻略](../年轻创业者全攻略.md)

> 定位：把"怎么体面结束"展开成**4 种退出方式 × 全流程 × 自查清单 × 应急预案**。
> **核心观点**：退得不干净 = 替过去买单 10 年。**注册时多花 1 小时想清楚退出条款，注销时省下 100 小时的麻烦。**

---

## 一、4 种退出方式对比（先选对方式）

| 方式 | 适用 | 关键动作 | 时间 | 费用 |
|------|------|----------|------|------|
| **股权转让** | 合伙人退出/套现 | 签协议 → 工商变更 → 税务完税 | 1–3 个月 | 印花税 + 个税 |
| **被收购/并购** | 业务成型被买 | 签 SPA → 交割 → 对赌执行 | 3–12 个月 | 中介费 + 税费 |
| **清算注销** | 不做了 | 税务清算 → 工商注销 → 缴销印章 | 2–6 个月 | 公告费 + 清算费 |
| **保留运营（休眠）** | 暂停但不注销 | 零申报 + 地址保住 + 定期维护 | 持续 | 记账 + 地址费 |

> **决策表**：
>
> | 业务是否还想继续？| 是否有合伙人想接手？| 建议方式 |
> |---|---|---|
> | 是 | 是 | 股权转让给合伙人 |
> | 是 | 否 | 被外部收购 |
> | 否 | — | 清算注销 |
> | 暂时不想做但可能重启 | — | 保留运营（休眠）|

## 二、注销全流程（深圳"注销一窗通"线上）

> **简易注销**：未开业/无债权债务的小公司可走简易程序，**最快 20 天**。
> **普通注销**：有经营或债权债务的，必须走完整流程，**2–6 个月**。

### 2.1 普通注销 7 步

```text
步骤1 成立清算组 → 步骤2 登报公示 45 天 → 步骤3 税务清算
步骤4 社保/公积金注销 → 步骤5 银行账户注销 → 步骤6 工商注销 → 步骤7 印章缴销
```

#### 步骤 1：成立清算组（公司决议）

- **触发**：股东会作出解散决议（2/3 表决权通过）。
- **清算组**：股东或聘请的清算人组成；自成立之日起 10 日内通知债权人、60 日内登报公告。
- **材料**：解散决议、清算组成员名单、营业执照副本。

#### 步骤 2：登报公示（45 天）

- **入口**：当地公开发行的报纸或国家企业信用信息公示系统的"清算公告"专栏（部分城市支持线上公告）。
- **内容**：公司名称、统一社会信用代码、清算组联系人、债权申报期限（45 天）。
- **费用**：报纸公告几百–千元；线上公告多数免费。

#### 步骤 3：税务清算（最易卡住的一步）

- **入口**：电子税务局 → 注销预检 → 清税申报。
- **流程**：
  1. 提交注销申请，税局做注销检查。
  2. 结清所有税款、滞纳金、罚款。
  3. 缴销空白发票 + 发票领购簿 + UKey。
  4. 取得**《清税证明》**（税务注销完成）。
- **常见卡点**：
  - 有欠税未清 → 必须补缴
  - 有未申报 → 必须补报
  - 发票未缴销 → 缴销后才能注销
  - 上下游有疑点 → 税局会发函协查（耗时）
  - **发票丢失** → 先登报 + 罚款 50–500 元/份

#### 步骤 4：社保/公积金注销

- **社保**：社保局 → 单位注销登记 → 结清欠费 → 注销账户。
- **公积金**：公积金中心 → 单位注销登记 → 结清欠费 → 注销账户。

#### 步骤 5：银行账户注销

- **基本户**：提前 30 天预约 + 法人到场 + 携带营业执照/公章/财务章/法人章/法人身份证/银行预留印鉴。
- **一般户**：相对简单，预约即可。
- **外币账户**：单独流程，部分银行要求外汇局证明。
- **注意**：先确认账户无未达账项 + 无未结清业务。

#### 步骤 6：工商注销登记

- **入口**：深圳市市场监督管理局"注销一窗通"或现场窗口。
- **材料**：清算报告、税务清税证明、登报公告样张、营业执照正副本、股东会决议。
- **审核时间**：一般 5–10 个工作日。
- **简易注销**：未开业/无债权债务的小公司直接登录"国家企业信用信息公示系统"做简易注销公示（20 天），无异议即可注销。

#### 步骤 7：印章缴销

- 公章/财务章/法人章/发票章/合同章 → 公安备案刻章点缴销。
- 缴销证明 + 注销回执留存。

### 2.2 简易注销条件（满足全部）

- **领取营业执照后未开展经营**（无年报/无税务申报/无发票领用）
- **无债权债务**（或债权债务已清理完毕）
- **公示期 20 天**无异议

### 2.3 注销失败常见原因速查

| 原因 | 怎么避免 |
|------|----------|
| 税务异常未处理 | 注销前 1 个月登录电子税务局"注销预检"查清所有异常 |
| 营业执照遗失 | 补办或登报声明 |
| 股东失联 | 走公告送达 + 强制注销路径 |
| 工商年报未报 | 注销前补报 + 申请移出异常 |
| 行业资质未注销 | 食品/医疗等资质先注销主体 |
| 印章丢失 | 登报声明 + 公安备案 |

### 2.4 注销时间预估

| 情形 | 时间 |
|------|------|
| **简易注销**（无经营无债权）| 20–45 天 |
| **小规模 + 干净账** | 2–3 个月 |
| **一般纳税人 + 干净账** | 3–4 个月 |
| **有税务异常/欠税/发票问题** | 4–6 个月 + |
| **有诉讼/债权债务复杂** | 6 个月 + |

> **提示**：能不走到注销就别走到——业务盘活总比注销省事；走到注销就一次做完别拖，**越拖越贵**（每年还要年报+记账+地址费）。

## 三、股权与合伙人退出（最常见的退出场景）

### 3.1 退出的 4 个关键问题

1. **按什么价退**？→ 估值方式
2. **多久付清**？→ 付款周期
3. **未实缴部分怎么处理**？→ 减资或承接
4. **退出后做什么约束**？→ 竞业 + 保密

### 3.2 退出估值方式（必须在股东协议里写死一种）

| 方式 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| **净资产法** | 重资产公司 | 简单清晰 | 不反映成长性 |
| **上轮估值倍数法** | 有融资经历 | 与市场接轨 | 估值波动大 |
| **协商法** | 双方互信 | 灵活 | 易扯皮 |
| **第三方评估法** | 大额退出 | 公允 | 耗时费钱 |
| **章程/协议约定法** | 最常见 | 提前约定，无扯皮 | 估值方法需合理 |

> **建议**：写"上年度经审计净利润的 X 倍" 或 "双方协商"——**千万别写"到时候再谈"**。

### 3.3 退出流程（标准 6 步）

```
1. 退出方提出书面申请（30 天前）
2. 股东会决议通过（2/3 表决权）
3. 双方签《股权转让协议》+《退出协议》
4. 工商变更登记（提交股东会决议 + 协议 + 新章程）
5. 税务申报（个人所得税 "财产转让所得" 20%）
6. 付款：分期付清（建议 30–90 天分批）
```

### 3.4 未实缴部分处理

| 情形 | 处理 |
|------|------|
| 退出方未实缴到位 | 两种方式：① 受让方承接未缴部分（修改章程）；② 公司先减资再退出 |
| 受让方不接 | 退出方要补缴或放弃未实缴部分对应股权 |
| 公司对外有债务 | 债权人可要求**加速到期**未实缴部分——退出方仍可能需补缴 |

> **警示**：注册资本写 1 亿 ≠ 不需要掏——退出时同样要承担未实缴部分责任。

### 3.5 退出的"5 个必谈"（一份都不能少）

1. **股权转让协议**（含估值、付款、声明保证）
2. **保密协议**（在职 + 退出后 X 年）
3. **竞业限制协议**（退出后 X 个月不得同业 + 经济补偿）
4. **债务切割声明**（明确哪些债务归公司、哪些归个人）
5. **知识产权移交清单**（代码/客户/供应商/账号）

> 模板片段见 [附录/05-可直接抄写的模板样张](../附录/05-可直接抄写的模板样张.md)。

## 四、创始人交接与传承（公司层面的"遗嘱"）

### 4.1 为什么必须做

- 创始人突发失能/意外 → 公司可能停摆：合同签不了、款付不出、决策没人拍板。
- **真实案例**：某创业公司创始人车祸去世，因未留任何授权，账户冻结、员工工资发不出、客户流失，公司半年内被迫注销。

### 4.2 交接文档清单（写一次用十年）

| 类别 | 内容 | 形式 | 存放 |
|------|------|------|------|
| **公司基础** | 营业执照、公司章程、股东协议、各类资质证照 | 扫描件 + 复印件 | 公司档案 + 家里 |
| **财务账户** | 基本户信息、网银 U盾、U盾密码、电子税务局密码、三方协议 | 加密文档 + 密码分持 | 保险柜 + 可信人 |
| **合同台账** | 在执行合同清单（对方/金额/节点/负责人） | 表格 | 公司云文档 |
| **客户资料** | 客户清单、联系人、合同、CRM | CRM + 表格 | 公司云文档 |
| **供应商清单** | 主要供应商、合作方式、付款条件 | 表格 | 公司云文档 |
| **员工档案** | 劳动合同、岗位、薪酬、绩效、社保 | 加密文档 | 人事档案 |
| **印章登记** | 印章种类、保管人、用印登记本 | 纸质 + 电子 | 公司档案 |
| **密码清单** | 各系统账号密码（用密码管理器）| 加密文档 + 主密码分持 | 见 [05-数字资产 §4](../个人与人际/05-数字资产与账号安全.md) |
| **授权委托** | 突发失能时谁能代理（见 §4.3） | 公证文件 | 公证处 + 家里 |

### 4.3 授权委托书（突发失能时家人能代办）

> **场景**：创始人住院/失能/失联，配偶/父母/合伙人需要代理公司事务。

- **必备事项**：银行账户查询/支取、税务申报、社保公积金、合同签署（限定金额）。
- **建议公证**：单笔金额 > 50 万 或 涉及公司股权变更 的授权，**建议公证**——效力更高。
- **被授权人**：建议配偶 + 信任的合伙人各持一份，互为备份。
- **触发条件**：明确写"在本人失联 X 天以上时启用"。
- **样张**：见 [附录/05-可直接抄写的模板样张](../附录/05-可直接抄写的模板样张.md) §4。

### 4.4 接班 / 继任（公司能跑下去）

- **关键岗位有 B 角**：业务、密码、客户、供应商、财务，每项至少有 2 人能接手。
- **决策机制**：重大事项的审批权限写在章程（不只是默认老板）——例如"单笔支出 > 10 万需 CFO + CEO 联签"。
- **客户关系公司化**：客户认公司而非个人（呼应 [04-公司发展 §2.3](04-公司发展.md)）。

### 4.5 创始人意外时 48 小时应急动作

```
【第 0–2 小时】
□ 确认事实 / 联系家属 / 报警（必要时）
□ 联系律师 + 会计师
□ 暂时冻结公司印章、网银、关键账号（防止被误用）

【第 2–24 小时】
□ 召开临时股东会（如可）/ 启动授权委托书
□ 通知关键员工 / 关键客户 / 关键供应商
□ 盘点公司现金 + 应付到期款项

【第 24–72 小时】
□ 银行/税务/社保账户接管
□ 客户合同梳理：哪些能正常履约、哪些需延期
□ 公开回应（如有舆论关注）

【第 1 周内】
□ 业务继续运营 / 临时 CEO 确定
□ 账务月度盘点
□ 法律意见（公司是否继续经营、是否清算）
```

## 五、保留运营（休眠公司）的维护

> **场景**：业务暂停但不注销，等市场回暖可能重启；或为保牌照/资质保留主体。

### 5.1 维护清单

| 频率 | 事项 |
|------|------|
| **每月** | 零申报（增值税、个税、企税）|
| **每年 1–6 月** | 工商年报 |
| **每年** | 财务记账（保留凭证）+ 银行账户维护（避免久悬）|
| **每年** | 法人/股东身份证有效期检查 |
| **每年** | 资质证照有效期检查 |

### 5.2 风险

- **忘申报**：逾期 → 罚款 → 列入异常 → 影响法人征信
- **地址失联**：列入异常
- **银行账户久悬**：冻结后激活难

> **建议**：休眠公司每年总维护成本 500–2,000 元（记账 + 地址）；不如直接注销划算。

## 六、退出前的自查清单（清算 / 注销 / 转让前必查）

### 6.1 税务

- [ ] 所有税款已结清（无欠税）
- [ ] 所有申报已补齐（含零申报）
- [ ] 空白发票 + 发票领购簿 + UKey 全部缴销
- [ ] 取得《清税证明》

### 6.2 劳动

- [ ] 员工工资/补偿金/加班费已结清
- [ ] 社保/公积金已结清（最后一个月已缴）
- [ ] 离职证明已开
- [ ] 员工档案已移交或归档

### 6.3 债务 / 合同

- [ ] 对外债务已结清或书面转移（含借款、应付货款）
- [ ] 对外担保已解除或书面转移
- [ ] 客户预收款/押金已退清或交接
- [ ] 在执行合同有交接清单（对方/金额/节点/责任人）

### 6.4 资产 / 资料

- [ ] 公章 / 财务章 / 法人章 / 发票章 / 合同章 全部缴销
- [ ] 营业执照正副本 缴销
- [ ] 网银 U盾 / 电子税务局密码 已交接或封存
- [ ] 客户/供应商清单、合同台账 已交接

### 6.5 对外宣传

- [ ] 公司网站停止或挂"公司已注销"提示
- [ ] 公众号/视频号/小程序 已停止更新或公告
- [ ] 商业目录/平台账号 已注销或注明
- [ ] 名片/宣传材料 已停用

### 6.6 法律 / 行政

- [ ] 行业资质已注销或书面转移
- [ ] ICP/域名/小程序已注销或转移
- [ ] 知识产权（商标/专利/软著）已转让或注销
- [ ] 政府补贴/专项资金已结题

## 七、退出成本估算

| 退出方式 | 费用区间 |
|----------|----------|
| **简易注销**（无经营）| 500–2,000 元（公告费 + 杂费）|
| **普通注销**（小规模）| 2,000–5,000 元（公告 + 清算 + 杂费）|
| **普通注销**（一般纳税人/复杂）| 5,000–20,000 元（含税务异常处理）|
| **股权转让** | 个税（按"财产转让所得" 20%）+ 印花税 + 工商变更 + 律师费 |
| **被收购** | 中介费（投资额的 1–5%）+ 律师 + 会计师 |

> **最贵的是"拖着不注销"**——每年记账 + 地址 + 年报 = 5,000–10,000 元/年 + 信用损失。

## ✅ 本节行动清单

**注册时（预防）：**
- [ ] 股东协议里写清楚退出条款（估值/付款/未实缴/竞业）
- [ ] 章程里写"单笔支出 > X 万需 Y 联签"
- [ ] 建一份"公司交接文档"骨架（即使创始人还在）

**任何退出前：**
- [ ] 选对退出方式（决策表 §1）
- [ ] 完成 §6 全套自查清单
- [ ] 准备 §4.3 授权委托书（即使是临时）

**公司运营中（每年）：**
- [ ] 维护一份"公司交接文档"（一次写好 + 实时更新）
- [ ] 关键岗位 B 角 + 文档化
- [ ] 每年 1 次"如果我明天不在了"桌面演练
