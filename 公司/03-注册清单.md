复制本清单，逐项打勾 ✅。以深圳注册「有限责任公司」为例。

## 一、前期决策
- [ ] 确定公司类型（有限责任公司 ✅）
- [ ] 确定主营业务与未来方向
- [ ] 自己办 / 找代办（决定预算）

## 二、注册前 6 要素
- [ ] 公司名称：准备 3–5 个备选字号
  - [ ] 字号 1：
  - [ ] 字号 2：
  - [ ] 字号 3：
- [ ] 注册资本金额与认缴期限（__万元 / __年）
- [ ] 经营范围（主营 + 兼营）
- [ ] 注册地址（实际租赁 / 挂靠 / 孵化器 / 前海）
  - [ ] 地址证明/租赁合同
- [ ] 人员到位：法人、股东、监事、财务负责人（法人≠监事）
- [ ] 股权比例与出资方式

## 三、注册流程
- [ ] 名称自主申报（一窗通）
- [ ] 设立登记提交（章程、任职文件、股东信息）
- [ ] 全体人员实名认证
- [ ] 领取营业执照（电子 + 纸质）
- [ ] 刻章：公章 / 财务章 / 法人章 / 发票章 / 合同章
- [ ] 银行开立基本户（预约 + 法人在场）
- [ ] 税务报到（税种核定、票种、小规模/一般纳税人）
- [ ] 社保开户 + 公积金开户
- [ ] 申领发票 / UKEY

## 四、注册后合规
- [ ] 建立账套，开始记账
- [ ] 按月/季报税（含零申报）
- [ ] 设置年报提醒（次年 1–6 月）
- [ ] 银行对账与资金管理
- [ ] 员工社保公积金缴纳

## 五、可选 / 后续
- [ ] 商标注册
- [ ] 行业资质/许可证（食品、进出口、ICP 等）
- [ ] 开通企业微信 / 对公支付
- [ ] 网站/小程序备案（ICP 备案）
