## 一、风险管理的 4 步通用法

**任何风险都按这个套路处理**：

```
识别（这事会发生吗？） → 量化（发生会怎么样？）→ 应对（能预防/减少/转移吗？）→ 监控（怎么知道正在发生？）
```

### 1.1 风险评分矩阵（用于排序"先管哪个"）

| | 影响：小 | 影响：中 | 影响：大 |
|---|---|---|---|
| **概率：高** | 🟡 中风险 | 🟠 高风险 | 🔴 极高风险 |
| **概率：中** | 🟢 低风险 | 🟡 中风险 | 🟠 高风险 |
| **概率：低** | 🟢 低风险 | 🟢 低风险 | 🟡 中风险 |

- **🔴🟠 必须现在就应对**（有书面预案 + 责任人）。
- **🟡 季度复盘时检查**。
- **🟢 知道就好，不必专门花精力**。

### 1.2 4 种应对策略

| 策略 | 含义 | 例子 |
|------|------|------|
| **规避** | 不做这事 | 不给亲友做贷款担保 |
| **减少** | 降低概率或影响 | 合同逐条审、季度备份数据 |
| **转移** | 让别人承担一部分 | 买保险、外包给供应商、找担保 |
| **接受** | 损失可承受，不花精力防 | 偶尔的小额客户拖欠 |

## 二、7 类核心风险详解

### 2.1 财务与债务风险（最易致命）

#### 风险 1：公私混同

- **识别**：用个人卡收公司款、公司钱转个人账户花、老板个人借款给公司走对公账户。
- **量化**：一旦公司欠债被诉、且不能证明财产独立 → **揭开公司面纱**，有限责任变**个人无限连带**，可能赔到家庭资产。
- **应对**：
  - 严格**双账户**：公司账户只走经营款、个人账户只走个人收支。
  - 老板从公司拿钱走**工资/分红/费用报销**三种合规路径，**每月记账**。
  - 个人与公司间借款要**签借款协议**，约定利息和还款期。
- **自查**：每月 1 日核对上月流水——所有"公司付款"摘要里都不应出现个人消费类商户（餐饮/购物/家用等）。

#### 风险 2：对外担保

- **识别**：给朋友/兄弟公司/上下游企业做贷款担保。
- **量化**：被担保方违约 = 你替他还钱。**担保金额可能远超你的净资产**。
- **应对**：
  - 原则：**非必要不担保**，委婉话术见下。
  - 真要担保 → 看清担保形式（一般担保 vs 连带担保）、担保期间、有无反担保。
- **拒绝话术**：「公司董事会/股东会不允许对外担保，章程有明确限制，给您介绍 XX 银行有 X 方案可以试试。」

#### 风险 3：过度赊销 / 应收账款堆积

- **识别**：客户欠款 > 90 天、单一客户欠款 > 总应收 30%、催款要找老板才能付。
- **量化**：账面利润 100 万、应收账款 80 万 = **现金可能不到 20 万**，工资都发不出。
- **应对**：
  - **账期上限**：新客户 30 天，老客户 60 天，超大客户单独签协议（最严的也别 >90 天）。
  - **信用额度**：单客户赊销上限 = 你能承受"他跑单"的金额。
  - **催款四梯度**：见 [10-报价与收款 §5](10-报价与收款.md)。
  - **坏账预警线**：超 60 天的应收占月度营收 > 20% = 立即冻结新单出货。

#### 风险 4：隐形负债（签字时没看清）

- **识别**：对赌协议、售后承诺（无上限）、长期租赁违约金、个人连带担保条款。
- **量化**：触发时可能要你个人卖房还债。
- **应对**：**所有签字的合同都要逐条看**——大额合同请律师。详见 [12-危机与客诉应对](12-危机与客诉应对.md) 的合同管理。

### 2.2 法律与合规风险

#### 风险 5：合同风险

- **识别**：口头协议、关键条款缺失（付款/违约/保密/知识产权）、阴阳合同。
- **量化**：纠纷时无凭无据，诉讼成本远大于履约成本。
- **应对**：
  - **书面优先**：超过 1 万元的合作必须书面合同。
  - **必备 4 条款**：① 标的（做什么、什么标准）② 价款（多少钱、含不含税、怎么付）③ 违约（逾期/质量不达标怎么算）④ 争议（仲裁还是诉讼、哪个地方法院）。
  - **阴阳合同 = 双向风险**：合同价 vs 实际付款不一致，税务和纠纷时都说不清。
- **模板起点**：[附录/02-常用模板与术语](../附录/02-常用模板与术语.md) + [附录/05-可直接抄写的模板样张](../附录/05-可直接抄写的模板样张.md)。

#### 风险 6：知识产权风险

- **识别**：未注册商标被抢注；用了他人的素材/字体/图片；员工开发的代码归属不明。
- **量化**：抢注后你只能改名/赎回（昂贵）；侵权要赔 + 公开道歉；员工带走代码可能丢失产品核心。
- **应对**：
  - **商标尽早注册**（公司名≠商标，公司名同音不同字也是别人家）。
  - **职务作品协议**：员工入职签"知识产权归属公司"条款（参考 [附录/05 劳动合同补充协议](../附录/05-可直接抄写的模板样张.md)）。
  - **素材来源**：只用有授权的（商用字体、正版图库、自己拍的、CC0/CC-BY 注明来源的）。
- **预算参考**：商标注册官费 300 元/类 + 代理费 500–1,000 元/类；海外单国 1,000–3,000 美元。

#### 风险 7：劳动风险

- **识别**：不签合同、不缴社保、口头辞退、规章制度无公示、加班无记录。
- **量化**：
  - 超 1 个月未签合同 → **双倍工资**最多 11 个月。
  - 违法解除 → 2N 赔偿金（N=工作年限 × 月工资）。
  - 工伤未缴社保 → 公司全额赔付（几万–几十万）。
- **应对**：
  - **入职 1 个月内必须签书面合同**（含试用期条款）。
  - **试用期也要缴社保**（很多人误以为转正才缴）。
  - **规章制度**：成文 + 员工手册签收 + 公示（保留公示证据）。
  - **辞退前**：参考 [09-招人与用人 §6](09-招人与用人.md) 的"辞退与好聚好散"。
- **老板 3 条红线**：① 不签合同 ② 试用期不缴社保 ③ 口头辞退不留证据——每一条都可能赔几万。

#### 风险 8：数据与隐私（《个人信息保护法》）

- **识别**：客户/员工个人信息未脱敏采集、明文存储在网盘/微信、跨境传输、APP 违规收集。
- **量化**：处罚最高 5,000 万元或上一年营业额 5%；情节严重的吊销许可。
- **应对**：
  - **最小必要原则**：只采集业务需要的字段（不要"为以后用"先收一堆）。
  - **存储加密**：敏感字段加密存储，访问留痕。
  - **删除权**：用户要求删除时，30 天内响应。
  - **跨境传输**：确需时做 PIPL 安全评估或签标准合同。

### 2.3 税务稽查风险（红线最高）

#### 风险 9：虚开发票（刑事红线）

- **识别**：为他人虚开、为自己虚开、让他人为自己虚开、介绍他人虚开——四种形式都违法。
- **量化**：**最高无期徒刑**（虚开税额 ≥50 万或造成国家税款损失 ≥30 万）。
- **应对**：
  - **不买卖发票**（有些"代开"渠道本身是骗）。
  - **业务真实**：合同/物流/资金/发票四流一致。
  - **不开与实际业务不符的票**（品名/金额/购货方）。
- **真实判例警示**：某公司为他人虚开专票 200 万元，法人判 5 年；某公司购买发票抵成本，法人+会计双双判刑。

#### 风险 10：长期零申报 / 税负异常

- **识别**：连续 6 个月零申报、增值税税负远低于同行、企业所得税贡献与利润严重不匹配。
- **量化**：触发税务预警 → 稽查 → 补税 + 滞纳金（每日万分之五）+ 罚款（0.5–5 倍）。
- **应对**：
  - **没有业务也要零申报**（每月/每季，逾期罚款）。
  - **税负异常自查**：对比同行业平均税负（可在电子税务局查询同地区同行业税负参考）。
  - **合规省税靠政策**：小规模季度免征额、小微企业所得税优惠、研发费用加计扣除——**这些都是公开政策**，用足它。

#### 风险 11：账实不符

- **识别**：库存盘亏盘盈长期不处理、银行流水与账面对不上、现金长款短款。
- **量化**：稽查必查项，查不清就要补税 + 罚款 + 滞纳金。
- **应对**：
  - **月对账**：现金日记账、银行日记账、应收应付明细与总账核对。
  - **季盘点**：库存 / 固定资产。
  - **年审计**：年营收 ≥ 特定规模或行业要求时必须审计。

> 详细合规清单见 [07-税务法律消防合规](07-税务法律消防合规.md)。

### 2.4 经营与市场风险

#### 风险 12：大客户/单一业务依赖

- **识别**：单一客户占营收 > 30%、单一产品/服务占营收 > 70%。
- **量化**：客户/品类一变动 → 业绩腰斩。
- **应对**：
  - **客户分散**：Top 5 客户合计 < 60%；Top 1 客户 < 25%。
  - **业务多元**：在核心业务之外有 1–2 个探索方向（小投入试错）。
  - **客户关系沉淀到公司**：合同主体为客户公司、CRM 化联系人、关键岗位多人维护——别只认你个人。

#### 风险 13：依赖个人关系做生意

- **识别**：销售/采购靠老板个人微信、电话、关系；客户只认老板不认公司。
- **量化**：老板生病/出差 = 业务停摆；老板离职/退出 = 客户流失。
- **应对**：
  - **客户资料公司化**：客户档案、合同、跟进记录入 CRM。
  - **对接人多点化**：每个客户至少让对方认识你公司 2–3 人。
  - **品牌化**：让客户认公司名而非老板个人名（呼应 [个人与人际/04-口碑经营](../个人与人际/04-口碑经营.md)）。

#### 风险 14：现金流断裂（详见 [04 §4](04-公司发展.md)）

- **识别**：账上有利润但无现金、应收 > 90 天、对供应商开始拖欠。
- **量化**：账面利润 100 万、现金 0 = 工资都发不出，下个月就崩。
- **应对**：12 周现金预测（每月底做）、安全垫 ≥ 3 个月固定支出、催款四梯度、断流时**砍非必要支出 + 股东借款 + 谈供应商延账期**——别等发不出工资才动。

### 2.5 行政与安全风险（小公司也躲不开）

#### 风险 15：注册地址异常

- **识别**：注册地址失联/虚假/被投诉、长期无实际办公人员。
- **量化**：列入**经营异常名录**（影响贷款、投标、平台入驻、法人征信）→ 满 3 年未移出 → 列入严重违法失信名单（"老赖"）。
- **应对**：
  - **地址真实可联系**（电话有人接、信件能送达）。
  - **变更地址及时做工商变更**。
  - **挂靠地址每年续费**别中断。

#### 风险 16：消防与办公安全

- **识别**：灭火器过期、疏散通道堵塞、易燃物乱放、电线私拉乱接、餐饮/生产无消防验收。
- **量化**：出事 = 停业整顿 + 罚款 + 媒体曝光；人身伤亡 = 刑事责任。
- **应对**：[07-税务法律消防合规 §3](07-税务法律消防合规.md) 完整清单。

#### 风险 17：公章管理失控

- **识别**：公章放桌面随便用、外借不登记、员工私下盖空白合同。
- **量化**：被私盖合同 = 公司可能要承担责任；公章丢失 = 登报声明 + 重刻。
- **应对**：
  - **专人保管**（出纳或行政）+ 用印登记本（用印文件 / 申请人 / 时间 / 用途）。
  - **不许盖空白合同**——所有盖章必须有对方信息/金额/日期的完整文本。
  - **外借需法定代表人书面审批**，归还时核对完好。
- **丢失响应**：立即登报声明作废 + 公安备案 + 重新刻制。

### 2.6 创始人个人风险

#### 风险 18：以个人名义为公司签无限责任条款

- **识别**：个人担保、个人无限连带承诺、用个人房产为借款抵押。
- **量化**：公司还不起 = 卖房还债。
- **应对**：原则上**公司的事归公司、个人归个人**——法人代表签字时看清"个人"还是"公司"。

#### 风险 19：突发失能 / 意外

- **识别**：无授权委托书、无家庭资产清单、密码/账号只在创始人脑子里。
- **量化**：失联时家人连你的钱都取不出、公司无法签字、关键业务停摆。
- **应对**：[05-数字资产与账号安全 §4 数字遗嘱](../个人与人际/05-数字资产与账号安全.md) + [08-退出与传承 §4](08-退出与传承.md)。

## 四、风险处置四原则（出事时别乱）

1. **早暴露**：问题藏得越久越贵——24h 内同步比 7 天后再说省 10 倍。
2. **先止血再根治**：先停损失（停出货、停拨款、停对接），再慢慢处理根因。
3. **该找人就找人**：法律/税务/保险专业问题别自己硬扛——一次咨询费几千，远便宜过事后赔几十万。
4. **记录留痕**：所有关键决定留书面/邮件/聊天记录——诉讼时"凭证链"是胜负手。

## 五、季度风控自查模板（30 分钟过一遍）

```
【第 X 季度 · 风控自查】
✅ 财务：
  - 公私账户是否严格分开？[是/否]
  - 应收账款账龄：30/60/90+ 天分别多少？
  - 现金预测：未来 12 周是否每月都 ≥ 3 个月固定支出？

✅ 合规：
  - 报税/缴费是否按时？（零申报也要报）
  - 劳动合同/社保是否全员覆盖？
  - 用印登记是否完整？

✅ 经营：
  - Top 5 客户/Top 1 客户占比？
  - 是否有新客户来源？

✅ 法律：
  - 本季新签合同是否逐条看过？
  - 是否有未解决纠纷？

✅ 安全：
  - 灭火器/疏散通道是否正常？
  - 数据备份是否本月已做？
```
