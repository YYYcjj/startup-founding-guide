> 定位：正文里反复出现的"签协议、写借条、看报表"——这里给出**模板要点清单**和**术语速查**，要签文件时对照着看。

---

## 一、关键文书要写清什么（自己拟时的要点）

### 股东协议（合伙必签）
出资额与比例、各自分工与决策权、利润分配、**退出机制**（怎么卖/卖给谁/定价）、竞业限制、知识产权归属、违约与僵局处理。

### 劳动合同
工资构成（基本+绩效+补贴）、试用期与期限、岗位职责、考勤休假、保密与竞业、解除条件。**入职 1 个月内签。**

### 借条 / 借据（亲友借钱也用）
借款人、出借人、金额（大小写）、**用途**、利息（有无/多少）、**还款日期**、逾期责任、签名+日期+转账凭证留存。

### 合作协议 / 委托合同（与公司/个人合作）
服务内容与交付物、时间节点、**验收标准**、付款方式与节点、违约责任、保密、知识产权、争议解决（仲裁/法院+管辖地）。

### 保密协议（NDA）
保密信息范围、保密期限、违约责任（违约金/赔偿）、不挖角条款。

## 二、术语速查

| 术语 | 一句话解释 |
|------|-----------|
| 有限责任公司 | 股东以**出资额为限**担责的公司形式（风险隔离）|
| 认缴 vs 实缴 | 认缴=章程承诺出资额；实缴=实际到账。新《公司法》须 5 年内缴足 |
| 法定代表人（法人） | 对外代表公司的负责人；**≠"法人"（公司本身）** |
| 监事 | 监督董事/高管的人；**不能由法定代表人兼任** |
| 注册资本 | 营业执照上承诺的出资总额，不是"要交的钱"，但欠债时可被追缴 |
| 基本存款账户（基本户）| 公司主结算账户，发工资/收付款用 |
| 小规模纳税人 | 年销售额≤500 万，增值税简易计税，优惠多 |
| 一般纳税人 | 可开专票抵扣，客户多为大企业时需要 |
| 零申报 | 没收入也要按期申报，**不报=逾期处罚** |
| 工商年报 | 每年 1.1–6.30 报上年度经营情况，逾期列经营异常 |
| 经营异常名录 | 失联/逾期年报等被列入，影响贷款、投标、开票，须申请移出 |
| 汇算清缴 | 企业所得税年度多退少补（次年 5.31 前）|
| 虚开发票 | 无真实业务开票/让他人代开 = **刑事犯罪** |
| 税务注销 | 注销公司第一步：结清税款、缴销发票 |
| 股权平均 | 50:50 / 33:33:34 这类结构，**易决策僵局**，避免 |
| 对赌/回购条款 | 融资里"业绩不达标要补偿/回购股权"的条款，风险高，需律师把关 |
| 雇主责任险 | 员工工伤时转嫁公司赔偿责任的保险 |
| 经营异常→吊销 | 长期列异不处理可能被吊销执照，法人受影响 |
