> 定位：这篇写的是一件不太好意思开口、但迟早会发生的事——**家里的顶梁柱出事（重病、意外、身故）那天，剩下的人怎么活。**
> 它分两半：**前半是"应急"（人还在，要救、要钱、要公司不断档）；后半是"身后"（人走了，遗产、债务、公司股权怎么落定）。**
> 两者共用一个前提：**信息必须能被找到。** 家人不知道你有几张保单、钱在哪个账户、公章放哪儿，你再周密的安排也等于零。

> ⚠️ 通用参考，**不构成法律意见**。继承、遗嘱效力、公司股权继承高度依赖个案与地方实践，涉及具体安排请找律师。

## 一、先做一件事：家庭应急信息包（周末 2 小时能完成）

**做法**：一份纸质清单 + 一份密封信（或密码管理器里的一个"紧急访问"条目），**至少两个家人知道放在哪**。

**为什么必须纸质/双备份**：如果所有信息都在你的手机里、而手机需要你的指纹或密码——**你出事的那一刻，信息和你一起被锁住了。**

### 家庭应急信息包（照抄这份清单）

**① 人**
| 项 | 内容 |
|---|---|
| 家庭成员 | 姓名 / 身份证号 / 手机 / 关系 |
| 紧急联系人 | 除家人外至少 1 人（合伙人、最靠得住的朋友） |
| 医疗信息 | 血型、过敏史、长期用药、既往病史、常去的医院 |
| 医生/医院 | 主治医生、科室电话 |

**② 钱**
| 项 | 内容 |
|---|---|
| 银行账户 | 开户行 / 卡号末四位 / 用途（哪张是家庭安全垫） |
| 保单清单 | 保险公司 / 险种 / 保单号 / 保额 / 受益人 / 客服电话 ★最关键 |
| 投资与证券 | 券商、基金平台、托管行 |
| 债务 | 房贷余额与还款账户、公司借款、个人担保 ★千万别漏 |
| 保险柜/贵重物 | 位置、钥匙在哪 |

**③ 权**
| 项 | 内容 |
|---|---|
| 公司 | 公章/财务章/法人章/营业执照/开户许可证放哪、U 盾谁拿 |
| 合同 | 重要合同（房租、大客户、贷款、股权）存放位置 |
| 股权文件 | 股东协议、代持协议、出资凭证 |
| 法律文件 | 遗嘱、婚前/婚内财产协议、意定监护、授权委托书的存放位置与见证人 |

**④ 码**
| 项 | 内容 |
|---|---|
| 密码管理器 | 主账号 + 紧急访问方式（见 [个人与人际/05](../个人与人际/05-数字资产与账号安全.md)） |
| 手机解锁 | 备用解锁方式（写进密封信） |
| 云盘/相册 | 账号与恢复方式 |
| 公司系统 | 财务软件、开票、电商后台、域名与服务器 |

> **做这个包的意义不在于"万一"，而在于它顺手暴露了一堆你从没想过的问题**——比如"我的受益人还是前女友""公司网银只有我一个人有权限""房子还在贷款但没人知道还款日"。**光是把清单填满，就已经值这几小时了。**

## 二、72 小时清单：家人重病 / 突发意外

**先记住优先级：命 > 钱 > 手续 > 情绪。** 大多数人栽在"钱还没到位就慌了"或者"先处理手续、耽误了治疗"。

### 第 1 小时：人

1. **打 120 或送最近的有救治能力的医院**（不是最近的医院）。心梗/脑卒中优先有**卒中中心/胸痛中心**的医院。
2. **带上**：身份证、医保卡（或医保电子凭证）、既往病历、正在吃的药（**直接把药盒带上**）。
3. **通知顺序**：直系亲属 → 能立刻到场的人 → 其他家人（**别在家族群里直接发消息**，会炸）。
4. **留一个"联络官"**：由一个人负责对外沟通，其余人不要各自发消息、各自打听。**信息混乱比病情更消耗人。**

### 第 2–24 小时：钱

**记住赔付/支付顺序，别先去借高息的钱：**

| 顺序 | 来源 | 特点 |
|---|---|---|
| 1 | **医保**（先备案/直接结算） | 报销大头；未备案会降比例（见 [06](06-父母养老与照护实操.md) §三） |
| 2 | **大病保险** | 自付超限额后二次报销，多数地区自动享受 |
| 3 | **商业医疗险** | 报销型，需发票与费用清单，**出院后一起报** |
| 4 | **重疾险**（确诊即赔） | **一次性给钱，不看发票**——这是救命钱，确诊后立刻报案申请 |
| 5 | **家庭安全垫** | 6–12 个月生活费，独立账户（见 [01](01-家庭与健康规划.md) §一.1） |
| 6 | 亲友借款 / 保单贷款 | 万不得已，优先"保单贷款"（利率通常低于民间借贷） |

**两个立刻要做的动作：**
- **向保险公司报案**（多数公司有 24 小时客服与 App 报案入口），**问清需要哪些材料**——不同险种材料不同，一次问全，别来回跑。
- **申请医院"先诊疗后付费"/分期**：不少医院对急重症可以协商，**别因为一时的钱放弃治疗**。

### 第 1–3 天：手续与公司

| 谁 | 做什么 |
|---|---|
| 你（或主要家属） | 医院缴费、签字、与医生沟通；**把每一张单据收进一个文件袋**（理赔全靠它） |
| 一位家人 | 陪护与后勤（吃饭、住宿、回家取东西） |
| **公司**（若出事的是你） | 见 §三——**越早安排，损失越小** |
| 一位家人 | 处理对外口径（真出了事，客户与员工要知道一句统一的话） |

**理赔材料通用清单（一次备齐，按险种删减）：**

- [ ] 保单（或保单号）、被保险人身份证、受益人身份证与银行卡
- [ ] 诊断证明书、门诊/住院病历、出院小结
- [ ] 医疗费用发票原件、费用明细清单
- [ ] 检查报告（CT/病理/化验，重疾认定常用）
- [ ] 意外类：事故证明（交警责任认定书 / 公安证明 / 单位证明）
- [ ] 身故类：死亡证明、户籍注销证明、受益人关系证明
- [ ] 医院等级要求：看清保单约定的医院范围（多为二级及以上公立医院）

> **最容易翻车的一步**：发票和病历没留全。**住院期间就每天把新单据拍照存档**（云盘 + 纸质文件袋），出院后再补非常痛苦。

## 三、如果出事的是你：让公司不断档

**大多数创始人公司出事，不是因为业务没了，是因为"没有人有权签字"。**

### 提前做的三件事（现在做，出事时救命）

1. **授权安排**：给一位可信任的人（合伙人或家人）一份**授权委托书**，明确授权范围（如"可代表本人处理公司日常经营事务"）与期限。放在应急包里，并告知被授权人。
2. **股东会/董事会预案**：提前形成书面决议——在创始人无法履职期间，由谁代为履行职务。**没有这份东西，工商变更、银行付款、投标签字都可能卡死。**
3. **账户与印章的"可动性"**：确保至少有两个人在紧急情况下能合法动账（走公司制度，不是共享密码）。**只有你一个人有 U 盾的公司，你住院那天等于停业。**

### 出事时的 72 小时公司动作

| 时间 | 动作 |
|---|---|
| 24 小时内 | 由预案指定的人出面：向核心员工说明"暂时安排"，**安抚而不是解释细节** |
| 48 小时内 | 保工资：**优先保证当月工资能发**（人心一散，业务立刻塌） |
| 48 小时内 | 客户侧：大客户逐个打电话（不是群发消息），给一个明确的联系人 |
| 72 小时内 | 供应商/房东/贷款：主动沟通一次，争取延期，**别拖到对方找上门** |
| 一周内 | 授信、开票、报税等有法定时限的事，确认没有断档 |

**对外统一口径（一句话）：**

> "公司经营正常，事务由 X 暂时代理，联系人电话是 Y，其他一切照旧。"

**不要对外披露病情细节、不要对外争论家事。** 对外沟通方法见 [公司/12-危机与客诉应对](../公司/12-危机与客诉应对.md)。

## 四、身后安排第一步：把"信息"留给家人

人走之后，家人要面对的第一堵墙常常不是法律，是**"他什么都没说"**。

**这一节只讲三件事，都不需要花钱：**

1. **告诉他们应急包在哪**（不是告诉他们内容，是告诉他们"在哪、怎么打开"）。
2. **告诉他们债务情况**：欠了多少、欠谁的、有没有担保。**家人最怕的不是欠债，是不知道欠债**——一旦被起诉或被执行才发现，代价大得多。
3. **告诉他们公司的安排**：股权给谁、谁接着管、"有事找谁商量"。**一句话能省掉一场官司。**

> 有人会问："说了会不会不吉利？" 反过来想：**你把这件事说清楚，才是真的把家人放在心上了。**

## 五、遗嘱：六种形式与最常见的五个无效原因

### 1. 六种法定形式（《民法典》第 1134–1139 条）

| 形式 | 关键要件（不满足即可能无效） |
|---|---|
| **自书** | **全文亲笔书写** + 亲笔签名 + **注明年、月、日** |
| **代书** | 两个以上见证人在场；其中一人代书；遗嘱人、代书人、其他见证人**全部签名** + 注明年月日 |
| **打印** | 两个以上见证人在场；遗嘱人和见证人**在每一页签名** + 注明年月日 |
| **录音录像** | 两个以上见证人在场；遗嘱人和见证人在录音录像中**记录姓名（或肖像）+ 年月日** |
| **口头** | **仅限危急情况**；两个以上见证人；危急情况消除后能立书面/录音遗嘱的，**口头遗嘱即失效** |
| **公证** | 由公证机构办理 |

### 2. 五个高频无效原因（踩一个就白写）

1. **缺日期 / 日期不全**（自书遗嘱只签名字不写日期 → 无法判断先后，极易被推翻）。
2. **打印出来自己签字**（打印遗嘱必须有两个见证人 + 每页签名，否则无效）。
3. **见证人是利害关系人**（继承人或受遗赠人、以及与他们有利害关系的人**不能当见证人**）——最常见的是"让大儿子当见证人"。
4. **处分了不属于自己的财产**（比如把夫妻共同房产整套写进遗嘱——**你只能处分自己那一半**）。
5. **没有为"双无"继承人保留必要份额**（缺乏劳动能力又没有生活来源的继承人，法律要求保留必要份额，即"必留份"，否则相关部分可能无效）。

### 3. 一个必须知道的变化

**公证遗嘱不再优先。** 立有数份遗嘱且内容冲突时，**以最后一份为准**（《民法典》第 1142 条）。
→ 所以：**改了主意就要重新立，并且把旧的收好或销毁**，别让家人拿着几份互相矛盾的文件去猜。

### 4. 遗嘱和保险的关系（这条最实用）

- **指定了受益人的保险金，不作为遗产**，直接给受益人，**不参与遗产分配、不用先拿来还债**（《保险法》第 42 条：只有未指定受益人、受益人先身故等情形才作为遗产）。
- 所以**对配偶、子女的定向保护，保单往往比遗嘱更干净、更快、更少争议**。
- 但前提是**受益人写对、写全、写当前的**——离婚、再婚、生子后都要重新看一眼。

## 六、没有遗嘱会怎样：法定继承的顺序与比例

### 顺序（《民法典》第 1127 条）

| 顺序 | 谁 |
|---|---|
| **第一顺序** | **配偶、子女、父母** |
| **第二顺序** | 兄弟姐妹、祖父母、外祖父母 |

- 有第一顺序继承人的，第二顺序不参与。
- **"子女"包括婚生、非婚生、养子女、有扶养关系的继子女**；"父母"包括生父母、养父母、有扶养关系的继父母。
- 同一顺序继承人，份额**一般均等**（第 1130 条）；但对生活有特殊困难、缺乏劳动能力的，或被继承人尽了主要扶养义务的，可以多分。

### 两个最容易出错的地方

1. **夫妻共同财产先切一半。** 比如婚后买的房、持有的股权，**其中一半本来就是配偶的，不进入遗产**；只有属于你的那一半才由全体第一顺序继承人分。所以"配偶能拿到 1/2 + 剩余部分的均分"。
2. **债务要先还。** 分割遗产前要先清偿被继承人的税款和债务（第 1159 条）；继承人对债务的清偿责任**以所得遗产的实际价值为限**——**超出部分不用自己掏**（第 1161 条）。放弃继承的，可以不负清偿责任，但放弃要**在遗产处理前书面作出**。

> **给你的一个现实提醒**：如果你和父母、兄弟姐妹关系复杂，或者有公司股权，**不要只靠法定继承**。默认规则是"均等分给一堆人"，而公司股权被平均分给四五个人，基本等于控制权解散。**这是必须提前立文件的原因**。

## 七、公司股权怎么继承：别再"想当然"

**关键点：继承人并不当然成为公司股东。**

- 法律允许自然人股东死亡后其合法继承人继承**股东资格**，但**公司章程另有规定的，从其规定**。
- 也就是说：**公司章程可以约定"股权不得继承，只能由其他股东按约定价格收购"**（这叫"继承限制条款"）。

**这意味着两件事：**

1. **你有章程，就可以提前把规则定好**——比如约定由某位股东或公司按公式价回购，把补偿款给继承人。**在 [公司/13-合伙人股权与散伙预案](../公司/13-合伙人股权与散伙预案.md) 的框架里，这是"退出与传承"必须写进去的一条。**
2. **你没写，就按默认来**——你的配偶、子女、父母将共同成为股东。**客户、员工、投资人都要面对一个突然多了四五个股东的公司。**

**如果你是被继承方（比如父母是股东）**：先看公司章程怎么写的；没有约定的，与其他继承人和其他股东协商"由一人继承股东资格、其他人拿折价补偿"通常是各方都更能接受的结果。**别急着去工商变更，先看清楚章程与股东协议。**

## 八、数字资产交接：不写清楚，就是永久丢失

这部分不是"钱"的问题，是**"家人连你的照片和资料都拿不到"**的问题。

| 类别 | 交接要求 |
|---|---|
| **手机** | 解锁方式写进密封信（家人拿不到手机 = 什么也处理不了） |
| **云相册 / 网盘** | 账号 + 恢复邮箱；如有"遗产联系人"功能（部分平台提供）请开启 |
| **微信 / 支付宝** | 余额与理财的提取渠道、客服电话；**账号本身通常不能继承**，但余额可依法处理 |
| **邮箱** | ★最关键——**几乎所有账号的找回都靠它**，必须先给家人留通道 |
| **域名 / 服务器 / 代码仓库** | 续费主体、账号、自动续费绑定的卡；**域名过期 30 天就可能被别人抢注** |
| **加密钱包 / 交易所** | 助记词、私钥、平台账号**单独密封**，并写清"这是什么、别丢、怎么用"（★丢失不可恢复） |
| **公司系统** | 财务软件、开票系统、电商后台的管理员账号 |

**做法**：用密码管理器（如 1Password/Bitwarden）建一个"紧急访问"条目，指定家人可在你失能/身故后申请访问；同时留一份**纸质密封信**，写明"主账号 + 怎么申请紧急访问"。详细方法见 [个人与人际/05-数字资产与账号安全](../个人与人际/05-数字资产与账号安全.md)。

> **加密资产特别提醒**：助记词**不要和手机放在一起**，也不要只存在唯一一份电子文件里。它既是资产，也是家人在你最不希望的时候能拿走全部现金的钥匙——**要设计成"只有按正确顺序、走正确流程才能拿到"**。

## 九、还要提前准备的两份文件（各一页纸）

### 1. 授权委托书（授权他人代你办事）

**用途**：出差、住院、失联时，有人能合法处理你的事务（银行、房产、公司、公务）。
**要点**：写清授权范围、期限、是否可转委托；**范围要具体**（别写"全权代理"这种模糊到容易被质疑或被滥用的表述）。

> 可直接抄的样张见 [附录/05-可直接抄写的模板样张](../附录/05-可直接抄写的模板样张.md) 第四节「授权委托书（突发失能时家人能代办事务）」。

### 2. 意定监护（授权他人替你做决定）

**用途**：在你**丧失或部分丧失民事行为能力**时（重病、认知症、意外昏迷），由你事先指定的人担任监护人，决定医疗、财产、照护安排（《民法典》第 33 条）。
**为什么重要**：**没有它，法定监护顺位可能让你最不放心的人来做决定。**
**要点**：**必须书面**；建议公证；把文件放进应急包并告知指定人（详见 [06](06-父母养老与照护实操.md) §十）。
