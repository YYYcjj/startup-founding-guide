## 一、家庭财务底线

家庭是比外部亲友更核心、更优先的圈子。只有内部稳固，才能守住财富、享受成果。

### 1. 财务安全垫（高优先级）
- 无论公司经营好坏，家庭账户里至少留 **6–12 个月家庭生活费**，独立于公司账户。
- **公司与个人账户严格分开**，避免财产混同（否则可能丧失有限责任保护）。

### 2. 保险配置：怎么买（高优先级）

**原则一句话：先保"赚钱的人"，再保不赚钱的；先保障，后理财。**

**四件套各保什么 / 给谁买 / 大概买多少：**

| 险种 | 保什么 | 给谁 | 保额参考 | 备注 |
|------|--------|------|----------|------|
| **定期寿险** | 身故/全残赔一笔给家人 | 经济支柱 | 房贷余额 + 5–10 年家庭年开支 | 买到 60 岁即可，最便宜、最该先买 |
| **重疾险** | 确诊即一次性赔付，补收入损失 | 支柱→配偶→孩子 | 30–50 万起，或年收入 3–5 倍 | 买**定期**（保至 60/70）比终身便宜很多；越年轻越便宜、越好过健康告知 |
| **百万医疗险** | 住院大额医疗费报销 | 全家（含父母） | 保额几百万 | 几百元/年，注意 1 万免赔额与续保条件 |
| **意外险** | 意外身故/伤残/意外医疗 | 全家，职业风险高者优先 | 保额 = 年收入 5–10 倍 | 一年一两百，杠杆最高 |

**预算纪律：** 全家保费控制在 **年收入 5–10%**。警惕被推销"理财型/返还型/两全型"产品——**先保障后理财**，别用保险当投资。

**购买顺序：** 经济支柱（定寿→重疾→医疗→意外）→ 配偶 → 孩子（重疾+医疗即可，**孩子不需要寿险**）→ 父母 55+（重疾贵且难过健康告知，改配 **防癌医疗险/惠民保 + 意外险**）。

**避坑清单：**
- 返还型/两全险慎买：贵、保障弱，"没出事返钱"的钱来自你多交的保费。
- 分红/万能险当理财卖：先保障配齐了再谈理财，顺序不能反。
- **健康告知如实填**：隐瞒既往病史，理赔时会被拒赔。
- 留意**等待期**（通常 90–180 天）：期内出险不赔，别"买完就体检"卡在等待期里。
- 别买"全家人一张单"的打包产品却不看条款；逐项看"保什么、不保什么、怎么赔"。
- 百万医疗重点看：免赔额、续保是否需审核、院外药是否报销。

**理赔 4 步：** ① 就医/出事第一时间联系保险公司报案；② 问清需要哪些材料（发票、诊断证明、费用清单、病历）；③ 材料一次性留全、拍照存档；④ 被拒赔先翻条款对质，必要时找专业人士协助复议。

**每年一次"保单体检"**：收入涨了保额要不要加、有没有重复购买、受益人是否仍正确。

### 3. 法律与财产安排（中优先级）
- 立一份简单**遗嘱**或做财产规划咨询，避免继承纠纷。
- 检查公司与个人财务边界，补签必要协议。
- **资产隔离**（前瞻）：防公司债务牵连家庭——独立账户只是第一步，公司做大前就做架构。
- **授权委托书**（前瞻）：突发失能/失踪时，家人能合法处理你的事务和账户。
- 警惕代持风险（用别人名义持股/买房隐患大）。

### 4. 子女与未来（中优先级）
- 为子女设立**教育金账户**，开始定期储蓄。
- 制定家庭年度预算，控制不必要消费。
- **教育观前瞻**：价值观与独立能力培养 > 只存钱；别用钱替代陪伴。

### 5. 幸福感（中优先级）
- 每年安排一次全家体检和一次旅行，提升幸福感与凝聚力。
- 学习基础税务和资产配置知识，或咨询专业顾问。

### 6. 家庭预算与记账模板（可直接抄）

**起步框架——"50 / 30 / 20"三分法：**
- 50% 必要支出：房贷/房租、水电燃气、伙食、交通、保险（按年摊月）
- 30% 可选支出：餐饮娱乐、旅行、购物、人情
- 20% 储蓄与投资：安全垫、教育金、长期投资

收入不稳定（创业期）时改成**"先储蓄后消费"**：发薪/回款先进 20% 储蓄，剩下的再安排花销。

**月度预算表（复制到表格/记账 App 即可用）：**

| 类别 | 明细项 | 预算 | 实际 | 差额 | 备注 |
|------|--------|------|------|------|------|
| 必要 · 住 | 房贷/房租 | | | | |
| 必要 · 生活 | 水电燃气/话费/网费 | | | | |
| 必要 · 吃用 | 伙食/日用/通勤 | | | | |
| 必要 · 保险 | 年缴保费 ÷ 12 | | | | 大项按月摊，防某月爆表 |
| 家庭 · 教育 | 子女教育金（固定储蓄） | | | | |
| 家庭 · 赡养 | 给父母的月钱 | | | | |
| 可选 · 娱乐 | 餐饮/购物/旅行 | | | | |
| 可选 · 人情 | 份子钱/礼物 | | | | |

| **合计** | | | | | |

**记账三习惯：**
1. 连续记 **3 个月**才形成真实基线，别第一月就焦虑超支。
2. 每月 20 分钟复盘：超支项问一句"必要还是想要"，不指责只调整。
3. 每季度滚动调整一次预算（收入/家庭阶段变了就重排比例）。

### 7. 家庭行动清单
| 序号 | 行动 | 优先级 |
|------|------|--------|
| 1 | 开设家庭独立银行账户，存够 6 个月生活费 | 高 |
| 2 | 为经济支柱配基础保险（重疾/医疗/意外/定寿） | 高 |
| 3 | 与配偶沟通财务透明机制，大额支出需双方同意 | 高 |
| 4 | 检查公司与个人账户是否分开，补签协议 | 高 |

| 6 | 为子女设教育金账户，定期储蓄 | 中 |
| 7 | 制定家庭年度预算并启用记账（用上 [§6 模板](#6-家庭预算与记账模板可直接抄)）| 中 |

## 二、健康：风险保障与身心管理

### 1. 健康风险的财务保障
> 原对话对健康的处理集中在「用保险和体检对冲健康风险」，并非饮食/运动等生活方式建议。
- **全家年度体检**：早发现早处理，比治病便宜得多。
- **健康类保险是核心防线**：重疾险（一次性赔付补收入）、医疗险（报销医疗费）、意外险（意外医疗/身故）——**"怎么买/买多少/避坑"详见上文 [一.2 保险配置](#2-保险配置怎么买高优先级)**。
- **每年一次家庭旅行**：既是放松，也是关系黏合剂，间接利好健康。
- 创业/有钱后最容易透支的是健康，**把「健康保障」当固定支出排进家庭预算**，别等出事才补。

### 2. 身心管理（创业高压，最易被忽略）★
- 创业高发焦虑、孤独、burnout——**健康不能只靠体检**。
- 要有疏压方式（运动/爱好）、有可倾诉的对象（伴侣/朋友）。
- 必要时找专业支持（心理咨询）。
- 长期高压会反噬家庭关系，把「心理精力」当独立维度单列管理。

## 三、婚姻经营：人生最重要的长期合伙

婚姻对创业者尤其重要：伴侣质量直接影响事业成败与财富安全。伴侣是"核心家庭"的另一半，边界与经营同等重要。

### 选伴侣看四维度（不只看感觉/外貌/条件）
1. **价值观**：钱怎么看、怎么花、对家庭的责任。
2. **性格**：情绪稳定、能沟通。
3. **能力**：独立解决问题、共同扛事。
4. **原生家庭**：相处模式会潜移默化带入新家庭。

### 经营婚姻四原则
- **财务透明**：大额支出共识，不与家庭账户混同。
- **情感连接**：定期交流，不只用钱代替陪伴。
- **共同成长**：事业与家庭同步往前。
- **边界清晰**：与原生家庭、亲友保持合理距离。

### 创业者的婚恋边界意识
- 婚前/婚内财产协议（股权、房产提前约定）——成长期再深做，先有意识。
- 伴侣知情权：公司债务、担保、大额负债要让伴侣知情，避免"突然背锅"。

> 「婚姻不是 1+1=2，而是 0.5+0.5=1」——各自削去一半的任性，才合成一个完整的家。好的伴侣是无后顾之忧的资产，糟糕的伴侣是最大风险源。

## 四、前瞻：父母养老与财富传承（成长期再深做，先有意识）

### 1. 父母养老（别只想到每月给钱）
- 查父母**医保缺口**，补商业医疗险。
- 失能照护安排、养老储备要提前想。
- 大病/失能场景的兜底方案。

### 2. 财富管理与传承
- 不把身家全押公司；留应急现金 + 分散投资。
- 学个税/投资税务常识；警惕「有钱后被推销」的坑。
- 传承预案：重疾/意外兜底、信托/保险、公司退出机制、税务居民身份——高阶但值得早想。
