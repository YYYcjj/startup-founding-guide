## 一、先分清四种"投资"（风险和能力要求完全不同）

| 类型 | 你投入什么 | 典型场景 | 核心风险 | 能力门槛 |
|------|-----------|----------|----------|----------|
| **自营项目** | 时间 + 精力 + 钱 | 创业、副业 | 需求是假的、现金流断 | 最高（要全能）|
| **股权投资他人项目** | 钱（+ 资源）| 投朋友的店/初创公司 | 团队、退出无门 | 高（要看人）|
| **债权/借款** | 钱 | 亲友周转、P2P 类 | 本金收不回 | 中（看信用）|
| **金融理财/新兴资产** | 钱 | 股票、基金、加密、大宗 | 波动、归零 | 中低（要自律）|

> **一句话纪律**：能用"闲钱"投的只有后两类；自营和股权投的是"亏得起的部分"。

### 1.1 能力 vs 投入匹配

| 你的能力 | 适合投 |
|----------|--------|
| 看不懂财务报表 | ❌ 不要碰股票个股 / 加密合约 |
| 没看过行业 | ❌ 不要碰陌生行业股权 |
| 没时间管理 | ❌ 不要碰需要高频操作的产品 |
| 懂法律 | ✅ 可做债权投资尽调 |
| 懂财务 | ✅ 可做股票/基金二级市场 |
| 懂技术 + 有行业经验 | ✅ 可做行业内早期股权投资 |

> **匹配原则**：**不要碰超出能力圈的"机会"**——那不是机会，是别人收割你的入口。

## 二、看项目：尽调九问（投资/加入前逐个回答）

> 九问里 ≥3 个答不上/含糊 = 再等等。**看得懂才投，看不懂就是赌**。

### 2.1 必答九问（含子问题）

#### 1. 解决什么问题？

| 子问题 | 答案要点 |
|--------|---------|
| 目标客户的痛点是什么？ | 是真痛还是想象痛？ |
| 客户当前怎么解决这个问题？ | 替代方案是什么？成本多少？ |
| 你提供的方案比替代好在哪？ | 差异化 + 可量化优势 |
| 客户**愿意付费**（不是"需要"）？ | 付费意愿 ≠ 需求 |

#### 2. 市场多大、多快？

| 子问题 | 答案要点 |
|--------|---------|
| 目标人群数量 | TAM（总市场）/ SAM（可触达）/ SOM（你能拿到的）|
| 客单价 | 平均客单价 + 客户终身价值（LTV）|
| 渗透率 | 当前渗透率 + 未来 3–5 年增长 |
| 市场在变大还是变小？ | 趋势 + 周期位置 |

#### 3. 团队怎么样？

| 子问题 | 答案要点 |
|--------|---------|
| 创始人是否全职？ | 兼职投入 = 项目多半黄 |
| 历史有没有做成过事？ | 失败可以，没做成过 = 警惕 |
| 能力和性格是否互补？ | 2 人搭档最好互补 |
| 是否有"毒"特征？ | 控制欲过强 / 不容异议 / 把所有功劳归自己 |
| 合伙人关系如何？ | 长期共事能力 > 商业能力 |

> **人不对，事再好也不投**。

#### 4. 怎么赚钱？

| 子问题 | 答案要点 |
|--------|---------|
| 商业模式一句话说清？ | 不能一句话说清 = 你也不懂 |
| 单位经济模型： | **单客户收入 - 单客户成本 - 获客成本 = 单客户毛利** |
| LTV / CAC 比值 | 健康：LTV ≥ 3× CAC |
| 毛利率 | 多数 SaaS 60%+；服务 30–50%；零售 20–40% |

#### 5. 有没有壁垒？

| 类型 | 例子 |
|------|------|
| **品牌** | 可口可乐 / 茅台 |
| **技术 / 专利** | 高端制造 / 半导体 |
| **网络效应** | 微信 / 滴滴 |
| **成本优势** | 规模制造 / 供应链 |
| **牌照 / 资质** | 金融 / 医疗 |
| **数据壁垒** | 训练数据 / 用户行为 |

> **没有壁垒的生意会被抄死**。

#### 6. 现金流怎么样？

| 子问题 | 答案要点 |
|--------|---------|
| 账上现金能撑几个月？ | runway（月数）= 现金 ÷ 月烧钱 |
| 烧钱速度 vs 收入增速 | 增速 > 烧钱 = 良性；反之 = 倒计时 |
| 何时能盈亏平衡？ | 真实预期，**别信"明年就盈利"** |
| 是否依赖外部输血？ | 下一轮融资谁接？ |

#### 7. 竞争格局？

| 子问题 | 答案要点 |
|--------|---------|
| 直接对手 | 谁在做？市占多少？ |
| 间接对手 | 替代方案 / 跨界竞争 |
| 凭什么你赢？ | 差异化 + 不可复制 |

#### 8. 合规干净吗？

| 子问题 | 答案要点 |
|--------|---------|
| 资质证照齐全？ | 行业准入 |
| 税务合规？ | 历史无重大违规 |
| 股权结构清晰？ | 无代持、无纠纷 |
| 潜在诉讼？ | 历史 + 在审案件 |

#### 9. 怎么退出？

| 方式 | 适合 | 时间 |
|------|------|------|
| 分红 | 成熟期盈利 | 持续 |
| 被并购 | 成长期被巨头看上 | 3–7 年 |
| 上市 | 行业头部 | 5–10 年 |
| 股权转让给下家 | 早期投资人 | 3–5 年 |

> **没有退出路径的投资是捐款**。

### 2.2 尽调加分项（多问几句心里更有底）

| 加分项 | 怎么查 |
|--------|--------|
| **客户访谈** | 找 3–5 个现有客户聊聊，不靠创始人 |
| **离职员工访谈** | LinkedIn / 脉脉找前员工聊真实情况 |
| **竞品对比** | 自己用一遍竞品 |
| **财务三表** | 近 3 年资产负债表/利润表/现金流量表 |
| **银行流水** | 大额投资可要求看对公账户流水（需签保密）|
| **工商档案** | 国家企业信用信息公示系统（公开） |
| **司法风险** | 中国裁判文书网（看诉讼记录）|
| **税务信用** | 部分地区公开查询 |

## 三、"不投"红线表（挡掉九成坑）

| 红线 | 一眼识别 | 真实案例 |
|------|----------|----------|
| ❌ **承诺保本/固定高收益** | 收益与风险不对称 = 骗局或资金盘 | P2P 暴雷 / 某些"理财"产品 |
| ❌ **拉人头返佣的"项目"** | 靠发展下线赚钱，产品只是道具 | 传销 / 一些微商盘 |
| ❌ **创始人简历造假/查无此人** | 尽调第一关就不过 | 一些"区块链"项目 |
| ❌ **催你马上打钱、"错过就没了"** | 制造紧迫感是收割的前置动作 | ICO / 私募盘 |
| ❌ **商业模式讲不清靠"情怀/愿景"** | 讲不清怎么赚钱的，通常不赚钱 | 一些"颠覆性"创业 |
| ❌ **自己不投钱只让你投** | 创始人没下注，凭什么叫你下注 | 朋友拉你投他的项目 |
| ❌ **高杠杆/合约类"理财"** | 加了杠杆的"投资"本质是赌博 | 加密合约 / 外汇杠杆 |
| ❌ **拿不出财务数据** | 真正在做事的不怕你看账 | 一些"内部渠道"项目 |
| ❌ **签字时不让咨询律师** | 怕你看出问题的协议 = 有问题 | 一些对赌协议 |
| ❌ **刚兑宣传 / 监管套利** | 任何承诺"国家政策保护"都要查实 | 一些"境外理财" |

> **黄金规则**：让你签"保密协议 + 不许问律师 + 限时限地" 的项目，**100% 是骗局**。

## 四、仓位与风险纪律（保住本金才能谈收益）

### 4.1 仓位铁律（5 条）

1. **只用闲钱**：亏光不影响生活的那部分钱（家庭安全垫之外的，见 [家族/01](../家族/01-家庭与健康规划.md)）。
2. **单项目仓位上限**：单项目 ≤ 可投资资产的 **10–20%**；单一品类合计 ≤ 50%。
3. **设止损线**：亏到 X%（建议 20–30%）就撤，**不补仓摊平"感觉会涨"的标的**。
4. **分散 ≠ 乱投**：分散到 3–5 个不相关方向才有意义，同赛道投 10 个等于投 1 个。
5. **定期复盘**：每季度看一次仓位与逻辑，逻辑破了就走，别恋战。

### 4.2 仓位计算公式（直接套用）

**前提**：你的可投资资产 = 总资产 - 家庭安全垫（6–12 月生活费）- 保险覆盖后剩余。

```
例子：总资产 200 万，安全垫 30 万，保险已配，可投资 = 170 万
├── 现金/货币基金：30%（51 万）应急用，随时可取
├── 稳健理财（债基/银行理财）：30%（51 万）低风险
├── 股票/股票基金：20%（34 万）中风险
├── 加密/新兴资产：5–10%（8.5–17 万）高风险
└── 个体项目股权：5–10%（8.5–17 万）极高风险
```

### 4.3 仓位决策表

| 你的资产规模 | 单项目上限 | 单一品类上限 | 备注 |
|--------------|-----------|------------|------|
| < 50 万 | 1–3 万 / 项目 | 10 万 | 小额试错 |
| 50–200 万 | 5–10 万 / 项目 | 30 万 | 标准配置 |
| 200–500 万 | 10–30 万 / 项目 | 100 万 | 可考虑专业咨询 |
| > 500 万 | 5–10% / 项目 | 不超过 50% | 建议找独立财务顾问 |

### 4.4 投资是放大器不是发动机

- **先有稳定现金流**，再用投资放大；现金流不稳时重仓投资 = **双重赌博**。
- 投资盈亏是 ±20%，但生活现金流断了就是 100% 的事。
- **顺序**：先健康/保险 → 安全垫 → 稳定收入 → 投资。

### 4.5 加仓与减仓纪律

| 动作 | 触发 | 怎么做 |
|------|------|--------|
| **加仓** | 投资逻辑被验证 + 价格跌到合理区间 | 分 3–4 次加仓（不是 1 次 all in）|
| **减仓** | 投资逻辑被破坏 + 达到止盈/止损线 | 按计划减，**不要"再等等"** |
| **清仓** | 看错了 / 出现红线信号 | 立即清，**承认错误比亏损更值钱** |

## 五、加密 / 新兴资产的特别提醒（波动与"归零"风险远高于传统资产）

> 仅作风险提示，不含任何买卖建议。以下每一条都对应过真实爆仓/归零案例：

### 5.1 加密 5 大风险点

| 风险 | 真实案例 | 防御 |
|------|----------|------|
| **合约/杠杆** | 高杠杆下 10% 反向波动即爆仓归零 | 把杠杆当工具前，**先确认你能接受本金归零** |
| **"喊单"与社群带单** | 荐币群/付费带单/内幕消息——喊单者赚的是你的手续费或对手盘 | 警惕"老师带你赚钱" |
| **新币/土狗/空气项目** | 多数生命周期极短，流动性说没就没 | **提现不了的价格都是数字** |
| **交易所/钱包风险** | FTX 暴雷 / 各类小型交易所跑路 | 选头部、2FA、密钥冷存储 |
| **地址钓鱼** | 假 App / 假网站骗授权 | 严格核对合约地址 + 不点不明链接 |

### 5.2 加密仓位更严

- 高波动资产建议单品种仓位更低（如 5–10%），止损更机械（-20%）。
- 合约仓位**永远** ≤ 现货仓位的 1/4——永远不要"all in 合约"。
- **只投看得懂逻辑的**：一句话讲不清它为什么值钱，就别投。

### 5.3 加密资产安全实操（呼应 [05-数字资产](../个人与人际/05-数字资产与账号安全.md)）

| 操作 | 要点 |
|------|------|
| 交易所 | 头部（OKX/币安/Coinbase）+ 2FA（不用短信）+ API Key 只开读取、不开提现 |
| 钱包 | 大额冷钱包（Ledger/Trezor）+ 小额热钱包日常用 |
| 助记词 | 手写 + 金属助记板 + 保险柜，**绝不截图、绝不发聊天** |
| 授权 | 定期用 revoke.cash / etherscan 撤销不用的合约授权 |
| 提现地址 | 大额提现先小额测试 + 二次确认 |

## 六、小额试水原则（把学费降到最低）

### 6.1 试水流程

```
1. 新方向/新品类先投最小可验证金额（本金的 1–5%）
2. 设 3–6 个月观察期
3. 跑通逻辑 → 加仓（分 3–4 次）
4. 跑不通 → 止损，记录复盘
```

### 6.2 决策笔记本（每次投入都记）

```
【项目/标的：XXX】
- 投资日期：
- 投入金额：___ 元（占可投资资产 ___%）
- 投资理由（逻辑）：
  1. 解决了什么痛点？
  2. 为什么这个标的能赢？
  3. 退出路径是什么？

- 止损线：亏损 ___% 清仓
- 止盈线：盈利 ___% 部分减仓

【3 个月后复盘】
- 逻辑被验证了吗？
- 现在的判断是？
- 动作：继续 / 加仓 / 减仓 / 清仓
- 学到了什么？
```

> **价值**：5 年后回看，**你的决策笔记比账户余额更值钱**——它暴露你的认知盲区。

### 6.3 情绪管理

| 状态 | 应对 |
|------|------|
| **连续赢** | 别上头，**回归仓位纪律**——运气赚的钱不一定是你的能力 |
| **连续亏** | 别回本心切，**暂停 1–2 周**，复盘后再动 |
| **听到"暴富"案例** | 警惕幸存者偏差，**绝大多数亏的人不会告诉你** |
| **市场大跌时想抄底** | 分 5 次抄，**永远留子弹**——不知道底在哪 |
| **市场大涨时想追** | 想清楚 FOMO（错失恐惧症）是不是决策主因 |

> **情绪是仓位最大的敌人**——**计划你的交易，交易你的计划**。

## 七、不投的具体清单（5 类典型陷阱）

### 7.1 "高息理财" 类

| 特征 | 实质 |
|------|------|
| 承诺年化 10%+ 保本 | 不可能三角（高收益+低风险+保本）不存在 |
| "国家政策支持" / "一带一路" | 拉大旗 |
| 拉新人有奖励 | 传销结构 |

### 7.2 "原始股" 类

| 特征 | 实质 |
|------|------|
| 低价买入"即将上市"公司股票 | 99% 是骗局（真公司不会找你）|
| 承诺"上市后翻 N 倍" | 上市路径/时间全靠嘴 |
| 必须签保密 + 不许律师看 | 怕露馅 |

### 7.3 "带单跟单" 类

| 特征 | 实质 |
|------|------|
| "老师"晒盈利截图 | P 图 / 模拟盘 / 拉新人费 |
| 群里有"学员"晒感谢 | 托 |
| 收会员费 / 跟单费 | 他赚的是你交的钱，不是市场 |

### 7.4 "虚拟币/外汇合约" 类

| 特征 | 实质 |
|------|------|
| 高杠杆 100x、50x | 爆仓机器 |
| 平台在你不知情时插针 | 操纵价格 |
| 出金困难/冻结 | 跑路前兆 |

### 7.5 "熟人项目" 类

| 特征 | 实质 |
|------|------|
| 朋友创业找你入股 | 99% 失败，感情 + 钱双输 |
| 同学/老乡项目"内购" | 拉你垫背 |
| 亲戚推荐"内部渠道" | 你懂他懂，"内部"就是割你 |

> **处理**：所有"熟人项目"按陌生人项目同等严格尽调，**不因关系降低标准**。

## 八、季度体检（10 项清单）

```
【第 X 季度 · 投资体检】

□ 仓位：单项目 / 单一品类占比是否超上限？
□ 现金：是否有 ≥ 6 个月生活费的安全垫？
□ 止损：是否有标的触发止损线未执行？
□ 复盘：本季度盈亏的根本原因（能力 vs 运气）？
□ 决策笔记：本季度所有投资是否都记录了理由？
□ 认知：本季度学到了什么新的投资认知？
□ 红利：是否还在有效策略上？有没有发现新的红利？
□ 健康：投资是否影响睡眠/情绪/家庭？
□ 资产配置：现金/股票/债券/另类 比例是否合理？
□ 行动：下季度计划（加仓/减仓/再平衡）
```
