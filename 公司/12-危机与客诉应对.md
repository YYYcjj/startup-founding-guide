# 12 危机与客诉应对：出事了怎么不塌房

> 同板块：[06-经营风险](06-经营风险.md) ｜ [09-招人与用人](09-招人与用人.md) ｜ [10-报价与收款](10-报价与收款.md)

> 定位：所有公司都会出事——**差别不在"会不会出事"，在出事后的 48 小时你怎么接。**
> 接得好，危机变口碑；接得烂，小事烧成公关灾难。本篇覆盖：客诉 / 重大失误 / 差评舆论 / 内部危机。

---

## 1. 先分清危机的类型

| 类型 | 例子 | 处理重点 |
|------|------|---------|
| **客诉** | 交付质量差、延期、态度问题 | 快回应 + 给方案 |
| **产品/交付事故** | 数据丢失、货发错、服务中断 | 止损 + 赔偿边界 |
| **舆论/差评** | 平台差评、被挂、负面发酵 | 公开回应专业度 |
| **内部危机** | 员工仲裁、离职带走客户、泄密 | 按法律流程走（[09-招人用人](09-招人与用人.md)）|
| **合规危机** | 被查/被罚 | 先找律师，别自己扛（[06-经营风险](06-经营风险.md)）|

## 2. 客诉处理五步法（大多数情况够用）

1. **接住情绪**：先让人说完，别打断、别辩解。"我理解您的感受，这事确实让人恼火。"（一句共情，火消一半）
2. **道歉但不揽全责**："给您添麻烦了，非常抱歉。"——道歉是针对"结果"，不是急着认"全错"（责任边界等查清再说）。
3. **给方案**：别只道歉，给 1–2 个可选方案（重做/退款/补偿/加急）。
4. **补偿边界**：先解决事情，再谈钱；小公司**赔偿以"客户满意 + 不伤现金流"为上限**（见 [10-报价与收款](10-报价与收款.md)），别为面子开天价。
5. **复盘**：处理完问一句"怎么会发生？"，修流程而不是修这一次（[05-项目管理](05-项目管理.md) 复盘）。

> **难缠客户**：给台阶 + 定底线。话术："您的要求我理解了，我们能做到的是 A 和 B，您看选哪个？如果都不接受，我们也尊重您的选择，按合同约定处理。"——**把纠缠拉回选择题**。

## 3. 重大失误 / 舆论危机：黄金四原则

- **快**：黄金 24–48 小时。装死 = 让别人替你讲故事。
- **诚实**：承认事实，别甩锅、别撒谎——**一个谎言需要十个谎言圆，被拆穿时信誉归零**。
- **担责**：先表态负责，再讲补救措施；把"我们很抱歉"换成"我们已做 X、Y 两步"。
- **不过度承诺**：只承诺能兑现的，兑现后再说下一步（承诺没做到 = 二次危机）。

**公开回应模板结构**（发公告/回复用）：
> ① 承认事实（我们注意到/经核实，确实发生……）
> ② 表态（对此深表歉意，责任在我们）
> ③ 已采取措施（已第一时间……/涉事环节已暂停）
> ④ 给期限（X 个工作日内给出完整处理结果）
> ⑤ 留通道（后续进展我们会在 XX 同步）

**别做清单**：删差评、拉黑客户、雇水军洗地、甩锅员工/客户/平台、装作没看见——每条都会让火更大。

## 4. 差评与舆论管理（专业地"回给第三方看"）

- 平台差评不只是回给那个客户，是**回给所有围观的人**：态度专业、有解决方案，路人看了反而加分。
- 回复公式：**共情一句 + 事实澄清（如有）+ 已做的补救 + 邀请私信解决**。
- 恶意差评/同行抹黑：保留证据，平台申诉；必要时发声明，但**不隔空对骂**。

## 5. 内部危机：员工仲裁与离职泄密

- 仲裁：平日留证据（工资记录、合同、绩效/警告书面记录），真到仲裁你才有底气——**临时补证据 = 没用**（[09-招人与用人](09-招人与用人.md) 辞退一节）。
- 离职带走客户/泄密：靠保密与竞业协议 + 权限回收（离职当天收回系统、改密码，见 [05-数字资产与账号安全](../个人与人际/05-数字资产与账号安全.md)）。
- 与员工有分歧：先按合同和流程走，情绪归情绪，钱的事谈钱。

## 6. 危机后 48 小时动作清单

- [ ] 0–4h：确认事实（别听一面之词，先核实）
- [ ] 4–24h：内部统一口径（谁对外说话？只说哪些？）→ 联系受影响方/发初步回应
- [ ] 24–48h：给出补救方案与期限；涉及合规/赔偿金额大 → 咨询律师
- [ ] 48h 后：执行补救 → 复盘根因 → 把改进写进流程（防复发）
