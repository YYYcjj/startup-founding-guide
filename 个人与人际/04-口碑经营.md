> 定位：口碑是你的**隐形名片**——客户、合伙人、投资人先信你这个人，才信你的事。
> 本文把"要有好口碑"展开成**可执行的完整系统**：定位一句话 → 靠谱的行为清单 → 内容复利打法 → 边界与修复 → 可抄的介绍模板 → 评价管理（要好评 / 接差评）→ 口碑证据库。

---

## 一、专业形象：一句话说清你

### 1.1 一句话定位公式

> **我是谁 + 为谁解决什么问题 + 凭什么是我**

- 例（代运营）："我帮中小电商老板做抖音代运营，3 年带过 60 个账号，最差的一个月也有 2 万播放。"
- 答不出 = 定位没想清。**先打磨这句话**，它是你所有介绍、名片、签名的母版。
- 检验标准：第一次见面的陌生人听完，能在 10 秒内说出"你是干嘛的、能不能帮到我"。

### 1.2 对外形象一致性清单

| 渠道 | 要统一什么 |
|------|-----------|
| 微信/头像/昵称 | 真实姓名或统一品牌名，别一三五一个名 |
| 签名 | 一句话定位 + 联系方式 |
| 自我介绍 | 同一套模板，别每次现编 |
| 朋友圈/内容 | 与定位一致的行业内容，别今天卖货明天晒鸡汤 |
| 名片/报价单 | 同一 Logo、同一句话 |

> 原则：形象不是装门面，是**降低别人的认知成本**——别人一眼知道你做什么、能不能合作，就愿意把你放进"可合作名单"。

## 二、靠谱：积累出来的信任

### 2.1 靠谱 = 承诺闭环

- 核心行为：**事事有回应、件件有着落**。别人托的事，无论成不成，给一个明确结果——"办不了"也是结果，最怕"没下文"。
- **承诺最小化，交付超预期**：答应 3 天给，2 天给 = 惊喜；答应 2 天，3 天给 = 失信。**永远给承诺留缓冲**。
- 靠谱的底层是**可预测**：客户知道你答应的事一定会做到，才会把更大的事交给你。

### 2.2 靠谱行为清单（对照自检）

- [ ] 收到消息 24h 内回复（哪怕只是"收到，X 号前答复"）
- [ ] 承诺的事写进待办，设置到期提醒，不靠脑子记
- [ ] 要延迟时**提前**告知 + 新时限，不等到期才说
- [ ] 自己搞不定的，明确说不 + 推荐能搞定的人
- [ ] 出错了先认错补救，不找借口不甩锅

### 2.3 信任账户模型

把信任想象成银行账户：
- **存款**：按时交付、说到做到、主动帮忙、诚实透明
- **取款**：拖延、失信、隐瞒、推责
- 关键认知：**存款是慢慢攒的，取款是一瞬间的**——账户透支一次，可能需要十次存款才补得回来。别做"一次性透支"的蠢事。

## 三、个人内容 / IP：让信任有复利

### 3.1 为什么要做内容

- 内容是**低成本获客 + 信任前置**：客户还没见到你，先通过内容认识你、信任你，成交成本大幅下降。
- 行业观点、案例复盘、踩坑分享——**不需要文笔好，需要真实有用**。
- 输出的过程本身在帮你理清业务（输出倒逼输入，联动 [02-能力成长](02-能力成长.md) 复盘闭环）。

### 3.2 打法：一致性 > 爆款

- **先定内容主题**：围绕你一句话定位展开的 3–5 个子话题（如代运营：选品 × 投流 × 内容 × 避坑）。
- **节奏优先**：每月 ≥1 篇高质量（或每周 1 条短的），比"憋大招半年一更"强一万倍。
- **爆款随缘，一致性是底线**：持续输出的人会自动吸引同频客户与合作伙伴；断更 = 从人们记忆中消失。
- 选题来源：客户问得最多的问题（那就是市场痛点）→ 答成文章。

### 3.3 内容主题库（先列 10 个）

一次性列 10 个"我能写、客户关心"的题目存进备忘录，想发时随手取，不用每次现想——**列题比写作更耗心力，先解决它**。

## 四、口碑的边界：别透支信任

### 4.1 拒绝比硬撑更保值

- 做不到的事**早说"不"**，好过硬扛后失信——拒绝是短痛，失信是长痛。
- 拒绝话术：见 [02-能力成长](02-能力成长.md) 5.2 的"说'不'清单"（三句现成话术），核心是**少解释、平和坚定、给替代方案**。
- 接单前评估"能力 × 时间 × 利润"：三样缺一样，果断不接或转介。

### 4.2 名声与实力：先于名声补齐实力

- 被捧得越高，一次翻车摔得越重。**内容/宣传里的能力 ≤ 实际能力**，留 20% 余量。
- 一次欺骗的代价 > 十次守信积累的收益——口碑坏了，业务就断了（同 [01-商业关系](01-商业关系.md) 第 7 节）。
- 客户夸你时，别顺着吹——把功劳分给团队和事实，反而更可信。

### 4.3 口碑修复公式（失信之后）

1. 第一时间承认，不找借口
2. 说明原因（简短，非辩解）
3. 给出补救方案 + 明确时限
4. 超预期补偿（哪怕多付成本）
5. 之后持续守信，让时间冲刷

> 修复一次失信的成本是守信的十倍，但**比装没事强一百倍**——圈子最讨厌的不是犯错，是犯错后不认。

## 五、可抄的自我介绍模板（照着改，别每次现编）

第一节讲了"要统一"，这一节给**填空模板**。三个场合各一份，写一次用三年。

### 5.1 微信：昵称 + 签名

```
昵称：真名（或统一品牌名）—— 不要用"随风""阿杰"这类看不出是谁的名字
签名：我帮【谁】解决【什么麻烦】｜【公司/品牌名】
```

> 示例：`李默 ｜ 帮中小电商做抖音代运营，3 年 60 个账号 ｜ 默studio`
> 检验：陌生客户加你时，**不点开聊天就能判断"能不能找你办事"**。

### 5.2 加好友后的第一句话（别只发"你好"）

```
【我是谁】+【从哪认识/谁介绍】+【能帮你什么】+【不打扰的结束语】
```

> "王总您好，我是李默，张姐推荐加的。我做抖音代运营，之前帮张姐的店把播放量从几百做到稳定 5 万+。您那边如果后续有需要，随时找我；没别的事，不打扰您。"

**要点**：**主动给"不打扰"的出口**——这一句让人从"又来了个推销的"变成"这人挺有分寸"。

### 5.3 见面 30 秒（同 [07-沟通与谈判](07-沟通与谈判.md) 2.2）

```
我是【谁】→ 专做【什么】→ 做出过【一个可验证的结果】→ 今天来是想【具体目的】
```

> 最后一句最重要：**带目的来的人，比"来学习交流的"更受尊重**。

### 5.4 名片 / 报价单

至少三样统一：**Logo、一句话定位、联系方式**。加一个**二维码**（微信或案例链接），让见面后能被找回来。

## 六、评价管理：好评要主动要，差评要正确接

口碑不是"等别人夸你"，是**有动作的资产**。

### 6.1 主动要好评：时机 + 话术

- **最佳时机**：交付完成后 **24–72 小时内**——此时满意度最高、印象最新。拖到一个月后问，对方已经没感觉了。
- **要的姿势**：不要"求好评"，要**给具体的表达脚手架**：

  > "项目顺利交付了，特别感谢您的信任。如果方便的话，能不能留一句评价？**比如：交付过程中哪一点帮到了您、或者哪块还可以更好**——这两句对我特别有用，我后续会用作案例说明（会先发您确认）。"

- **要"内容"不要"五星"**：一句具体的评价（"原本差评率 12%，两个月降到 3%"）比十个"服务很好"值钱得多。
- **给方便**：附上链接/入口，别让对方自己找；能一句话复制就更好。

### 6.2 差评分级处理（不是所有差评都要"救"）

| 类型 | 特征 | 处理 |
|------|------|------|
| **事实型** | 确实没做到（延期/质量/沟通不畅）| **立刻认 + 补救方案 + 时限**（公式见 4.3）。这类修好了反而加信任 |
| **预期型** | 没做到是"当初没说清"造成的 | 先承认沟通不足，重申实际能力边界，给替代方案 |
| **误解型** | 对方理解错了/第三方造成 | 私下用事实温和澄清，**不在公开场合争辩** |
| **恶意型** | 同行抹黑、无理勒索 | **留证 + 平台申诉 + 不纠缠**。你越吵，对方越有存在感 |

**三条通用铁律**：
1. **24 小时内先回应**（哪怕只说"收到，我马上核实并给您答复"）——沉默会被读成"默认"。
2. **公开场合只谈解决，细节移到私下**（电话/私信）——公开辩论只会两败俱伤。
3. **先接情绪再给方案**（同 [公司/12-危机与客诉应对](../公司/12-危机与客诉应对.md) 五步法）。

> 🚫 **红线**：刷好评、让员工/亲友假装客户、删除真实差评——一旦被发现，之前攒的全部口碑一起归零。

### 6.3 把好评变成"证据"

收到的每条好评/截图，**当天归档**（见第七节），别让它散在微信里——**半年后你需要案例时，是找不到的**。

## 七、口碑证据库：把"口碑"变成看得见的东西

"我很靠谱"是主张，"这是 X 个客户的评价 + 3 个可验证的案例"是证据。**别人信证据，不信主张。**

### 7.1 四类证据（按说服力排序）

| 类型 | 内容 | 说服力 |
|------|------|--------|
| **可验证的结果** | 具体数字变化（播放量/差评率/成本/周期）| ⭐最高——数字可查、可推敲 |
| **客户证言** | 客户原话截图（**须获授权**）| 高——第三方背书 |
| **案例复盘** | 背景 → 做法 → 结果 → 复盘（3–5 个精选即可）| 高——展示方法论 |
| **过程痕迹** | 项目排期、交付物、沟通记录、现场照片 | 中——证明真做过 |

### 7.2 维护动作（很轻，但必须有）

- **一个文件夹 + 一套命名**：`案例-2026XX-客户简称-成果`，与 [06-工具与 AI 提效](06-工具与AI提效.md) §六的命名规范同源。
- **每完成一个项目，当天写 200 字复盘**（背景/做法/结果各一两句）——**趁记忆新鲜**，事后补写质量差十倍。
- **每季度整理一次**：把最新的 3–5 个案例放到对外可发的版本（隐去客户敏感信息，**事先取得授权**）。
- **授权话术**："这个项目想作为案例对外说明（**只说行业类型和成果，不出现公司名和具体数据细节**），您看行吗？如果要出现贵司名称，我会先发您过目。"

> 🚫 **红线**：未经授权使用客户名称/数据/内部截图；把别人做的项目说成自己做的——**这两件事足以让你在圈子里一次性出局**。

### 7.3 到哪里用

报价时附案例、面试员工时展示、融资/找合作时作背书、内容创作用素材（同第三节）——**同一批证据，四种用途**。
