> 定位：你的钱、账号、作品、回忆，越来越多是**一串字符**。丢了密码、账号被封、人出意外家人登不进去——每一种都是真实的损失。
> 本文把"账号安全"从口号变成**可执行的三层系统**：**盘清楚 → 守得住 → 交得出去**，并附**常见攻击套路识别**与**加密资产特别防护**。

## 1. 先盘清楚：你有哪些数字资产

### 1.1 资产清单（花 1 小时列完，比想象的多）

| 类别 | 常见例子 | 丢了/被黑的代价 |
|------|---------|----------------|
| **资金类** | 银行卡、支付宝/微信支付、券商、交易所（如 OKX/币安）| 直接金钱损失 ⭐最高 |
| **身份类** | 手机号（一切的根）、主邮箱、微信/QQ | 收不到验证码 = 所有账号被连锁接管 |
| **账号类** | GitHub、云服务器、域名、APP/系统后台、企业邮箱 | 代码泄露、业务停摆（见 [公司/06-经营风险](../公司/06-经营风险.md)）|
| **内容类** | 云笔记、手机相册、网盘、个人站点、多年聊天记录 | 多年积累一夜蒸发 |

> 🔑 **手机号是根**：几乎所有账号都靠"短信验证码"找回。手机号一旦被补卡/盗用，攻击者能顺藤摸瓜重置你全部账号——所以：**运营商服务密码、SIM 卡 PIN** 都要设，别让任何人能凭身份证复印件去营业厅补你的卡。

### 1.2 给每个资产标三级

在清单上给每项标 **A/B/C 级**（判断标准见第 3 节），保护强度跟着级别走——这张表同时是"数字遗嘱"的底稿（第 4 节）。

## 2. 守得住：四道安全基线

### 2.1 ① 密码管理器 + 唯一强密码

- **别再用"一个密码走天下"或"姓名+生日"**——数据泄露库里几秒就能撞库，一个账号泄露 = 所有账号沦陷。
- 用密码管理器（Bitwarden 免费版 / 1Password 等）生成并保存**每个账号独立的长随机密码**（≥16 位）。
- 主密码是"钥匙中的钥匙"：设成**你能记住的最长句**（如"我第一家公司开在2026年夏天!"），并**手写一份放家里**——不是只存云端（云端账号本身也可能被盗）。
- 迁移路径（别想一口吃成胖子）：先把 **A 级账号**换完 → 再 B → 再 C，一周内完成 A 级即可。

### 2.2 ② 双重验证（2FA），能用 App 不用短信

- 优先级：**硬件 Key（YubiKey 类）> Authenticator App（Google/Microsoft/密码器内置）> 短信**。
- 短信验证码可被"**换卡攻击**"绕过（骗子拿伪造证件补你的 SIM 卡）——只能当兜底，不能当主力。
- **交易所/券商/主邮箱**务必开 2FA；交易所的 **API Key 只开"读取"权限、别开提现**，用独立 IP 白名单更稳（呼应你 OKX 策略的交易安全）。
- 换手机前：先在新设备装好 Authenticator 并迁移，再处理旧手机——否则 2FA 可能把你锁在自己账号外。

### 2.3 ③ 恢复码离线保存

- 开启 2FA 时给的**备用码/恢复码**：打印或手抄，放家里/银行保险柜，**别只存在同一个云盘里**（云盘被盗 = 一起丢）。
- 手机丢了/换了，恢复码是你唯一退路——**没存 = 账号可能永久锁死**（交易所客服也常救不了）。
- 建议每月抽 1 个恢复码**试登录一次**验证仍有效——等你真需要时才发现失效，就晚了。

### 2.4 ④ 每 90 天做一次"权限体检"

- [ ] 哪些设备登录着你的账号？踢掉不认识的
- [ ] 哪些第三方应用有授权？砍掉不用的
- [ ] 哪些 API token / PAT 还活着？**用完即吊销、用时再生成**
- [ ] token 一旦在聊天/截图/日志出现 = **按已泄露处理，立即吊销**（你经历过两次了——这是唯一正确姿势）

> GitHub 的 token / 授权管理入口见 [附录/01-办事网站与入口](../附录/01-办事网站与入口.md)。

## 3. 分级：分清"能承受的损失"和"不能承受的"

| 级别 | 判断标准 | 保护强度 |
|------|---------|---------|
| **A 级** | 丢了会致命：资金（银行卡/交易所）、手机号、主邮箱、代码仓库、域名/服务器 | 唯一强密码 + App 2FA + 恢复码离线 + 季度体检 + 离线备份 |
| **B 级** | 丢了很麻烦：社交账号、云笔记、网盘、订阅服务 | 唯一强密码 + 2FA + 定期导出备份 |
| **C 级** | 丢了不可惜：论坛、一次性注册的账号 | 独立随机密码即可（可不开 2FA）|

> 原则：**保护强度跟级别走，别所有账号一样用力**——你会累到放弃，反而裸奔。

## 4. 交得出去：意外时家人怎么接手（数字遗嘱）

### 4.1 为什么必须做

多数人没想过：**你出意外/失能时，家人连你的钱都取不出来**——交易所账号、基金、手机都打不开。而家人**不知道你有** = 资产永久沉睡（这是最常见的真实损失）。

### 4.2 三步做法

**① 资产清单放家里**
第 1 节那张"数字资产清单"（哪个平台、大概多少钱/在哪），打印放家里（或加密文档存给可信的人）。家人不知道你有 = 资产等于没有。

**② 写"钥匙位置"而不是"钥匙本身"**
别把全部密码写在一张纸上到处放；而是写：**"密码管理器是 XX 品牌，主密码手抄本在 XX 保险柜；交易所恢复码在 XX 处；2FA 手机是 XX。"**——需要时家人按图索骥去取，而不是把钥匙满世界撒。

**③ 防滥用设计**
- 留给最信任的 **1 人 + 律师/配偶各持一半**（两半合起来才能用），或约定"**仅在本人失联 X 天以上才启用**"。
- 资金类账户可以设"**紧急联系人/继承功能**"（支付宝、部分券商支持）——主动用官方机制。
- 涉及大额（房产/公司股权）走**正式遗嘱**（见 [家族/01-家庭与健康规划](../家族/01-家庭与健康规划.md) 传承一节）。
- 公司账号（域名/服务器/企业邮箱）的接管人，**写进公司交接文档**（[公司/08-退出与传承](../公司/08-退出与传承.md)）。

### 4.3 加密资产特别提醒（如果你持有）

- **私钥/助记词 = 钱本身**：任何人拿到就能转走，**没有任何客服能帮你找回**。
- 助记词**永不截图、永不发聊天、永不存云盘/邮箱**——只允许离线保存（手写/金属助记板 + 保险柜）。
- 考虑**冷钱包**（大额）与热钱包（小额日常）分离；小额试水见 [未来与投资/02-项目投资](../未来与投资/02-项目投资.md)。
- 数字遗嘱里单独给家人写一份"加密资产指引"（有哪些链/哪些钱包/助记词在哪）——这块不懂的人完全无从下手。

## 5. 常见攻击套路：识别与防御

| 套路 | 特征 | 防御 |
|------|------|------|
| **钓鱼链接/假网站** | 短信/邮件发"账户异常、需验证"，链接域名像官方但差一个字母 | 手动输入官网地址；重要网站存书签，不从链接进 |
| **撞库** | 用泄露的密码批量试你所有账号 | 每个账号独立密码（第 2.1 节）|
| **换卡攻击** | 伪造证件补你的 SIM 卡 → 收你的验证码 | SIM PIN + 运营商服务密码；发现手机突然无信号立即查 |
| **假客服** | 冒充平台客服要验证码/要你"转账到安全账户" | 平台客服**永远不会**要你的验证码/密码；挂断后从官方 App 内联系 |
| **屏幕共享诈骗** | 让你下会议软件开共享屏幕"指导操作" | 任何让你共享屏幕+操作转账的，100% 是诈骗 |
| **高收益理财/喊单群** | "保本高息""带你赚钱" | 见 [未来与投资/02-项目投资](../未来与投资/02-项目投资.md) 不投红线表 |

> 通用法则：**任何让你"赶紧、别告诉别人、先转一笔验证"的，都是诈骗**——真平台不怕你慢，骗子最怕你思考。

## 6. 红线清单（这些事别做）

- ❌ 密码明文贴在工位/手机备忘录，或发在聊天里
- ❌ API Key / token / 助记词截图发给任何人、提交进代码仓库（哪怕私有库）
- ❌ 所有账号共用同一密码，或用生日/手机号当密码
- ❌ 2FA 恢复码只存在同一个云盘（云盘被盗 = 一起丢）
- ❌ 手机号停机/换号前不迁移绑定——换绑要**提前 1 个月**逐个处理
- ❌ 点击不明链接输入账号密码 / 把验证码告诉"客服"

## 7. 季度自检（每 90 天 10 分钟）

- [ ] 授权设备/第三方应用清一遍，踢掉不认识的
- [ ] API token / PAT 清单过一遍，不用的吊销
- [ ] 密码管理器提示的"弱密码/重复密码"改掉
- [ ] 数字资产清单更新（新增的平台/账户补上）
- [ ] 确认 2FA 恢复码仍可用（拿一张试登录一次）
- [ ] 加密资产：确认助记词/冷钱包离线备份还在、没拍照没截图
