# 亲戚相处：救急不救穷，善良有锋芒

> 同板块：[01-家庭与健康规划](01-家庭与健康规划.md) ｜ [03-朋友与同学往来](03-朋友与同学往来.md)

> 定位：处理与**父母、兄弟姐妹、叔伯姑舅、堂表亲、族亲乡亲**的金钱与边界问题。
> 核心原则同样适用于朋友：**救急不救穷，不帮懒；善良但有锋芒，大方但有原则。**

---

## 1. 先调整心态
人一旦有钱，周围人的态度一定会变：有人巴结、有人嫉妒、有人觉得「你该帮衬」、有人反复借钱道德绑架。
**这是人性，不是你的问题。** 你不需要为别人的情绪负责，更不必因为有钱产生负罪感——钱是你辛苦赚的，你有绝对支配权。

## 2. 金钱三原则
- **救急**：生病住院、孩子上学、突发意外——能力范围内帮，甚至可以「送」一部分，不指望还。
- **救穷**：长期缺钱、赌博、挥霍、无底洞——坚决不帮，帮了是害他也是拖垮自己。
- **帮困**：暂时困难但有上进心、有具体计划——可帮一把，要有期限和约定。
- **不帮懒**：好吃懒做、等靠要、觉得你有钱就该给——直接拒绝。

## 3. 学会拒绝（话术参考）
- 「钱都投出去了，手上真没多少活钱。」
- 「我可以帮你出出主意、介绍个资源，但钱方面确实不方便。」
- 关键：**不要解释太多，越解释越被动**；语气平和坚定，别显得愧疚。

## 4. 两条硬边界
- **不给亲戚做贷款担保**：他们还不上，银行找的就是你，辛苦钱可能一夜替人还债。
- **不轻易和亲戚合伙做生意**：赚钱易分赃不均、亏钱易互相埋怨。要看能力看人品，**必须签协议 + 设退出机制**。

## 5. 不过度参与
不因有钱就大包大揽亲戚家事（如「孩子上学我包了」「房子我来想办法」），开了头后面全是期待。礼数到位即可。

## 6. 关系分层（越外圈，金钱介入越浅）
| 层级 | 成员 | 原则 |
|------|------|------|
| 父母（直系） | 父母 | 赡养是责任；但财务边界要清晰（见情境表）|
| 近亲 | 兄弟姐妹、祖父母 | 适度帮扶，避免长期依赖 |
| 远亲 | 叔伯姑舅、堂表亲 | 礼数到位，不轻易涉大额金钱 |
| 族亲乡亲 | 更远的同族、乡邻 | 尊重 + 量力，不被道德绑架 |

## 7. 常见情境应对表
| 情境 | 策略 |
|------|------|
| 父母要求资助兄弟姐妹买房 | 孝敬父母可以，兄弟买房靠自己；可借一部分但**打借条** |
| 兄弟姐妹想合伙做生意 | 先看能力看人品，必须签协议、设退出机制，否则不参与 |
| 亲戚在家族群酸你有钱 | 不回应、不解释、不退群，保持沉默 |
| 家族聚会总让你买单 | 轮流买单 / 事先 AA / 只承担自己核心家庭部分 |
| 远房亲戚借钱 | 直接拒绝，或给小额红包当赠送，不期待归还 |
| 长辈要求为村里修路/祠堂捐款 | 量力而行，捐但不超过预算，说清原则 |
| 父母过度干预你的财务 | 定期给赡养费，但不透露具体资产，温和坚定划清界限 |
| 兄弟姐妹长期不工作靠你养 | 停止现金资助，可帮找工作/技能培训，不养懒 |

## 8. 给父母养老（责任，不只是给钱）
- 每月固定赡养费 + **专项**：查父母医保缺口，补商业医疗/意外。
- 大病、失能场景提前聊：谁照顾、钱怎么出、要不要护工/机构。
- 财务透明到"够用即可"：防被骗、防被其他子女套走，也防你自己被绑死。

---

*血缘不是无限提款机的理由，也不是你被绑架的理由——**边界清晰才是对亲情最长久的保护**。*
