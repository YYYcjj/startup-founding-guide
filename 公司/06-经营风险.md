# 经营风险：提前识雷，别等爆了才处理

> 定位：把公司可能"翻车"的地方提前列出来——**知道风险在哪，就是一半的风控**。

---

## 1. 财务与债务风险
- **公私混同**：用个人卡收公司款、公司钱随便花 → 可能被"揭开公司面纱"，有限责任变无限连带。
- **对外担保**：给他人/他公司担保，一旦对方违约，你替他还——**非必要不担保**，真要做先评估抵押物。
- **过度赊销**：大客户欠款拖垮现金流；设账期上限、按节点催收。
- **隐形负债**：对赌协议、售后承诺、房租违约金——签字前看清每一项责任条款。

## 2. 法律与合规风险
- 合同风险：口头承诺不算数，**重要合作写书面合同**，关键条款（付款/违约/保密/知识产权）逐字看。
- 知识产权：商标不注册可能被抢注；核心技术/内容要有保密协议和权属约定。
- 劳动风险：不签合同 → 双倍工资；随意辞退 → 赔偿金；社保不缴 → 补缴+罚款。
- 数据与隐私：客户信息、个人信息别乱采集滥用（《个人信息保护法》）。

## 3. 税务稽查风险
- 虚开发票 = 刑事红线；买发票抵成本是给自己埋雷。
- 长期零申报/税负异常会触发预警；账实不符是稽查重点。
- 别听"包税/避税神器"的忽悠——**合规省税靠政策，不靠造假**。

## 4. 经营与市场风险
- 大客户/单一业务占比过高：丢一个就重伤，主动分散。
- 依赖个人关系做生意：人走茶凉，把客户关系沉淀到公司（CRM、合同主体、品牌）。
- 现金流断裂：利润≠现金，账上永远留安全垫。

## 5. 行政与安全风险（小公司也躲不开）
- 注册地址失联/虚假 → 列入**经营异常名录**，影响贷款、投标、开票。
- 办公场所：用电、消防通道、易燃物——见 [07-税务法律消防合规](07-税务法律消防合规.md)。
- 公章管理：**公章=公司意志**，专人保管、用印登记，别随手放桌上。

## 6. 创始人个人风险
- 以公司名义乱签个人无限责任条款（如个人连带担保）。
- 个人财产与公司不分，出事一起赔。
- 突发失能/意外 → 提前准备**授权委托书**，家人能接管事务。

## 7. 风险处置原则
1. **早暴露**：问题藏得越久越贵。
2. **先止血再根治**：先停损失，再慢慢处理。
3. **该找人就找人**：法律/税务/保险专业问题别自己硬扛。
4. **记录留痕**：所有关键决定留书面/邮件记录。
