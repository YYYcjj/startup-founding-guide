## 一、身体精力：一切的本钱

### 1.1 睡眠：第一生产力，不可透支

- **固定就寝/起床时间**（含周末误差 ≤1h），先保证 7 小时 × 每周 ≥5 晚——固定节律比时长更重要。
- 睡前 1 小时**离开屏幕**（蓝光抑制褪黑素），手机放客厅充电，别放床头。
- 咖啡因半衰期约 5–6 小时：**下午 2 点后不喝咖啡/浓茶**，否则晚上躺下脑子还在转。
- 创业最蠢的省钱方式：熬夜省下的时间，用生病 + 决策失误加倍还。

### 1.2 运动：每天 30 分钟，比补品值钱

| 类型 | 频率 | 目的 |
|------|------|------|
| 有氧（快走/跑步/骑行）| 每周 3–4 次 | 心肺、情绪、大脑供氧 |
| 力量（自重/器械）| 每周 2 次 | 基础代谢、抗衰、久坐代偿 |
| 拉伸/活动 | 每天 | 对抗久坐：每坐 45–60 分钟起身 2 分钟 |

> 没时间去健身房？**快走上下班、电话会议时踱步、爬楼梯**——碎片运动也有效，关键是别整天不动。

### 1.3 饮食与咖啡因

- 别用咖啡/功能饮料**硬顶长期透支**——那是在向未来的自己借高利贷。
- 规律三餐，别把"随便吃"当常态：外卖可以，但保证每餐有蛋白质 + 蔬菜。
- 酒后第二天的高强度决策，质量会肉眼可见地下降——重要谈判/签约前夜，**别喝酒**。

### 1.4 体检与身体报警

- 年度体检交给 [家族/01-家庭与健康规划](../家族/01-家庭与健康规划.md) 的家庭体检安排（别省，创业后尤其要查：血脂、血糖、肝功、甲状腺、幽门螺杆菌）。
- **身体报警及时就医**：长期失眠 / 胸闷 / 无故消瘦 / 持续胃痛 / 便血——别拖成大病再花十倍时间与钱。创业者的"再等等"，往往是病情加重的加速器。

## 二、心理与情绪：创业最易崩的维度

### 2.1 先承认：这不是矫情

创业高发**焦虑、孤独、burnout**（职业倦怠）——因为创业者同时扛着：钱的压力、决策的责任、没人可说的孤独、随时可能翻车的恐惧。**情绪是生理与环境的真实反应**，不是你不够坚强。

### 2.2 心理四防线（缺一不可）

| 防线 | 做法 | 为什么 |
|------|------|--------|
| **疏压出口** | 固定运动 / 一个爱好 / 一段独处 | 让大脑从"战斗模式"定期下线 |
| **可倾诉的人** | 伴侣、挚友，至少 1 个能说真心话的 | 孤独是创业者最大的隐形杀手 |
| **规律锚点** | 每周固定一顿家庭饭、一次打球、一天不碰工作 | 防止工作吞噬全部生活（见 [家族/01](../家族/01-家庭与健康规划.md) 时间平衡）|
| **求助通道** | 心理咨询作为正常选项写进备忘录 | 和感冒看医生一样，别硬扛到崩 |

### 2.3 创业者高发心理状态：识别与应对

| 状态 | 表现 | 应对 |
|------|------|------|
| **焦虑** | 停不下来地想最坏情况、失眠 | 写下来（最坏结果是什么？概率多大？能做什么？）→ 只做能做的部分 |
| **孤独** | 没人理解你的处境 | 找同类：创业者社群/同行饭局，报团取暖是刚需 |
| **Burnout（倦怠）** | 对原本热爱的事失去兴趣、效率崩 | 强制休息 3–7 天 + 砍掉低价值事务，别靠"再努力一把"硬撑 |
| **冒名顶替感** | 觉得自己不配、随时会被拆穿 | 这是能力焦虑的假象；列"做成的事清单"，用事实对抗日 |
| **成功后的迷失** | 钱来了膨胀、多疑、挥霍 | 定期照镜子复盘，找敢敲打你的人（见 2.4）|

### 2.4 防"成功后的迷失"

- 定期给自己**照镜子**（每月一次）：最近是不是飘了？对家人/老友的态度变了吗？消费膨胀了吗？
- 找一个**敢跟你说真话、甚至敢泼冷水的人**（导师/老友/伴侣），明确授权他："我飘的时候，你要直说。"
- 钱是放大镜，不是改变器：它放大你本来的样子——本来就贪的会更贪，本来就虚的会更虚。守住底层价值观，钱才不会反噬。

## 三、身心互锁与状态自检

### 3.1 为什么放在一起讲

身体和心理**互相拖垮，也互相托底**：长期失眠 → 情绪崩；长期焦虑 → 身体垮（胃、免疫、心血管）。所以自检要"身心一起查"。

### 3.2 红黄绿自检表

| 维度 | 🟢 绿灯（正常） | 🟡 黄灯（该调整） | 🔴 红灯（立刻行动）|
|------|----------------|------------------|------------------|
| 睡眠 | 入睡快、醒后精神 | 连续一周入睡难/多梦/早醒 | 长期失眠 ≥1 个月，或每天靠药物才能睡 |
| 情绪 | 有波动但能自愈 | 持续烦躁、对什么都提不起劲 | 情绪低落到影响日常 ≥2 周 |
| 身体 | 精力够用 | 肩颈痛、易疲劳、靠咖啡硬顶 | 胸闷 / 无故消瘦 / 不明疼痛 / 便血 |
| 状态 | 能正常推进工作 | 效率下滑、拖延加重 | 无法工作、频繁失控、**有伤害自己的念头** |

> 🚨 **出现任何红灯，尤其最后一行——立刻就医/求助，并告诉一个信得过的人**。公司可以重来，你只有一个。

### 3.3 极端期预案（提前写好，别等崩了再想）

- **提前写一份"自我关怀卡"**（情绪崩溃时照着做）：① 找一个能说话的人 ② 今天只做最小必要的事 ③ 允许自己休息，不评判 ④ 必要时的求助电话/就医路径。
- 把这 4 条存进手机备忘录——**崩溃时大脑是空白的，靠临时想是想不到的**。

## 四、日常运作：把"作息"做成默认设置

原则：**不靠意志力，靠默认设置**。意志力会耗尽，日程表不会。

### 4.1 一天的基本骨架（可按自己节奏前后平移）

| 时段 | 默认动作 | 为什么 |
|------|---------|--------|
| 起床后 30 分钟 | 见自然光（出门走走/开窗）、喝水、别第一时间刷手机 | 光照是校准生物钟最强的信号；起床即刷手机 = 让别人的议程先占据你的大脑 |
| 上午（精力峰值）| **2 小时深度时间**：关通知、做最难最值钱的那一件 | 同 [02-能力成长](02-能力成长.md) 5.1；把最贵的大脑用在最贵的事上 |
| 午间 | 正常吃、别用工作配饭；20 分钟小睡（≤30 分钟，超了会更昏）| 下午的清醒度靠午间这一觉 |
| 下午 | 会议、沟通、琐事批量处理放在这里 | 精力次高峰适合社交与协调类工作 |
| 傍晚 | 30 分钟运动（快走也算）| 把压力激素用掉，晚上才睡得着 |
| 睡前 1 小时 | 离开屏幕、手机放客厅、把明天的三件事写下来 | 写下来 = 大脑不用整夜替你记着（这是最有效的"防失眠"动作）|

### 4.2 创业特有的节奏：冲刺—休整

创业不是匀速长跑，是**一阵一阵的冲刺**。真正搞垮人的不是忙，是**冲刺之后没有休整**。

- 每个大项目/旺季结束，主动排 **1–2 天"低负荷日"**（不回非紧急消息、只做整理与复盘）——**写进日历**，不然永远排不进。
- 连续高强度超过 **3 周**，必须安排一次完整休息日（全天不碰工作）。
- 别把"忙完这阵就好了"当承诺：这阵忙完永远有下一阵。**休息要主动排，不会自己出现。**

### 4.3 三个"防过载"的开关

- **信息开关**：每天固定 2–3 个时段看消息/群/新闻，其余时间关通知（不是没看到，是**不被随机打断**）。
- **决策开关**：把低价值决策变成固定选项（穿什么、吃什么、几点开会）——**省下的决策力留给重要判断**。
- **情绪开关**：每天留 15 分钟什么都不做（散步、发呆、听音乐），让大脑从"战斗模式"下线（呼应第二节"疏压出口"）。

## 五、具体操作手册：失眠 / 焦虑 / 崩溃时怎么做

前面讲"应该怎样"，这一节讲**出状况时具体怎么动**——因为这些时刻大脑是空白的，必须提前写好照着做。

### 5.1 长期睡不好：五步排查（按顺序，别跳）

1. **先查节律**：起床时间是否每天浮动超过 1 小时？先固定起床时间（比固定入睡时间有效）。
2. **查刺激物**：下午 2 点后是否还有咖啡/浓茶/奶茶？晚上是否喝酒？（酒助入睡但**破坏深睡**，醒来更累。）
3. **查屏幕**：睡前 1 小时是否在看手机/电脑？亮度与内容刺激都会推迟入睡。
4. **查心事**：是否一躺下就开始盘工作？→ 用"睡前写下来"（§4.1 最后一格）。
5. **以上都做了还持续 ≥1 个月** → 挂号看医生（见 §5.4），**别自己长期靠褪黑素或酒**。

### 5.2 焦虑涌上来时：先让身体下来，再处理事

情绪高峰时讲道理没用，**先降生理唤起**：

- **呼吸**：吸气 4 秒 → 屏 2 秒 → 呼气 6 秒，做 6–8 轮。**呼气比吸气长**是关键。
- **接地（5-4-3-2-1）**：说出 5 个看到的、4 个听到的、3 个摸到的、2 个闻到的、1 个尝到的——把注意力从"脑中灾难片"拉回当下。
- **降温**：用冷水洗脸/洗手腕，或走到户外吹风 2 分钟。
- **然后才处理事**：写下"最坏结果是什么 → 概率多大 → 我现在能做的一件小事"（同第二节 2.3 焦虑应对）——**只做那件小事**。

### 5.3 情绪崩溃时的急救卡（提前存手机，照着念）

1. **先找一个人**——现在就发消息，不用解释清楚，一句"我现在很不好，能陪我说说话吗"就够。
2. **今天只做最小必要的事**：吃饭、喝水、睡觉。其他全部推迟或取消。
3. **允许自己休息，不评判**——"我现在需要停一下"是事实描述，不是失败声明。
4. **危险时刻**：如果出现伤害自己的念头，**立刻联系信任的人并在身边陪着**，同时就医/拨打心理援助热线——**不要独自待着**。

> 🚨 这一节不是鸡汤：**出现红灯立刻行动**（见第三节 3.2 红黄绿灯表）。公司可以重来，你只有一个。

### 5.4 该找谁、去哪找（别拖到崩了才查）

| 情况 | 找谁 | 怎么找 |
|------|------|--------|
| 身体症状（失眠/胸闷/胃痛/消瘦）| 正规医院**全科 / 内科 / 消化科 / 心内科** | 先挂最贴合症状的科；查不出器质问题但症状持续，医生会建议转诊心理科 |
| 情绪持续低落 ≥2 周、影响工作生活 | **精神心理科 / 临床心理科**（三甲医院多设）| 医院官方渠道预约；**精神科医生可以诊断与开药，心理咨询师不能** |
| 压力大、想梳理、无临床问题 | **心理咨询**（医院心理科 / 正规机构 / 平台） | 优先选有资质与受训背景的；单次常见区间几十到几百元不等，问清计费与频次再开始 |
| 突发危机、有伤害自己或他人的念头 | **急诊 / 心理援助热线 / 立即联系身边人** | 不要等预约，直接去急诊或打热线 |

> 就医是**能力**不是羞耻：创业者做决策靠大脑，**大脑出问题就等于公司核心设备出问题**——修它和修服务器一样正常。

### 5.5 创业压力怎么跟家人说（别用"没事"糊弄）

- 家人最怕的不是"公司难"，是**被排除在外 + 你的情绪突然爆发**。适度透明比完全隐瞒更稳。
- 说法模板："**最近公司在做一个大项目，我这两个月会很忙、可能回得晚（事实）。我压力有点大，如果偶尔脾气不好，是我的问题不是你的（认领情绪）。我预计 X 月能缓过来，我们 X 月安排一次出去玩（给确定预期）。**"
- 什么不该说：具体金额的恐慌（除非需要共同决策）、每天的业绩波动、把焦虑原样倒给家人当出口——**出口该是运动、朋友、咨询师，不是家人**（同 [家族/01-家庭与健康规划](../家族/01-家庭与健康规划.md) 时间与沟通平衡）。

## ✅ 本节行动清单

**本周：**
- [ ] 定就寝/起床时间，手机移出卧室，先保 7h×5 晚
- [ ] 把一天的骨架写进日历（§4.1）：上午 2h 深度时间 + 傍晚 30min 运动 + 睡前 1h 离屏
- [ ] 预约今年体检（连同 [家族/01](../家族/01-家庭与健康规划.md) 家庭计划一起办）
- [ ] 写下"自我关怀卡"4 条 + §5.3 急救卡，一起存进备忘录
- [ ] 确认 1 个固定爱好 + 1 个可倾诉的人（没有就先找）
- [ ] 查清本地就医路径：三甲医院精神心理科怎么挂号（别等到需要时才查，§5.4）

**每月：**
- [ ] 照镜子复盘：钱、关系、情绪有没有跑偏
- [ ] 用红黄绿表自评一次，黄灯项挑 1 个改
- [ ] 检查有没有"冲刺激活超 3 周"——有就排一次低负荷日（§4.2）

**随时：**
- [ ] 心理咨询当作正常选项，需要时不犹豫
- [ ] 失眠持续 ≥1 个月 / 情绪低落 ≥2 周 / 出现红灯 → 立刻挂号就医，不拖（§5.4）
- [ ] 崩溃时照着 §5.3 四步做：找人 → 只做最小必要 → 允许休息 → 有危险念头立刻求助
