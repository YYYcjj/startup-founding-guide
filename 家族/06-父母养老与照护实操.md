> 定位：**"每月给钱"解决的是钱的问题，"照护"解决的是人的问题——这两件事的难度差一个量级。**
> 赡养的分担原则见 [02-亲戚相处](02-亲戚相处.md) §6；本篇负责更麻烦的那一半：**医保怎么补、异地怎么报、失能了谁照顾、钱花在哪儿最值、什么时候必须谈那三件难事。**

## 一、先算清两笔账，别凭感觉

照护这件事之所以会拖垮一个家庭，往往不是没钱，是**从没把账算清**，于是每个人心里都有一本不同的账。

### 账一：钱（按月估算，代入本地价格）

| 项目 | 大致量级 | 说明 |
|---|---|---|
| 日常赡养 | 父母基本生活缺口 | 有退休金的老人缺口小，无退休金的要全额兜 |
| 常规医疗 | 慢性病药费/复查 | 医保可报一部分，自付部分按月算 |
| 长期用药 | 高血压/糖尿病等 | 可办**门诊慢特病**，报销比例更高（见 §三） |
| 一旦失能 | 护工或机构费用 | 这是最大的变量，见 §五 |
| 应急储备 | 单独留一笔 | 建议 ≥ 6 个月照护费，专款专用 |

> **一定要把"失能情景"按一个真实报价算一遍。** 大部分人只算了"父母现在身体还行"的账，等事情来了才发现"每月要多出七八千"，而这个数字会直接决定兄弟姐妹之间能不能谈得拢。

### 账二：人（谁出时间）

| 角色 | 能出什么 | 会失去什么 |
|---|---|---|
| 同城居住的子女 | 陪诊、跑手续、日常照看 | 请假、加班机会、自己的休息 |
| 异地子女 | 钱、远程协调 | 缺席感、被指责 |
| 配偶 | 隐性承担大量照护 | 常常没人算她的贡献 |
| 父母自己 | 尽量自理 | 自主感，如果被过度代劳 |

> **"谁主导照顾谁多得补偿"** 这条原则见 [02](02-亲戚相处.md) §6.2——但**前提是有账可算**。所以第一件事就是：把两笔账写在纸上，兄弟姐妹一起看。

## 二、先补医保的三个缺口（最高性价比，几百元起）

父母的健康风险靠"孝心"兜不住，靠**保障结构**才兜得住。这三层按性价比排序：

### 1. 国家医保（基础，必须有）

- **职工医保**（有单位退休 / 灵活就业自缴）：报销比例高，有个人账户。
- **城乡居民医保**（原新农合/居民医保）：每年缴费几百元，**必须年年缴**（很多老人以为"退休了就不用缴"，一旦断缴当年就不能报销）。
- **大病保险**：超过一定自付额度后可二次报销，多数地区已自动纳入居民医保，**不用单独买，但要确认当地是否自动享受**。

**必查清单：**
- [ ] 父母的医保**今年缴了没有**（城乡居民医保一般每年 9–12 月缴下一年度）
- [ ] 是否办了**门诊慢特病**（高血压、糖尿病、透析、肿瘤门诊治疗等）——办了报销比例显著提高
- [ ] 医保电子凭证是否激活（手机就能挂号、结算）

### 2. 惠民保（城市定制型补充医疗险）—— 60+ 也能买的那一类

**为什么推荐给父母**：多数城市的惠民保有两条关键宽松——**不限年龄、通常不要求体检或健康告知很宽**（部分城市对既往症可保但降低赔付比例）。

| 项 | 参考 |
|---|---|
| 保费 | 每年几十元到一百多元/人（各地不同） |
| 保额 | 通常上百万（多为医保目录内自付部分 + 特定高额药品） |
| 免赔额 | 一般不低（常见 1–2 万），**所以它防的是"大病"，不防小病** |
| 投保渠道 | 当地医保局公众号 / 政务服务 App / 官方合作平台 |

> 一句话：**惠民保是"父母买不到百万医疗险"时的最佳替补**，一年一顿饭钱，防的是几十万那种账单。

### 3. 商业补充（视年龄与健康情况）

| 险种 | 55–65 岁 | 65 岁以上 |
|---|---|---|
| **百万医疗险** | 有机会，健康告知严格 | 通常买不到或很贵 |
| **防癌医疗险** | 推荐（健康告知比百万医疗宽） | **推荐**（三高人群常可投保） |
| **意外险** | 强烈推荐 | **强烈推荐**（一年一两百，含意外医疗） |
| 重疾险 | 贵、杠杆低，不优先 | 不建议 |

**结论顺序：国家医保 → 惠民保 → 意外险 → 防癌医疗险 →（能买到才考虑）百万医疗险。**

> 详细购买纪律与避坑见 [01-家庭与健康规划](01-家庭与健康规划.md) §一.2。再强调一次那条最容易被推销话术绕过去的：**先保障，后理财**。

## 三、异地就医备案：父母在外地，这一件事能省几千块

**问题场景**：父母在老家参保，来你所在的城市看病。**不备案 = 报销比例大幅下降，甚至要全额垫付再回老家报。**

### 备案步骤（手机上就能办完，全程免费）

1. **打开"国家医保服务平台"App**（或微信/支付宝搜索同名小程序），实名登录。
2. 找到 **「异地就医备案」** 入口，选择备案类型：
   - **异地长期居住**（父母随子女长期居住）：一般一次备案长期有效。
   - **临时外出就医 / 转诊转院**：按次或按周期。
3. 填写参保地、就医地、联系人，提交。多数地区**线上即时审核或 1–2 个工作日**。
4. **选定点医院**：在"异地联网定点医药机构查询"里确认要去的医院是否**支持跨省直接结算**。
5. **就诊时刷医保电子凭证/社保卡直接结算**，只付自付部分，不必垫全款。

### 三个高频坑

| 坑 | 说明 |
|---|---|
| **没备案就先住院** | 有些地区允许事后补备案，但有的要降比例；**能提前办就提前办** |
| **门诊能报 ≠ 所有门诊都能报** | 普通门诊跨省直接结算在推进中，**慢特病门诊**通常要先在参保地完成病种认定 |
| **异地药店的药** | 多数不通用；长期药建议在参保地开好、或办好慢特病后按当地政策 |

> **给创业者的实用建议**：把父母的备案、慢特病认定、医保电子凭证**在你还不忙的时候就办掉**。这类事平时花 30 分钟，急起来要花三天。

## 四、长护险：失能照护的"第六险"，很多人不知道能领

**长期护理保险（长护险）** 是国家在推进的独立险种，专门覆盖**失能人员的长期照护费用**。目前已在多数省份的城市落地，各地规则不同。

### 什么情况能享受

通常要满足：**因年老、疾病、伤残导致失能，且失能状态持续 6 个月以上**，经**失能等级评估**（一般分轻/中/重度）达到规定等级。

### 怎么申请（通用路径）

1. 向**参保地医保局**或其委托的**社区/街道受理点**提出申请。
2. 提交材料：诊断证明、病历、失能持续时间证明、身份证与医保卡等。
3. **评估人员上门做能力评估**（吃饭、穿衣、如厕、行走、认知等维度打分）。
4. 评估通过后，按当地标准享受：
   - **服务形式**：定点机构照护 / 居家上门照护 / 亲情照护补贴
   - **给付形式**：多为"报销服务费用"或"按月补贴"，各地差异很大

> **一句话行动**：现在就打电话给父母参保地的医保局问一句"咱们这儿长护险落地了吗？什么条件、怎么申请？"
> 这个电话的价值可能是每月几千元——**而它不需要你多付一分保费。**

## 五、失能了怎么办：三种照护方案的费用与取舍

假设真的到了需要人照护的阶段，只有三条路。**没有"哪条最好"，只有"哪条撑得住"。**

| 方案 | 大致费用量级（不同城市差异极大） | 优点 | 缺点 |
|---|---|---|---|
| **居家 + 家人照护** | 主要是时间成本 + 少量辅助器械 | 老人熟悉环境、心理最舒服、最省现金 | **照护者被长期消耗**，一人失能全家失衡 |
| **居家 + 请人（护工/保姆）** | 住家保姆/护工普遍几千元/月；医院陪护常见 200–400 元/天 | 老人留在家里，你正常上班 | 现金压力大；人员流动、专业度参差；需要有人管 |
| **机构（养老院/护理院/医养结合）** | 普通养老院几千元/月；**护理型/医养结合明显更高** | 24 小时专业照护、有医疗支持 | 贵；好机构要排队；老人可能抵触"被送走" |

**怎么选？按这四问：**

1. **老人的失能程度**：能自理 → 居家为主；半失能 → 居家 + 上门服务；全失能/有医疗需求（插管、褥疮、认知症）→ **优先医养结合机构**。
2. **有没有本地子女**：没有 → 远程照护几乎必须靠机构或住家护工。
3. **现金能不能持续**：**看"能撑几年"，不看"第一个月付得起"**。
4. **老人自己的意愿**：这一条最常被忽略，但**决定了配合度**。硬送进去的结果通常是老人抗拒、机构拒收。

### 选机构的检查清单（实地去看，别只看宣传）

- [ ] 是否**有民政部门备案/资质**，营业执照与养老机构备案证明
- [ ] **护理型床位**有多少（普通床位与护理床位差别很大）
- [ ] 能否处理**常见医疗情况**（吸氧、换药、导尿、鼻饲），有没有医护人员
- [ ] 有没有**与周边医院的绿色通道**
- [ ] **看现有住客的状态**（比看装修更真实）、闻气味、看卫生间
- [ ] 护工与老人**配比**（问"一个护工管几个人"）
- [ ] 收费构成：床位费 + 护理费 + 餐费 + 医疗费，**有没有额外收费项**、押金怎么退
- [ ] 探视制度、能不能装摄像头、突发情况怎么通知家属
- [ ] **签约前确认退出条款**（不满意怎么退、押金多久退）

> 一个不那么好听但真实的判断法：**去看的时候，先看卫生间和老人的手。** 卫生间有没有异味、老人指甲剪没剪、皮肤有没有褥疮——这三处骗不了人。

## 六、居家照护：先做"防跌倒改造"（最值钱的一件事）

**老人失能的第一诱因常常是一次跌倒**——跌一次卧床，卧床三个月肌肉萎缩，从此再也站不起来。

**适老化改造清单（几千元能做完，回报极高）：**

| 位置 | 动作 |
|---|---|
| 卫生间 ★★★ | 马桶旁 + 淋浴处加**扶手**；铺防滑垫；装**洗澡椅**；有条件做**干湿分离与地漏找坡** |
| 卧室 ★★★ | **夜灯**（起夜路线全程）；床边起身扶手；床高度以"坐床边脚能落地"为准 |
| 全屋 ★★ | 去掉小地毯与门槛；电线不走地；走廊装扶手（尤其去卫生间那条路） |
| 玄关 ★★ | 换鞋凳；感应灯 |
| 厨房 ★ | 常用物品下移到腰部高度；燃气报警器 |
| 通信 ★★ | 老人手机**大字大音量**；把一键拨号设成你；家里装一个固定电话（比手机可靠） |

**辅助器械（该买就买，别省这个钱）：** 助行器/四脚拐、坐便椅、护理床（失能后）、防褥疮气垫、血压计与血糖仪（并教会他们用）。

## 七、多子女陪护排班表：把"谁该来"变成"几号谁在"

兄弟姐妹之间的矛盾，90% 不是不愿意做，而是**"我以为你会做"**。

**一张表解决大部分问题（每家一张，共享表格即可）：**

| 日期 | 主责人 | 任务 | 是否需陪诊 | 费用（垫付） | 备注 |
|---|---|---|---|---|---|
| … | … | 上门/电话/取药 | … | … | … |

**规则四条：**

1. **主责制**：每周/每两周轮一位"主责人"，负责那段时间的日常联系与突发响应。**不搞"大家都有空就去"**——那样等于没人负责。
2. **垫付 + 公账**：任何人为父母垫付的钱记在表上，月底从"父母养老公账"里结清（公账由各子女按约定比例存入）。
3. **异地子女的折算方式**：出不了时间的多出钱，**并且要明确说出来、写进表里**（否则容易一边掏钱一边觉得委屈）。
4. **每季度开一次"养老会"**：对着表看一次，调整分担比例。**必须定期开**——只在出事时开，每次都是吵架。

> 父母收支与赡养费**对兄弟姐妹公开透明**这条，见 [02-亲戚相处](02-亲戚相处.md) §6.2 第 2、4 条。

## 八、老人防骗：四条纪律（比讲道理有用）

骗子的招数每年换皮，但底层逻辑不变：**用小恩小惠建立信任，再要他的一次性大额转账。**

| 骗局 | 典型信号 |
|---|---|
| 保健品/保健器械 | "免费体检 + 专家讲座 + 现场优惠名额有限" |
| 高价理财 / 原始股 | "保本高息""内部额度""带你赚钱" |
| "以房养老" / 房产抵押 | 让老人抵押房产去"投资" |
| 冒充公检法/银行 | "你涉嫌洗钱""你的账户不安全，转到安全账户" |
| 冒充子女求助 | 来电显示被伪造、"我出事了快打钱" |

**四条纪律（和父母一起定下来，写在纸上）：**

1. **大额转账必须多问一个人**：约定"单笔超过 5000 元，先给子女打个电话"——不是征求同意，是**知会一声**（保住他们的面子）。
2. **银行卡分两张**：一张日常小额（放在手边），大额存款单独一张**不绑手机支付、不开网银**。
3. **手机设置**：关闭"未知来源安装"，加装国家反诈中心 App，开启来电预警。
4. **不给父母讲你的真实资产**：他们被套话的风险比你高得多（见 [02](02-亲戚相处.md) §6.3）。

**已经发生了怎么办：** ① 立刻报警（越早越可能止付）；② 联系银行冻结/止付；③ **不要责备父母**——越骂他们越不敢说，可能已经被骗第二次了。补上这四条纪律，然后往前看。

## 九、别把自己耗干：照护者的耗竭（创业者的真实风险）

长期照护者的典型症状：睡不好、情绪失控、注意力涣散、对父母产生愧疚与厌烦交织的情绪。**这不是不孝，这是耗竭。**

**对照护者（也就是你）的四条纪律：**

1. **排班而不是硬撑**：明确"我每周固定哪几天管"，其余时间**关机也不内疚**。
2. **必须花钱买时间**：在能动用钱的地方用钱（跑腿、送药、陪诊服务、上门护理），**你的时间要留给公司和家人**（见 [个人与人际/03-身心管理](../个人与人际/03-身心管理.md)）。
3. **允许情绪**：你会烦、会累、会想逃。承认它比压抑它安全得多。
4. **有一个能说话的人**：伴侣、兄弟姐妹、朋友或心理咨询。**照护是长期战，不能靠意志力一个人扛。**

> 提醒一句最容易被忘掉的：**你也是别人的家人。** 你把自己拖垮了，公司、孩子、伴侣都会陪葬。见 [01-家庭与健康规划](01-家庭与健康规划.md) §二.2。

## 十、必须提前谈的三件难事（越早越省事）

这三件事**不适合在急救室门口谈**。趁父母思路清楚、身体尚可时，分散在几次闲聊里聊完。

### 1. 将来住哪儿：居家 / 跟着子女 / 机构

**怎么开口：**

> "妈，我不是催你。我就是想知道你希望以后怎么过——是想一直住家里，还是将来想离我近一点？我先照着你的想法准备，免得到时候手忙脚乱。"

**要点**：给选项、不给结论；把"安排"说成"准备"。**目标是拿到他们的倾向**，不是当天定下来。

### 2. 钱从哪出、怎么分

把 §一 的两笔账拿出来，和兄弟姐妹（不必和父母）算一次。**写进一张纸**：每月各出多少、公账怎么管、垫付怎么结、大额支出怎么决策（参考 [02](02-亲戚相处.md) §6.2）。

### 3. 临终阶段的医疗意愿（最难的一件）

不是"要不要救"，而是**在什么情况下希望以减轻痛苦为主**。这件事现在就在医院有正式工具了：

- **生前预嘱**：在意识清楚时，书面说明在临终或不可逆昏迷状态下希望接受或拒绝哪些医疗措施（是否心肺复苏、是否用呼吸机、是否插胃管等）。深圳等地已通过地方立法为生前预嘱提供依据，可咨询医院或专业机构。
- **意定监护**：在意识清楚时，以书面形式指定自己失能后由谁来做决定（《民法典》第 33 条）。**照护 ≠ 决策权**，这两件事最好都写到纸面上。
- **写清并让关键人知道放哪儿**：写好了没人知道放在哪，等于没写（放进 [07](07-家庭应急与身后安排.md) 的家庭应急包）。

**怎么开口（一次说一点，不用一次说完）：**

> "爸，我看了个文章说，人可以提前写清楚万一不行了要不要插管。我想听听你的想法——不是咒你，是我不想将来替你做错决定。"

> **这段话可能是不好说的，但它是你能给父母的最后一重尊重：让他们对自己的人生有决定权。**
