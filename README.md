## 📖 阅读顺序建议

1. **先看总纲**（时间线 + 优先级矩阵，决定先做什么）
   → [年轻创业者全攻略.md](年轻创业者全攻略.md)
2. 筹备/注册期 → ① 公司 01–03；经营起来 → 04–08
3. **要拉人一起干** → ① [13-合伙人股权与散伙预案](公司/13-合伙人股权与散伙预案.md)（先把散伙谈好再合伙）
4. **钱进账之后** → ① [14-公司财务基本功](公司/14-公司财务基本功.md) + [15-品牌与知识产权](公司/15-品牌与知识产权.md)
5. 赚到钱后 → ② 家族（家庭先、亲戚/朋友同学配套）+ ③ 个人与人际（含 [06-工具与 AI 提效](个人与人际/06-工具与AI提效.md)）
6. **家人进了公司 / 准备结婚买房** → ② [04-家人参与生意的边界](家族/04-家人参与生意的边界.md) + [05-婚姻财产与股权安全](家族/05-婚姻财产与股权安全.md)（这两件事只在你还有议价空间的时候好办）
7. **父母上了年纪 / 家里有人生过大病** → ② [06-父母养老与照护实操](家族/06-父母养老与照护实操.md) + [07-家庭应急与身后安排](家族/07-家庭应急与身后安排.md)
8. 迷茫期/有余钱时 → ④ 未来与投资（先选方向，再谈投项目）
9. 真要办事 → 对照 附录 找官方入口
