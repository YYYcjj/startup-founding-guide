> 定位：**亲戚相处的原则是"不合伙"；但现实里妻子、丈夫、父母、兄弟总有人要进公司。**
> 进了就得按公司规矩办——本篇讲的是"怎么进、给什么、怎么管、怎么退"这四件事，而不是"该不该让家人进"这种空话。
> 本篇覆盖：三种进入方式 → 必须做对的四件事（合同/发薪/社保/权限）→ 岗位红线与亲属回避 → 代持的四个真实风险 → 只拿钱不干活怎么处理 → 家庭与公司两个会要分开 → 怎么体面地请出去。

> ⚠️ 通用参考，不构成法律意见。涉及劳动关系、股权代持、社保基数，请以当地政策与律师意见为准。

## 一、先分清：家人"进公司"其实有三种，风险完全不同

很多人把这三件事混成一件，于是要么白送股份、要么白干活、要么埋了个大雷。

| 方式 | 给的是什么 | 他是不是股东 | 要不要签合同 | 主要风险 |
|---|---|---|---|---|
| **A. 任职**（最推荐） | 岗位 + 工资 | 否 | **要**（劳动合同） | 劳动关系没理清 → 工伤、双倍工资、经济补偿 |
| **B. 分红权**（可考虑） | 只分利润，无表决 | 否（签协议约定） | 要（任职的还要签） | 协议没写清 → 被当成"隐性股东"主张权利 |
| **C. 给股权 / 代持**（最慎） | 真股份 | 是（或名义上是） | 要（股东协议 + 代持协议） | 婚变/债务/继承/退出四重风险，见 [公司/13](../公司/13-合伙人股权与散伙预案.md) §八 |

**一个判断口诀：**

> **先问"他要的是钱，还是权？"**
> 要钱 → 走 A + B（岗位工资 + 分红权），公司控制权不受影响，将来也好收。
> 要权 → 那就是真合伙，按 [公司/13](../公司/13-合伙人股权与散伙预案.md) 那一整套走（协议 12 条、vesting、决策权三条线），一步都不能省。

**最常见的错误**是：家人明明只想要"生活有保障"，你却给了 20% 股份——三年后他退出，股份还在他手上，你想收回得花钱买；他若离婚或欠债，股份还可能被分走或被法院执行（详见 [05-婚姻财产与股权安全](05-婚姻财产与股权安全.md)）。

## 二、必须做对的四件事（做了就省掉 90% 的麻烦）

### 1. 签劳动合同——哪怕是亲妈

**不签的代价很具体**（不是"不规范"这么虚）：

| 没做到 | 现实后果 |
|---|---|
| 未签书面劳动合同满 1 个月 | 员工可主张**未签合同期间的双倍工资**（最长 11 个月） |
| 未缴社保 | 员工可要求补缴，还可能要经济补偿；发生工伤时**公司全额自负** |
| 未约定岗位与工资 | 想调整岗位/降薪时没有依据，一调就可能被认定违法变更 |
| 想辞退时拿不出考核记录 | 被认定违法解除 → **2N 赔偿** |

**操作清单：**

1. 入职 30 天内签书面劳动合同（一式两份，公司和个人各留一份）。
2. 明确写：岗位、工作内容、工作地点、工资构成（基本 + 绩效）、发薪日。
3. 试用期要有，但要合法（合同 3 个月–1 年 → 试用期 ≤1 个月；1–3 年 → ≤2 个月；3 年以上 → ≤6 个月），试用期工资不低于转正的 80%。
4. 附一份**岗位职责说明书**，双方签字——这是将来"不胜任"的唯一凭据。
5. 涉及钱的岗位（财务、采购、仓管）**单独签一份《廉洁与保密承诺》**。

> 劳动合同的补充条款（工资/保密/竞业）可直接抄 [附录/05-可直接抄写的模板样张](../附录/05-可直接抄写的模板样张.md) 第三节。

### 2. 工资按规矩发——别用"报销"代替

给家人发钱有三种做法，只有第一种是安全的：

| 做法 | 合规性 | 说明 |
|---|---|---|
| ✅ 工资表如实列，依法代扣个税、缴社保 | 安全 | 工资是公司的合理成本，可税前扣除 |
| ⚠️ 走"费用报销"发生活费 | **虚列成本** | 无真实业务支撑的报销 = 偷逃税，被查要补税 + 罚款 + 滞纳金 |
| ❌ 直接从公司账户转"私账" | 高危 | 既涉税，又涉**公司财产与个人财产混同**——可能丧失有限责任保护（见 [01](01-家庭与健康规划.md) §一.1） |

**工资定多少？** 参考两个锚：
- 不低于同岗位市场价的 **70%**，也不要高到离谱——税务局有权对"明显不合理的工资"做纳税调整。
- 全年工资 + 年终奖合计，要能覆盖他的真实生活需要；**不够的部分走"家庭内部支持"（从你自己的个人所得里给），不要从公司走**。

### 3. 社保：能不缴也能缴错，两种都别踩

- **必须缴**：只要是劳动关系（有管理、有工资、有考勤），就得缴。别信"家里人不用缴"。
- **基数不能乱报**：按实际工资报。长期按最低基数缴，未来养老金少、被稽查要补。
- **特殊情况**：已经退休返聘的父母 → 属**劳务关系**不是劳动关系，签《劳务协议》，不缴社保但**必须买一份雇主责任险/意外险**，否则老人上下班或工作受伤，公司要全额赔。
- **大学生子女实习** → 签实习协议，同样配意外险。

### 4. 权限：给岗位，别给万能钥匙

家人最容易在"权限"上出事，因为它不像工资那样看得见。

**三条线的授权纪律：**

| 权限 | 建议 |
|---|---|
| **银行 U 盾 / 网银复核** | 不要与你的付款权限在同一人手上。**制单与复核必须分离**——这是唯一能防住"内部一次性转走一大笔"的机制 |
| **公章 / 财务章 / 法人章** | 三章分人保管。若家里一人全拿，等于把公司交出去了 |
| **客户与供应商联系方式** | 不要在一个人手里无备份。统一进公司通讯录（哪怕只是个共享表格） |
| **系统管理员账号** | 财务软件、开票系统、电商后台，管理员账号留给你或专业会计 |

> **反面案例的典型形状**：妻子管钱 + 妻子管章 + 妻子管 U 盾 + 你从不过问流水 → 两年后你才发现公司账户里的钱和家里账目对不上。这不是信任问题，是**没有任何人能发现问题的机制**。见 [公司/14 财务基本功](../公司/14-公司财务基本功.md) 与 [公司/06 经营风险](../公司/06-经营风险.md)。

## 三、岗位红线：哪些位置不能让亲属占

### 1. 亲属回避清单（照抄进你的制度）

**必须回避**（同一人不能同时出现在这两端）：

- 上下级直接汇报关系（丈夫是妻子主管）
- 收款/付款 与 记账/对账（出纳与会计不能是夫妻）
- 采购/招投标 与 供应商管理（同一个人既找供应商又定价格）
- 人事招聘 与 薪酬核算
- 审计/内控 与 被审计岗位
- 仓管 与 进出库单据审核

**谨慎安排**（可以，但要加监控）：

- 家族成员担任**财务负责人**：可以做，但要求**每月报表复核 + 你亲自看银行流水**（见 [公司/14](../公司/14-公司财务基本功.md) §三"每月必盯的 8 个数"）。
- 家族成员担任**法定代表人**：⚠️ 特别注意——法定代表人要承担行政、甚至刑事层面的责任（欠税、被执行、被限高）。让配偶或年迈父母挂名"法人"而实际经营是你，风险几乎全落在他身上；他一旦被限高，孩子上学、家庭出行都受影响。**能自己当就自己当，别让家人替你挂名。**

### 2. 一个具体的反例：亲戚在采购岗

最容易出问题的岗位不是财务，是**采购**。原因：它有"合法地把钱花出去"的权力。

**采购岗的四个必要控制（哪怕公司只有 8 个人）：**

1. **三家比价**：单笔超过一定金额（建议 3000 元）必须三家报价单留档。
2. **价格库**：常买的东西记一份"上次多少钱、谁家买的"，你自己按月看一次。
3. **供应商黑名单**：明确"不得与本人或配偶的亲属经营的公司交易"，写进制度。
4. **回扣条款**：在采购岗合同里写明"收受回扣属严重违纪，可立即解除并要求赔偿"。

## 四、代持：让家人"帮你持股"，四个风险讲清楚

**代持是什么**：实际出资和享有权益的是你，但工商登记上写的是家人的名字。

**什么时候会被迫用**：自己已是被执行人、名下公司太多不方便、不想暴露、或者"父母要求写他们名字放心"。

**四个真实风险（按发生概率排序）：**

| 风险 | 说明 | 后果 |
|---|---|---|
| **1. 代持人自己的债务** | 他名下股份在你看来是资产，在法院看来是**他的财产** | 被强制执行抵债，你要另案起诉才能抢回来，且未必抢得到 |
| **2. 代持人婚变 / 继承** | 股份登记在他名下，离婚时配偶可主张分割；他去世则股份进入遗产 | 你会突然多出一堆"共同股东"（前嫂子、外甥） |
| **3. 显名困难** | 想把股份过回自己名下时，需要他配合签字，还要处理优先购买权、税务 | 谈崩了就是漫长的诉讼，甚至公司决策卡死 |
| **4. 口头代持等于没有** | 只有转账记录、没有书面代持协议 | 一旦翻脸，钱算"赠与"还是"借款"都可能说不清 |

**如果非做不可，把风险压到最低的三件事：**

1. **书面代持协议**：写清出资来源（你的钱、从哪个账户出的）、权益归属、他不得处分（不得转让/质押/设定担保）、显名条件（什么情况下必须配合过户）、违约责任。**双方签字 + 留存出资流水。**
2. **配套文件**：让他**同步签一份"股权转让协议"（日期留空）+ 授权委托书**，并让他配偶**签一份知情确认**（承认股份不是他的、不主张分割）。这不是防他，是防"他家的意外"。
3. **把代持写进家庭共识**：至少让核心家人知道这件事，避免他出事后家属一无所知、直接按遗产处理。

> 更彻底的做法是**用持股平台 / 有限合伙**代替个人代持：你当 GP 管事儿，家人当 LP 只享收益，既能给到利益又不分散表决权。这属于架构层面的事，够规模了再找专业人士做。

> 反过来也提醒一句：**别用"股份登记在父母名下"当财产隔离手段**。若被认定为逃避债务，法院可以撤销；而且父母一旦去世，股份变成遗产按法定继承分，会牵扯到你的兄弟姐妹。财产保护要走合法路径，见 [05-婚姻财产与股权安全](05-婚姻财产与股权安全.md) §六。

## 五、最难的一题：家人只拿钱不干活 / 干不了

### 1. 先分类，别用同一个办法

| 情形 | 处理方向 |
|---|---|
| **有能力、也认真干** | 正常员工对待，该涨工资涨工资，**该表扬表扬**（比给股份更有用） |
| **能力不够，但很努力** | 调岗到匹配的位置（后勤、仓管、客服）；工资随岗位走 |
| **能力不够，还不认同规矩** | 给"闲职 + 分红"而不是实职；别让他管人管钱 |
| **压根不想干，只想有保障** | 不安排岗位，直接给生活支持（从你个人收入出），**不进公司编制** |
| **在岗但造成实质损害**（吃回扣、拉帮结派） | 按制度处理，见下节"怎么请出去" |

### 2. 提前立好四份文件（这是"能开口"的底气）

问题几乎都出在"当初什么都没说"。四份东西在**他入职那天**就备好：

1. **岗位职责说明书**（他签字）——定义了"应该做什么"。
2. **考核标准与周期**（他签字）——定义了"做到什么算合格"，建议季度一次。
3. **薪酬方案与调整规则**（他签字）——写清"工资随岗位和考核变动"。
4. **《家庭内部约定》**（只有你和家人签，不用给外人看）——写明：
   - 家人进公司可以有岗位，但**不能有豁免权**；
   - 出现分歧时，**在公司听岗位、在家里听情理**；
   - 谁在家庭群里议论公司事务，你可以在群里回应"这事在公司说"。

> 这四份文件的作用不是"将来打官司用"，而是把**一次性的、撕破脸的谈判，变成事先说好的流程**。人在被辞退时最难受的不是失去工作，是"你从来没跟我说过这是不行的"。

### 3. 话术：怎么开口让他换个位置

> "你的活现在更多是 XX 这块，我想让你去做 YY，一个是这块我实在没人，第二个是这个位置更稳，不用天天求人。工资先不变，我们跑三个月看。"

**要点**：① 给新位置而不是"你不行"；② 强调"我缺人/我信任你"，不强调"你做不好"；③ 给观察期，让台阶下得来。

**如果必须让他离开公司**，用工上按法定流程走（协商一致解除 / 依法解除），再单独做一次家庭层面的沟通：

> "公司这段时间钱紧，X 这个岗位暂时不需要人了，你先出来。家里人这边该给的我一分不少，等行情好了再说。"

**关键：先走程序，再讲人情。** 顺序反了（先讲人情、程序放着不动）就成了"不清不白地走了"，将来谁都能拿这件事说话。

## 六、家庭会与公司会：两个会必须分开

这是家族企业唯一真正有效的"治理"。做法简单到离谱，但不做就一定乱。

| | 公司例会 | 家庭会 |
|---|---|---|
| **频率** | 每周 1 次，30 分钟 | 每月或每季度 1 次 |
| **参加人** | 有岗位的家人 + 员工 | 家庭成员（哪怕不参与生意） |
| **谈什么** | 目标、进度、问题、下周动作 | 家里的事、钱怎么安排、老人孩子、关系 |
| **不谈什么** | ❌ 家务事、妯娌矛盾、谁偏心 | ❌ 客户、供应商、员工评价、公司内斗 |

**三条纪律（贴在冰箱上都行）：**

1. **公司的事在公司会解决完，不带回家**；家里的事不进公司会。
2. **回家不批评价员工**——家人对员工的评价一旦传进公司，员工会立刻分成派系。
3. **重大财务决定（买房、大额投资、给亲戚借钱）在家庭会上定**，定完你就去执行；反过来，公司的经营决策**不需要家庭会批准**。

> 一句话：**"家里的事讲情，公司的事讲数。"**
> 混着讲，两边都会输——公司失去效率，家庭失去温度。

## 七、一处容易被忽略的地方：伴侣的知情权

创业者出事时，最先受伤的往往是伴侣。原因通常不是"没感情"，而是**不知道**。

**必须让伴侣知情的四件事：**

1. **公司债务与担保**：你以个人名义为公司借的钱、做的担保（见 [公司/13](../公司/13-合伙人股权与散伙预案.md)）。有些情况会构成夫妻共同债务，见 [05-婚姻财产与股权安全](05-婚姻财产与股权安全.md) §四。
2. **家庭资产的真实状况**：账户、房产、保单、投资分别在谁名下、值多少、密码在哪（用密封信或密码管理器，见 [个人与人际/05-数字资产与账号安全](../个人与人际/05-数字资产与账号安全.md)）。
3. **最坏情况预案**：公司倒了、你出事了，家里的安全垫能撑几个月、先动哪笔钱（见 [07-家庭应急与身后安排](07-家庭应急与身后安排.md)）。
4. **不让她"签字"是保护**：如果某些担保或共同借款你不希望她承担，**就不要让她出现在签字栏**——而不是签完再瞒着。

> 伴侣不是公司的股东，也不是你的下级。**她的知情权来自"共担后果"，而不是"参与经营"。**

## ✅ 本篇行动清单

| # | 行动 | 优先级 |
|---|---|---|
| 1 | 把已在公司工作的家人列出，逐个确认：有合同吗？发工资吗？缴社保吗？ | 高 |
| 2 | 补齐劳动合同 + 岗位职责说明书（含签字） | 高 |
| 3 | 检查"制单/复核/印章"是否分人保管，出纳与会计是否夫妻/亲属同岗 | 高 |
| 4 | 采购岗加"三家比价 + 价格库 + 回扣条款" | 高 |
| 5 | 有代持关系的，补齐代持协议 + 转让协议（空日期）+ 配偶知情确认 | 中高 |
| 6 | 让家人挂名法定代表人的，评估是否改为本人担任 | 中高 |
| 7 | 建立公司例会与家庭会两个机制，明确各自谈什么 | 中 |
| 8 | 与伴侣做一次"资产与风险坦白会"，列为年度动作 | 中 |
| 9 | 给退休返聘/实习的家人补雇主责任险或意外险 | 中 |

*亲情不是公司治理的替代品，公司治理也不是亲情的敌人——**把规矩立在前面的家庭，才不用靠翻脸来解决问题**。*
