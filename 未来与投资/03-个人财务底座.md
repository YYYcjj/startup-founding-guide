## 一、为什么"投什么"之前先要"我有什么"

- **投资亏的是钱，财务底座塌的是生活**：投资亏 30% 是账面难看；现金流断了、征信花了、房贷逾期，是**连锁反应**（断贷 → 罚息 → 征信 → 抽贷 → 公司周转也断）。
- **老板最容易犯的错：把个人和公司的风险叠在一起**——公司缺钱时用个人卡垫、个人借网贷填公司。这不是"投入"，这是把有限责任的保护**亲手拆掉**（见 §6）。
- **顺序不能反**：先看清家底 → 再还清坏债 → 再留应急金 → 最后才谈"投什么"。[02-项目投资 §4.4](02-项目投资.md) 讲的"投资是放大器不是发动机"，前提是发动机本身没漏油。

> **一句话**：**负债没理清之前，任何"机会"都是在放大你的脆弱。**

## 二、一张表看清家底：个人资产负债表

大多数人只知道自己"每月要还多少"，不知道自己"总共欠多少、值多少"。**先把它写在纸上，模糊的焦虑会立刻变成具体的数字。**

### 2.1 资产端（按变现速度从快到慢）

| 层级 | 项目 | 记什么 |
|------|------|--------|
| **随时能用** | 现金、活期、货币基金、余额宝 | 现在就能取出的金额 |
| **几天内能变现** | 银行理财（开放型）、短债基金、股票/ETF | 按**当前市值**记，不按买入价 |
| **几个月到几年** | 定期、封闭型理财、保险现金价值 | 赎回有成本，打折记 |
| **不好动的大件** | 自住房、车 | 按**保守市价**（不是中介挂的高价）|
| **最不流动** | 你持有的公司股权、期权 | 未变现前建议记 **0**，或按最近融资估值大幅打折 |
| **别人欠你的** | 借出去的钱、应收款 | 分"能收回的"和"当送的"两栏 |

> ⚠️ **两个最容易自欺的地方**：① 房子按挂牌价记，实际成交要低 5%–10%，还要减掉剩余的贷款和税费；② 公司股权按上一轮估值记——**没卖出去之前那不是钱，是纸面数字**。

### 2.2 负债端（按真实利率从高到低）

| 负债类型 | 典型年化 | 性质 |
|----------|----------|------|
| 网贷 / 助贷 / 现金分期 | 18%–36%（有的更高）| **坏债** |
| 信用卡分期、最低还款 | 13%–18%（实际 IRR）| **坏债** |
| 消费贷（银行） | 4%–15% | 看用途，多半是坏债 |
| 车贷 | 3%–8% | 中性（车本身在贬值）|
| 亲友借款 | 0%–8% + **人情成本** | 隐性成本最高 |
| 房贷 | 3%–5%（存量有更低/更高）| 可算**好债**（见 §3.1）|
| 经营贷 / 供应商账期 | 3%–6% | 工具型负债，用对是杠杆 |
| 欠税 / 欠社保 / 欠薪 | 罚息 + 法律后果 | **最优先处理** |

### 2.3 净值 = 资产 − 负债

画三条线自评（**用个人口径，不算公司**）：

| 指标 | 健康线 | 说明 |
|------|--------|------|
| **净值** | > 0 | 资产减负债为正，才算"有底子" |
| **净值 ÷ 月固定支出** | ≥ 6–12 个月 | 这是你"能扛多久没事"的真实长度 |
| **月还款额 ÷ 月收入** | ≤ 40%（红线 50%）| 超过 50% = 已被债务锁死，任何投资都别谈 |

> **发现净值是负的怎么办**：不要慌、也不要急着"投资翻本"。按 §3.4 的还款优先级先减债——**还掉 18% 的债，等于无风险赚 18%**，比任何投资都稳。

### 2.4 家底表模板（可直接抄）

```
【个人资产负债表 · 截至 ____年__月__日】

资产
├─ 随时能用（现金/货基）：          ______ 元
├─ 短期可变现（理财/股票/ETF）：     ______ 元
├─ 中长期（定期/保险现价）：         ______ 元
├─ 自住房（保守市价）：              ______ 元
├─ 车（保守市价）：                  ______ 元
```

> **什么时候填**：每季度一次，10 分钟。**它比任何理财课都更能让你清醒**——数字摆出来，"我其实还行"和"我在硬撑"一眼可见。

## 三、负债：分清"好债 / 坏债 / 致命的债"

### 3.1 一条判据就够

> **利率 < 你资产能稳定拿到的长期回报 → 好债；利率 > 它 → 坏债。**

比如你的钱只能稳定拿到 3%（存款/货基），那么 18% 的网贷是**纯亏**——**提前还款的收益率就是 18%，无风险**。反过来，3.5% 的房贷，而你长期能拿到 7%–8%，那这笔钱留着投资更划算（**前提是你不拿它去亏**）。

### 3.2 举债前先过四问

| 问题 | 不通过的表现 |
|------|--------------|
| **这笔钱会产出收益吗？** | 借来消费、借来还别的债 → 不通过 |
| **还款靠旧的收入还是靠新借的钱？** | 靠新借的 → **危险信号** |
| **最坏情况我能还上吗？** | 要靠"希望明年好起来" → 不通过 |
| **利率我看得懂吗？** | 说不清年化是多少 → 先算清再签（见 §3.3）|

### 3.3 真实年化利率怎么算（这是最容易被忽悠的一步）

**三个常见话术，及其真实年化：**

| 话术 | 真实代价 |
|------|----------|
| "日息万分之五" | 0.05% × 365 ≈ **18.25%/年**（且多数按日复利，实际更高）|
| "月费率 0.6%，10 万分 12 期" | 手续费 7200 元，但**本金逐月减少**，真实 IRR ≈ **13%**，不是 7.2% |
| "免息分期，只收手续费" | 手续费就是利息。免的是"名义利息"，不免成本 |
| "先扣服务费/砍头息" | 借 10 万先扣 1 万，到手 9 万却按 10 万计息 → 真实年化再抬一截 |

**自己算的办法（不用公式也能估）：**

```
名义总成本 ÷ 平均在用本金 ≈ 真实年化

例：借 12 万，分 12 期，每月还 1.1 万，共还 13.2 万
├─ 名义总成本 = 1.2 万
├─ 平均在用本金 ≈ 12 万 ÷ 2 = 6 万（按月等额还款，本金平均只借到一半）
└─ 真实年化 ≈ 1.2 ÷ 6 = 20%   ← 不是 10%
```

> **红线**：任何"算不清年化"的产品，签之前先问一句"**把全部费用算进去，年化是多少**"。对方答不出来或绕开这句话的，**直接不签**。

### 3.4 还款优先级：先杀利率最高的（雪崩法）

| 方法 | 做法 | 适合 |
|------|------|------|
| **雪崩法（优先）** | 最低还款保住所有债，**余钱全砸利率最高的那笔**，还完转下一笔 | 理性、省钱最多 |
| **雪球法** | 先还**金额最小**的那笔，快速获得"还清一笔"的成就感 | 需要心理支撑、容易半途放弃的人 |

```
还款顺序（从先到后）：
1. 欠税 / 欠社保 / 欠薪       ← 有法律后果，最优先
2. 网贷 / 助贷（18%+）        ← 纯亏，优先清
3. 信用卡分期 / 最低还款       ← 真实年化 13%–18%
4. 消费贷
5. 亲友借款                   ← 金额小也先还，人情成本高
6. 车贷
7. 房贷                       ← 好债，照常还，不必急还
```

> ⚠️ **绝对不要**：为了"统一利率更低"去借一笔新的网贷来还旧债——看似降息，实则**加了一层手续费**，且把短期债换成了更长的锁定期。**唯一的例外**：把 5 笔高息小额网贷置换成一笔银行低息贷款（**且总成本真降了**），这叫"债务整合"，是正经做法。

### 3.5 "以贷养贷"的三个红灯（出现一个就要立刻停手）

| 红灯 | 表现 |
|------|------|
| 🚩 **借新还旧** | 这个月的还款靠新借的钱 |
| 🚩 **多头借贷** | 同时在 3 家以上平台有借款（征信上一目了然）|
| 🚩 **本金不降** | 还了一年月供，总欠款几乎没少（说明在还利息和手续费）|

**停手动作**：① 立刻停止新增借贷；② 列出全部债务与利率；③ 主动联系机构协商（见 §3.6）；④ 必要时告诉家人——**独自硬扛到催收上门是代价最大的路径**。

### 3.6 逾期了怎么办：能做的事与绝不能做的事

**能做的（按顺序）：**

1. **别失联**——电话要接，渠道要留痕（这是"有还款意愿"的唯一证据）。
2. **主动协商**：向机构申请**延期、分期、减免罚息**。说明真实困难（失业、生病、公司周转），提供证明。信用卡类欠款协商成功的概率，**远高于**你想象。
3. **保留全部证据**：借款合同、还款记录、通话录音、协商结果（要求书面或短信确认）。
4. **优先保住房贷和征信干净的那部分**——房贷断供处置成本最高。
5. **真到极限**：咨询正规律师或当地法律援助；个人破产制度目前仅在**深圳等少数地区试点**，各地不适用，别轻信"帮你破产免债"的中介。

**绝不能做的：**

| ❌ 动作 | 为什么 |
|---------|--------|
| 借高利贷/套路贷平账 | 债务雪球从这一刻失控 |
| 找"反催收""征信修复"中介 | 几乎全是骗局，收费后让你伪造材料，**可能涉嫌违法** |
| 换号失联、注销手机 | 会被认定为恶意逃废债，性质变了 |
| 拿公司钱/公款还个人债 | 可能构成职务侵占，**从民事变刑事** |
| 借亲友的钱去堵窟窿但不说明 | 把一个人的债变成一群人的债 |

> **正确的征信"修复"只有一种：结清欠款 + 等时间**（见 §4.4）。任何声称能"洗白征信"的，100% 是骗子。

## 四、征信：未来五年最贵的一张纸

对一个 25–35 岁、还要买房、贷款、开公司的人来说，**征信报告是你在金融系统里的身份证**。它坏了，不是"影响心情"，是：房贷利率上浮或直接被拒、经营贷批不下来、公司融资时投资人尽调减分、部分岗位入职被卡。

### 4.1 征信报告上有什么

| 板块 | 内容 |
|------|------|
| 基本信息 | 身份、婚姻、职业、住址（部分来自你办业务时填的）|
| 信贷信息 | 每笔贷款/信用卡的额度、已用额度、还款记录（**逐月标注是否逾期**）|
| 非信贷信息 | 法院失信被执行人、欠税、行政处罚等公共记录 |
| 查询记录 | 谁在什么时候因为什么查了你的征信 |

### 4.2 怎么查

- **官网**：中国人民银行征信中心"个人信用信息服务平台"（互联网查询，免费）。
- **线下**：人民银行分支机构 / 商业银行代理网点的自助查询机（通常每年有一定免费次数，超出少量收费，**以官网最新公告为准**）。
- **建议频率**：**每年 1–2 次**，重点看有没有"不是自己办的"贷款或担保。

> ⚠️ **注意**：自己查（"本人查询"）属于**软查询**，不影响评分。**机构因放贷而查（"硬查询"）才会**——所以别到处点"测测你能借多少"，那些按钮就是硬查询。

### 4.3 三个毁征信的动作

| 动作 | 后果 |
|------|------|
| **"连三累六"** | 连续 3 个月逾期，或两年内累计 6 次逾期 → 银行直接判为严重不良 |
| **频繁被查征信** | 短期内在多家机构申请贷款/信用卡（"多头"信号）→ 即使没逾期也降分 |
| **给别人做担保** | 对方逾期，**账记在你的征信上**；这是最容易被亲情绑架的坑 |

> **给老板的特别提醒**：做企业贷款时常见的"**法人/股东个人连带担保**"，签下去就把公司风险接回个人身上了。签前一定确认：额度、期限、有没有配偶同意函、公司出事了你要还多少。

### 4.4 征信坏了怎么修

| 情况 | 处理 |
|------|------|
| **确实逾期过** | 结清欠款 → 从**结清之日**起满 5 年，不良记录自动不再展示（不是从逾期那天算起）|
| **非本人原因**（被盗办、机构报送错误、已还款被记逾期）| 向**放贷机构**或**人民银行征信中心**提出**异议申请**，要求更正——这条路免费且有效 |
| **小额短期逾期** | 结清后保持 2 年以上良好还款，影响会明显衰减（银行主要看近 2 年）|
| **被中介说"能洗白"** | 骗局。唯一路径：结清 + 时间 + 保持良好记录 |

> **一句话**：征信没有捷径，只有"**别再逾期**"这四个月就见效的动作 + "**等五年**"这个不快但确定的动作。

## 五、应急金：给"意外"留出跑道

家庭层面的安全垫见 [家族/01-家庭与健康规划](../家族/01-家庭与健康规划.md) 一、家庭财务底线 · 1. 财务安全垫。这一节只讲**个人口径**和**创业者怎么算**，不重复。

### 5.1 该留多少（按月数算，不按"感觉"）

| 你的处境 | 应急金 = 个人月固定支出 × |
|----------|--------------------------|
| 双职工、收入稳定、无负债 | 3–6 个月 |
| 单收入 / 有房贷 / 有孩子 | 6–12 个月 |
| **自由职业 / 收入波动大** | 9–12 个月 |
| **创业者（公司还没稳定盈利）** | **12–24 个月** |

> **为什么创业者要 12–24 个月**：公司现金流断了的时候，你**不能**从公司拿钱，也不该用个人借贷去填（见 §6）。这段时间的房租、生活费、社保、孩子学费，都得从个人应急金出。

### 5.2 放在哪（三个要求：能立刻取、不亏本、和日常账户分开）

- **货币基金 / 银行活期+**：随时可取，收益低但不会亏——这是应急金该有的样子。
- **短债基金**：收益略高，波动极小，赎回 1–2 天到账，可放一半。
- **绝对不放**：股票、基金定投、加密、有封闭期的理财、你公司的账上。**应急金的第一要求是"确定"，不是"收益"。**

### 5.3 什么情况能动（白名单 / 黑名单）

| ✅ 能动的 | ❌ 不能动的 |
|-----------|------------|
| 失业、收入中断 3 个月以上 | 想买个新手机/包 |
| 生病住院、意外事故 | "这个币要涨了""这只股票抄底" |
| 家人急病、必须赶回老家 | 公司缺钱（这是 §6 的红线）|
| 房屋/车辆必需维修 | "机会难得"的投资 |

> **动过之后第一件事：补回来。** 应急金被消耗后，下一步的余钱优先补满应急金，再谈投资。

## 六、个人与公司的"防火墙"（别用个人卡填公司）

创业者最贵的错误不是投错项目，是**把个人信用当成公司的备用金**。有限责任公司之所以"有限"，前提是你**没有**亲手把它拆掉。

### 6.1 四种穿透有限责任的常见动作

| 动作 | 为什么危险 |
|------|-----------|
| **公私账户混用** | 用个人卡收公司款、拿公司钱付私人开销 → 法院可认定财产混同，判你**个人承担公司债务** |
| **个人为公司担保** | 银行/投资人要求法人签字连带 → 公司还不上，直接追到你个人房产 |
| **个人名义借经营款** | 以"我"的名义借，钱进公司花 → 借款人是你，公司只是花了你的钱 |
| **抽逃出资 / 随意转出** | 注册资本验资后转走、股东随意借款不还 → 可能构成抽逃出资，股东在抽逃范围内对公司债务担责 |

> 详细规则见 [公司/06-经营风险](../公司/06-经营风险.md)。**一句话：公司缺钱的正解是"融、省、收"（融资/降本/催收），不是"从个人身上抽"。**

### 6.2 给自己发工资的正确姿势

- **严格分账**：公司账户 → 个人账户，走**合法薪酬或分红**，有凭证、有记录，理由说得清。
- **金额锚定"生活所需"**：按当地社保缴费基数区间和个人固定支出定，别定到刚好覆盖月供还超支——**收入不稳定时，公司发的越少、你越安全**。
- **社保别断**：断缴影响医保报销、部分城市的购房/落户资格。公司困难时，可先按最低基数缴（见 [家族/06-父母养老与照护实操](../家族/06-父母养老与照护实操.md) 关于医保的说明）。
- **分红和工资是两件事**：分红要有利润和决策程序，不是"想拿就拿"。

## 七、季度个人财务体检（8 项，10 分钟）

```
【第 ___ 季度 · 个人财务体检】

□ 净值：本季度净值为 ______ 元（上季度 ______ 元）→ 增加 / 持平 / 减少
□ 负债：总负债 ______ 元，最高利率那笔是 ______%（有网贷/信用卡分期吗？）
□ 月供比：月还款额 ÷ 月收入 = ______%（是否 > 40%？）
□ 应急金：现有 ______ 元 ÷ 月支出 ______ = ______ 个月（是否达到 §5.1 的标准？）
□ 征信：本季度有无逾期？有无新增硬查询？有无新签担保？
□ 公私边界：有无用个人账户收付公司款？有无新增个人担保？
□ 保险：医保/商业险是否在有效期内？保额是否随家庭变化调整？
□ 下季度动作：还债 ______ 元 / 补应急金 ______ 元 / 投资 ______ 元
```

## ✅ 本节行动清单

**本周：**
- [ ] 填完 §2.4 的家底表，算出净值与"月供 ÷ 收入"两条线
- [ ] 把所有负债列出来，**写下每一笔的真实年化**（算不清的那笔单独标出来查）
- [ ] 查一次个人征信报告（官网），确认无盗办、无错误逾期、无遗忘担保
- [ ] 关闭所有 App 里的"测额度"入口，停止产生硬查询

**1 个月内：**
- [ ] 按 §3.4 的优先级制定还款计划，最高息那笔开始额外还款
- [ ] 应急金单独开一个账户，开始**每月先转走**（金额按 §5.1 目标倒推）
- [ ] 若已逾期：主动联系机构协商一次，并保留书面/短信结果
- [ ] 若公司账与个人账有混用：这周起严格分开，写下分账规则

**每季：**
- [ ] 跑一遍 §7 的 8 项体检
- [ ] 更新家底表，看净值是升还是降
- [ ] 检查有无新增担保、新增硬查询

**每年：**
- [ ] 重评负债结构（有无高息债可置换为低息）
- [ ] 重估应急金月数（收入/家庭/负债变化 → 调整）
- [ ] 复盘：这一年净值的增长，来自"多赚"还是"少欠"？
